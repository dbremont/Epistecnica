## Notes

> Objects that exist only inside a computer system — an avatar's possessions, a plot in a virtual world, an account entry — behave like property: they are rivalrous, they persist, and they connect to other things. Fairfield argues that this is enough to treat them as property, with claims running both against other users and against the operator whose code defines them.

The article's contribution is to break the identification between a holding and a physical thing. If rivalrousness and persistence are what matter, then a database entry can be the object, and the code that governs access *is* the enforcement apparatus rather than a neutral platform underneath it.

That is the precise point where virtual objects meet the digital register: the same record is the title and the thing titled, and the platform operator holds a power — rewriting the entry — that no land registrar has. Fairfield's argument supplies the corpus note with the boundary case for the `Digital Register` row and for the virtual-object entry in the relation note.
