## Notes

> Herman Hollerith's 1889 paper — the electric tabulating system described: the punched card and its positions, the press whose pins closed circuits through the holes, the dials that counted, and the sorting box that divided the cards by any field. The system built for the 1890 census, and the origin of data processing as a technical practice — the card, the code and the machine in one design.
