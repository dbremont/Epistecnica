## Which are the most fundamental ideas in mathematical epistemic practice?

| Fundamental family | Primary concepts | Important derived concepts |
|---|---|---|
| **Existence and identification** | Object, element, set, collection | Membership, identity, distinction |
| **Characterization** | Property, predicate | Classification, invariance, attribute |
| **Association** | Relation, correspondence | Equality, equivalence, order, incidence, adjacency |
| **Mapping** | Map, function, transformation | Injection, surjection, bijection, isomorphism |
| **Combination** | Operation, composition | Addition, multiplication, union, intersection, join |
| **Quantification** | Quantity, cardinality, magnitude | Counting, measure, metric, norm, probability, dimension |
| **Organization** | Structure, configuration | Group, ring, field, vector space, topology |
| **Comparison** | Comparison, ordering | Inequality, ranking, dominance |
| **Restriction** | Condition, constraint | Equation, inequality, system of equations, boundary condition |
| **Change** | Transformation, variation | Derivative, difference, rate, evolution |
| **Approximation** | Approximation, error | Limit, convergence, tolerance, numerical approximation |

This suggests a useful distinction between three levels:
1. Basic mathematical notions: object, collection, property, relation, quantity.
2. Mathematical constructions: map, operation, measure, metric, ordering, structure.
3. Mathematical formulations: equation, inequality, function definition, system of equations, optimization problem.

| Concept | Fundamental idea | Examples / manifestations |
|---|---|---|
| **Object** | Something mathematically identifiable and distinguishable. | Number, point, vector, function, set, matrix, group. |
| **Set / Collection** | A plurality of objects considered together. | Natural numbers, points of a plane, subsets. |
| **Property** | A characteristic or condition attributable to an object. | Being even, being continuous, being prime, having a particular dimension. |
| **Membership** | Whether an object belongs to a collection. | \(x \in A\). |
| **Relation** | A specified association between objects. | Equality, inequality, order, incidence, adjacency, equivalence. |
| **Map / Function** | A correspondence assigning elements of one domain to elements of another. | \(f:A\rightarrow B\). |
| **Operation** | A rule that combines mathematical objects to produce an object. | Addition, multiplication, composition, intersection. |
| **Structure** | An organized configuration of objects and specified relations or operations. | Group, ring, field, vector space, topology. |
| **Quantification** | Determining or expressing how many, how much, or to what extent. | Counting, cardinality, measure, probability, dimension. |
| **Order** | An arrangement of objects according to a specified comparison. | \(<,\leq\), partial orders, rankings. |
| **Equivalence** | Identifying objects as equivalent according to a criterion. | Congruence, isomorphism, equality. |
| **Constraint** | A condition restricting which objects or configurations are admissible. | Equations, inequalities, boundary conditions. |

most fundamental ideas in maths; quantification, property (self,  join), object, map, relation (equation, ..)
