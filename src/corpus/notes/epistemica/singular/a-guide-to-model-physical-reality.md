# A Guide to Model Physical Reality

> **Physical reality** is modelled by first saying what is being modelled: the things that exist, the features they carry, the relations between them, and the changes they undergo. This guide fixes that cut — four families of target plus the layer that describes them — so that a model can be located in the corpus and its scope stated, rather than argued from scratch each time.

> The cut is not a taxonomy of the world; it is a way of separating questions. *What exists* is answered by entities, *what it carries* by properties, *how entities bear on one another* by interactions, and *what happens* by phenomena. A model that cannot say which of the four it is about has not yet said what it models.

> The second layer is the one usually left implicit. A model of physical reality is not itself physical reality: a frame of reference, a configuration space, a phase space, a state space, and a framework of mechanics are instruments of description. Filing them among the entities is the error this guide exists to prevent — a reference frame is not a thing in the world, it is the standpoint from which a description is written.

## The cut

```text
Physical reality
│
├── Physical entities
│   ├── Particles
│   ├── Fields
│   ├── Physical systems
│   ├── Body
│   ├── Continuous body
│   └── Matter
│
├── Physical properties
│   ├── Mass
│   ├── Electric charge
│   ├── Spin
│   └── Inertia
│
├── Physical interactions
│   ├── Gravitational
│   ├── Electromagnetic
│   ├── Strong
│   └── Weak
│
└── Physical phenomena
    ├── Motion
    ├── Magnetism
    ├── Radiation
    └── Nuclear decay

Description of physical reality
│
├── Reference frame
├── Configuration space
├── Phase space
├── State space
└── Frameworks of mechanics
```

## How to read the tree

The tree is a **lens, not an inventory**: each leaf names the corpus note that decomposes it, and a leaf without a note is marked rather than invented. Using it means answering in order — which family the model is about, which node inside it, and whether the apparatus it depends on belongs to the target or to the description layer.

Two boundaries carry most of the work. **Entity versus property**: mass, charge, and spin are carried; particles, fields, bodies, and matter carry them — the same note may appear under both headings only as a bearer and as a carrier, never as a second element. **Target versus description**: a frame, a space, or a framework changes what can be said about reality, not what reality contains, so a model's dependence on them is a dependence on its instruments.
