# Phase Field Method


> A numerical technique for modeling phase transitions and complex phenomena like crack propagation, interfaces, and microstructure evolution.
>

> The **phase-field model** is the model the technique integrates: an interface is represented by a continuous field that varies smoothly across the transition, so the boundary needs no explicit tracking.
>
