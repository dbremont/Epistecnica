# Personal

> The personal corpus: the working knowledge forest — how to study, how to think, how to run a task, and the guides and essays gathered around that practice.

The forest came in from the *Breviarium* export, one note per guide, essay, question or template. Its master note is the inventory the rest hangs from:

- [Breviarium](/view.html?p=notes/miscellanea/personal/breviarium.md) — the inventory of methods, guides and task-execution practice.
- [A Guide to Study](/view.html?p=notes/miscellanea/personal/a-guide-to-study.md) — studying as intentional engagement with a subject, and the guides it contains.
- [A Guide to Building Knowledge Forest](/view.html?p=notes/miscellanea/personal/a-guide-to-building-knowledge-forest.md) — the knowledge system the corpus itself is an instance of.
