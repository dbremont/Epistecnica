# Interactions

> The interaction shelf: the relations through which two elements act on each other, filed by what kind of relation they are. A force is one way an interaction shows itself — the [force shelf](../force/forces.md) holds those — and a [fictitious force](../force/fictitious-force.md) is the case of a force-like term that names no interaction at all.

## The axes

| Axis | Values | What it decides |
| --- | --- | --- |
| **Status** | fundamental / effective | whether the interaction is one of the four, or emerges from them at a scale |
| **Description** | classical / quantum | whether it is written as a force field or as an exchange of quanta |
| **Scope** | pairwise / collective | whether it joins two elements or produces a behaviour of the many |
| **Domain** | molecular / electromagnetic / cosmological | which scale and which theory owns the description |

## What is in the shelf

| Note | What it carries |
| --- | --- |
| [Fundamental Interaction](fundamental-interaction.md) | The four interactions and their unification — the electroweak case stated in the note. |
| [Fundamental Molecular Interaction](fundamental-molecular-interaction.md) | The intermolecular attractions and repulsions that decide the properties of a molecular substance. |
| [Electromagnetic Interactions](electromagnetic-interactions.md) | The interaction of charges and currents — the one that builds chemistry and matter as it is met. |
| [Electron Interaction](electron-interaction.md) | The interaction of an electron with its surroundings and with other electrons. |
| [Quantum Mechanical Interactions](quantum-mechanical-interactions.md) | Interactions described as exchange and superposition rather than as classical fields. |
| [Configuration Interaction (CI)](configuration-interaction-ci.md) | The mixing of electronic configurations in a quantum-chemistry calculation. |
| [Cosmological Interactions](cosmological-interactions.md) | Interactions at the scale where gravity and the expansion of the universe set the frame. |
| [Emergent and Collective Interactions](emergent-and-collective-interactions.md) | Interactions whose effect is a collective behaviour rather than a pairwise sum. |
| [Physical Interaction](physical-interaction.md) | The general notion: two physical elements affecting each other. |
| [Interaction Space](interaction-space.md) | The space in which the possible interactions of a system are laid out. |
| [Interaction / Effects](interaction-effects.md) | The effects an interaction produces — the observable side of the relation. |
| [Interaction's Outcomes](interactions-outcomes.md) | What the interaction leaves behind: the state change read as an outcome. |
| [Taxonomy of Interactions](taxonomy-of-interactions.md) | The classification the shelf applies, stated as its own note. |
| [Specialized and Niche Interactions](specialized-and-niche-interactions.md) | Interactions that hold only in a narrow regime, and the models built for them. |

Most of these are still undecomposed imports: they state a type and mark the expansion as pending. The shelf exists so that the family can be worked in one place.
