# Actor — Interaction Unit Home

> Notes for the Interaction Unit element — who acts. The actor shelf keeps `private/` (societal actors) and the generic kind hubs at this root (organization, firm, research, finance, human, family, party, …). Mixed families (`research`, `finance`) split by public authority, each with a root hub linking both halves. The public-actor side is filed in the koinomia domain shelf at [`koinomia/actor/`](/view.html?p=notes/social/koinomia/actor/readme.md); the old `public/` path is a source shell with a directory link. The plural side — the Social Compound genus and its branch of society and sovereignty — is filed in the koinomia domain shelf under [`koinomia/collective/`](/view.html?p=notes/social/koinomia/collective/readme.md); polity is the political form in [`koinomia/polity/`](/view.html?p=notes/social/koinomia/collective/polity/polity.md). Root hub: [Actor](/view.html?p=notes/social/actor/actor.md).
