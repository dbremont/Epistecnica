# Facet Scope

> **Facet Scope** is the master note of the facet shelf: the contract a per-facet note follows, and the register of the facets that have one. Each note here takes a single row of the [facet catalogue](/view.html?p=notes/social/meta/facet.md) and develops it — the mechanism in its own terms, its boundaries against the neighbouring facets, and where its elements live in the corpus.

> The concept is not defined here. [Facet](/view.html?p=notes/social/meta/facet.md) owns the definition, the authoritative list, the distinction from a field, and the crossing with the layer axis. This note owns the shelf: what a facet note must contain, and which ones exist.

## What a facet note contains

A note on this shelf is read in five parts, and each answers a question the catalogue cannot:

1. **The mechanism, in one sentence.** The row's mechanism restated so that it can be applied, not merely quoted — *what does the explanatory work here?*
2. **Its boundaries.** The adjacent facets it is most easily confused with, and the difference stated by mechanism rather than by subject matter.
3. **What it explains.** The kind of instance the reading is illuminating for, and the kind it is not.
4. **Where its elements live.** The corpus paths that carry the facet's elements, each keeping its own element type.
5. **QA, and references.** The questions the reading raises, and the notes and literature it rests on.

A facet note carries **no decomposition table**. A facet is a lens: it owns no nodes, so there is no instance tree for it to decompose. The `Instance Tree Path` tables belong to elements, and an element read under a facet keeps the table it already has.

The catalogued facets without a note are not a gap to be filled for symmetry. A facet earns a note when the corpus holds enough of its elements for the reading to be worth stating, and the catalogue remains the authority on which facets exist.

## How a facet is assigned

- **Ask what does the explanatory work.** Not *who participates* and not *in which sector the instance sits*: a hospital, a bank and a farm each carry a technical facet, and none of them *is* the technical facet.
- **Keep the element's own type.** The instance is still an actor, an activity or a compound; the facet only scopes the inquiry. Typing is not reassigned by reading.
- **Expect more than one reading.** The same configuration answers to several mechanisms at once — a port city as labour market, jurisdiction and hiring culture — and each reading should be internally coherent.
- **Take a reading only if it explains.** A reading that explains nothing another facet does not is a redescription, and the mechanism test exists to reject it.

## What a facet note is not

- **Not the catalogue.** The list of facets and their one-line definitions lives in [Facet](/view.html?p=notes/social/meta/facet.md); duplicating it here is how two versions begin.
- **Not a field.** A field is an arena with positions and resources — a locus; a facet is a dimension — a lens.
- **Not a system.** No boundary is drawn around a society, and no whole is claimed.
- **Not a sector.** Facets cross-cut industries, organisations and institutions.
- **Not a decomposition.** No branch, no type segments, no instance paths.

## Adding a facet

1. Add the row to the [catalogue](/view.html?p=notes/social/meta/facet.md) first, with the mechanism named in one line. The catalogue is the authority; a note without a row is an orphan.
2. Write the note on this shelf, tagged `[note, facet, <facet>, social-ontology]`, following the five parts above.
3. Rebuild the notes index so the shelf and the search snapshot see it.

## QA

### Why does the concept not live on this shelf?

> Because a catalogue that is also an argument drifts: the list is consulted, the argument is read, and the two update at different speeds. Keeping the definition and the authoritative list in one note, and the developments in another, gives each a single place to change.

### Can a facet note exist before its elements?

> Yes. The [Research Facet](/view.html?p=notes/social/meta/facet/research.md) was written while its elements were still being filed, and it stated where they would live. The order matters for a different reason: a facet note is a claim about what the corpus will hold, and it should be written when the claim can be checked against something.
