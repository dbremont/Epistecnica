# How do you search for all files in Linux using the command line?


## mlocate

> Install: `sudo apt-get install mlocate`
> 

> **mlocate** is a **command-line tool** used for quickly locating files and directories on a Unix-like operating system by building and updating a database of file names and locations.
> 
1. **updatedb**: A command-line tool that updates the mlocate database by scanning the filesystem to record the names and locations of files and directories.
2. **locate**: A command-line utility that searches the mlocate database to quickly locate files and directories based on their names.
3. **locate.updatedb**: A cron job script that schedules regular updates of the mlocate database to ensure it reflects changes in the filesystem.
