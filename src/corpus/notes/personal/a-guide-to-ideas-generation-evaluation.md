# A Guide to Ideas: Generation & Evaluation


Here's a list of some popular **idea-generation models**:

| **Model** | **Description** |
| --- | --- |
| **Brainstorming** | Group generates ideas spontaneously and without criticism. |
| **SCAMPER** | Structured method using prompts to modify existing ideas/products (Substitute, Combine, Adapt, Modify, etc.). |
| **Mind Mapping** | Visual technique where ideas branch out from a central concept, enabling nonlinear thinking and idea association. |
| **TRIZ (Theory of Inventive Problem Solving)** | Systematic approach focusing on resolving contradictions to find inventive solutions. |
| **Six Thinking Hats** | Method by Edward de Bono, exploring problems from six perspectives: emotional, positive, negative, creative, process, factual. |
| **Design Thinking** | Human-centered approach to innovation involving user understanding, ideation, prototyping, and testing. |
| **Osborn-Parnes Creative Problem Solving (CPS)** | Structured process for problem understanding, idea generation, evaluation, refinement, and solution implementation. |
| **Random Word/Phrase Generation** | Using random words/phrases to trigger new ideas and associations. |
| **Reverse Thinking** | Considering the opposite scenario to stimulate new ideas. |
| **The Walt Disney Method** | Looking at a problem from three perspectives: dreamer (creative), realist (planning), critic (evaluating). |
| **Attribute Listing** | Breaking down a problem/product into attributes and generating ideas by changing/improving them. |
| **Morphological Analysis** | Breaking a problem into parts and combining elements in various configurations to generate solutions. |
| **Provocation** | Posing provocative or extreme statements/questions to stimulate unconventional thinking. |
| **Lotus Blossom Technique** | A variation of mind mapping with ideas organized in a structured grid around a central theme. |
| **Synectics** | Making connections between unrelated concepts to generate innovative ideas. |
| **Cross-Pollinate Ideas** | Sparking innovation by discovering novel solutions at the intersection of unrelated domains. |
