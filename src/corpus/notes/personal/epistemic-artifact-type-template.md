# Epistemic Artifact Type Template

**Contains:** [Epistemic Tool Template](/view.html?p=notes/personal/epistemic-tool-template.md)

> An **epistemic artifact type** is a **class of structured objects** defined by a shared formal structure, semantic interpretation, and admissible operations, which collectively encode a family of possible affirmations about reality.
> 

> An **epistemic artifact** is a structured object that encodes constraints, claims, or distributions over reality, and enables systematic reasoning, inference, or decision-making.
> 

> It is defined by its **role in the space of possible affirmations about reality**, not by its representation (symbolic, numeric, graphical, etc.).
> 

> 
> 
> 
> It is characterized not by a single instance, but by the **space of all valid instances**, along with:
> 
> - constraints on their structure,
> - rules of interpretation,
> - and permitted transformations.

## Meta-Questions (Schema Limits)

- **Which classes of artifacts escape this schema?**
    - Tacit mental states (non-externalized beliefs)
    - Pre-linguistic perceptual fields
    - Purely procedural knowledge (no stable representation)
- **Which dimensions are intentionally excluded?**
    - Implementation substrate (memory, notation, storage)
    - Sociological production context
    - Cognitive accessibility constraints

## Index

## Identity

- **Name**
- **Artifact Class**
    - What *kind* of epistemic object is this?
        - (proposition, model, distribution, embedding, constraint system, program…)
- **One-line Semantic Summary**
    - *What kind of claim about reality does it encode?*

## Structural Characterization

- **Internal Structure**
    - Formal structure of the artifact
        - (graph, vector space element, logical formula, function, distribution…)
- **Granularity**
    - Resolution at which reality is represented

## Semantic Content

- **Claim Type**
    - What kind of affirmation does it encode?
        - Deterministic (true/false)
        - Probabilistic
        - Relational
        - Causal
        - Functional
- **Reference Mapping**
    - How does it map to reality?
        - Direct (measurement)
        - Indirect (latent construct)
        - Hypothetical (model-based)
- **Truth Conditions**
    - Under what conditions is the artifact *correct*?

## Epistemic Role

- **Function in Reasoning**
    - What does this artifact enable?
        - Inference
        - Prediction
        - Compression
        - Explanation
        - Decision
- **Position in Epistemic Pipeline**
    - Input, intermediate, or terminal artifact?
- **Dependency Structure**
    - Which prior artifacts does it depend on?

## Operational Affordances

> What can you *do* with this artifact?
> 
- **Supported Operations**
    - (conditioning, marginalization, composition, querying, optimization…)
- **Closure Properties**
    - Which operations produce artifacts of the same type?
- **Composability**
    - How it combines with other artifacts

## Information Profile

- **Information Content**
    - Entropy, complexity, or description length
- **Compression Characteristics**
    - What redundancy is removed?
- **Information Loss**
    - What distinctions are collapsed?

## Interpretation Layer

- **Human Interpretability**
    - Direct / mediated / opaque
- **Common Misreadings**
    - Typical semantic errors when interpreting the artifact
- **Representation Dependence**
    - Does meaning depend on encoding?

## Validation & Justification

- **Validation Criteria**
    - Logical consistency
    - Empirical adequacy
    - Calibration (if probabilistic)
- **Falsifiability**
    - Can the artifact be invalidated?
- **Uncertainty Characterization**
    - Does it encode its own uncertainty?

## Failure Modes

- **Semantic Failure**
    - Misalignment with reality
- **Structural Failure**
    - Ill-posed or degenerate representation
- **Operational Misuse**
    - Invalid operations applied
- **Overinterpretation**
    - Extracting claims not encoded

## Scope & Limits

- **Domain of Validity**
    - Where does this artifact apply?
- **Resolution Limits**
    - What cannot be represented?
- **Non-Expressible Phenomena**
    - Which aspects of reality are excluded by construction?

## Cognitive Friction

- Confusion between:
    - Artifact vs underlying reality
    - Precision vs accuracy
    - Representation vs semantics
- Treating:
    - Model outputs as observations
    - Encoded uncertainty as ignorance (or vice versa)

## Comparative Position

- **Adjacent Artifact Types**
- **Substitutable Artifacts**
- **Trade-offs**
    - Expressiveness vs tractability
    - Interpretability vs richness
    - Stability vs sensitivity

## Provenance & Lineage

- **Generating Tools**
    - Which epistemic tools produce this artifact?
- **Transformation History**
    - Sequence of transformations applied
- **Versioning / Evolution**
    - How the artifact changes over time

## ❓ QA (Diagnostic Layer)

- What *exactly* would make this artifact false?
- Which transformations preserve its meaning?
- Can two distinct artifacts encode identical claims?
