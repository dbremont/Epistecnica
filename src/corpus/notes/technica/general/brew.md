# brew

> Homebrew, the package manager for macOS and Linux: formulae install into a prefix the user owns, without touching the system package manager.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Package management |
| **Relation** | `apt`/`dnf` |
| **Main advantage** | User-space packages across platforms |

## Typical use

```sh
brew install ripgrep
```
