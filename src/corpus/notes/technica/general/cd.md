# cd

> The shell builtin that changes the current working directory; it is a shell primitive rather than an external program, so it affects the shell's own state.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Navigate directories |
| **Relation** | `cd` |
| **Main advantage** | The primitive every other tool relies on |

## Typical use

```sh
cd /var/log
```
