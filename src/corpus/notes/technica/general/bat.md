# bat

> A `cat` replacement that adds syntax highlighting, line numbers, Git change markers and paging, while staying a drop-in for the common cases.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Inspect file metadata |
| **Relation** | `cat` |
| **Main advantage** | Syntax highlighting and paging |

## Typical use

```sh
bat --style=numbers file.md
```
