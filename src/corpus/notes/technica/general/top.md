# top

> An interactive process monitor that refreshes the process table in place and shows load, memory and per-process CPU.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Process management |
| **Relation** | `top` |
| **Main advantage** | The portable monitor |

## Typical use

```sh
top -o %CPU
```
