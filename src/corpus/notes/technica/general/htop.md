# htop

> An interactive process viewer with colour, mouse support, per-core meters and kill/search keys — the friendlier replacement for `top`.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Process management |
| **Relation** | `top` |
| **Main advantage** | Colour, mouse and richer meters |

## Typical use

```sh
htop
```
