# broot

> An interactive tree navigator: it opens a directory tree with fuzzy search, previews and actions, and can print the selected path for the shell.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Navigate directories |
| **Relation** | `tree`/`find` |
| **Main advantage** | Interactive navigation with preview |

## Typical use

```sh
broot src/
```
