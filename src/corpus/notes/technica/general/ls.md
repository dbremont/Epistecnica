# ls

> Lists directory entries, with options for long format, hidden files, recursion and sorting; the default view of a filesystem.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Navigate directories |
| **Relation** | `ls` |
| **Main advantage** | The portable listing |

## Typical use

```sh
ls -lah
```
