# diff

> Compares two files line by line and reports the edits that would turn one into the other, in normal, unified or context format.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Compare |
| **Relation** | `diff` |
| **Main advantage** | The standard line differ |

## Typical use

```sh
diff -u old.md new.md
```
