# dnf

> The package manager of Fedora and the RHEL family, with dependency resolution and transaction history.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Package management |
| **Relation** | `apt` |
| **Main advantage** | RPM-family package management |

## Typical use

```sh
sudo dnf install ripgrep
```
