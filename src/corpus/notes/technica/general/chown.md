# chown

> Changes the owner and group of a file or directory; on most systems only a privileged user can give ownership away.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Permissions |
| **Relation** | `chown` |
| **Main advantage** | The ownership interface |

## Typical use

```sh
chown www-data:www-data file.txt
```
