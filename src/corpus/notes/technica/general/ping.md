# ping

> Sends ICMP echo requests and reports the replies and round-trip times — the first test of reachability.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Network inspection |
| **Relation** | `ping` |
| **Main advantage** | Reachability and latency |

## Typical use

```sh
ping -c 4 example.com
```
