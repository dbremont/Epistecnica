# eza

> A modern replacement for `ls`: colourised long format, Git status per file, icons and tree view, built on the same model of directory listing.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Navigate directories |
| **Relation** | `ls` |
| **Main advantage** | Better output and Git integration |

## Typical use

```sh
eza -lah --git
```
