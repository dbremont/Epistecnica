# zip

> Creates and updates ZIP archives, a cross-platform format that stores multiple files with random access — the archive to hand to another operating system.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Archive/compress |
| **Relation** | `zip` |
| **Main advantage** | Cross-platform archive format |

## Typical use

```sh
zip -r archive.zip src/
```
