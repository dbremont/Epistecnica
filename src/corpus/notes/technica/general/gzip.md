# gzip

> Compresses a single stream or file with the DEFLATE algorithm; the `.gz` suffix and the decompression tool of the same name.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Archive/compress |
| **Relation** | `gzip` |
| **Main advantage** | The portable stream compressor |

## Typical use

```sh
gzip -k notes.md
```
