# delta

> A syntax-highlighting pager for diffs and Git output: it renders the same patch as `diff` with colour, line numbers and side-by-side views.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Compare |
| **Relation** | `diff` |
| **Main advantage** | Readable, highlighted diff output |

## Typical use

```sh
git diff | delta
```
