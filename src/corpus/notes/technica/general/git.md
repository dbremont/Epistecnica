# git

> The distributed version-control system: it records snapshots of a tree, branches and merges them, and moves commits between repositories.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Version control |
| **Relation** | `git` |
| **Main advantage** | Distributed history and branching |

## Typical use

```sh
git status --short
```
