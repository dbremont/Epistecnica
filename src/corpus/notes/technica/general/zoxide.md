# zoxide

> A smarter `cd` that records visited directories and jumps to the best match by frecency (`z project`), so navigation replaces typing paths.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Navigate directories |
| **Relation** | `cd` |
| **Main advantage** | Frecency-based jumping |

## Typical use

```sh
z corpus
```
