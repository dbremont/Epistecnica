# plocate

> A faster `locate`: it compresses the index and answers queries from it in a fraction of the time, while keeping the same command-line interface.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Find files |
| **Relation** | `locate` |
| **Main advantage** | Much faster index lookup |

## Typical use

```sh
plocate nginx.conf
```
