# procs

> A modern `ps`: colourised, sorted, with searchable columns and tree view, and a configurable default output.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Process management |
| **Relation** | `ps` |
| **Main advantage** | Better formatting and filtering |

## Typical use

```sh
procs --sortd cpu | head
```
