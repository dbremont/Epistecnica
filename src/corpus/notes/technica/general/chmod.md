# chmod

> Changes the permission bits of a file or directory — read, write and execute for owner, group and others, or an ACL where supported.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Permissions |
| **Relation** | `chmod` |
| **Main advantage** | The permission-bit interface |

## Typical use

```sh
chmod 644 file.txt
```
