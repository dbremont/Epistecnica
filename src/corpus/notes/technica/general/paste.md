# paste

> Merges files side by side, line by line, optionally with a delimiter — the complement of `cut` for assembling columns.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Join datasets |
| **Relation** | `paste` |
| **Main advantage** | Side-by-side column assembly |

## Typical use

```sh
paste names.txt scores.txt
```
