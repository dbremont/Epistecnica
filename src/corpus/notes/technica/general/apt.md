# apt

> The package manager of Debian and its derivatives: it resolves dependencies, downloads and installs, upgrades and removes packages.

## In the toolchain

| | |
| --- | --- |
| **Abstract task** | Package management |
| **Relation** | `apt` |
| **Main advantage** | Debian-family package management |

## Typical use

```sh
sudo apt install ripgrep
```
