# Cooperative Concurrency


> **Cooperative Concurrency**: In cooperative concurrency models, the control is explicitly yielded or voluntarily shared among concurrent entities. Each entity must cooperate by explicitly yielding control to others to allow them to execute. This model requires explicit coordination but can provide finer-grained control over concurrency.
