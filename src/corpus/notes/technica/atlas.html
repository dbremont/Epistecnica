Technical Element Forest

The decomposition of the technica corpus — every row of every | Instance Tree Path | Description | table merged into one instance tree, read off the notes and never off the file layout, rendered from atlas.json. Paths split on →: backticked segments are type groupings, plain segments are instances typed by their nearest grouping. Types are named by the canonical guide Philosophia Artium Technicarum et Operis; each node lists the notes whose tables decompose it. This is the forest; the technical-object taxonomy is the classification object domain → kind → class → object over the same corpus.

Data: atlas.json — Technical Element Forest, generated from the decomposition tables of the technica notes (14,536 nodes); never hand-edited, so the store is rebuilt after any table edit and validated by the atlas check. The selected node lives in the URL fragment (#Technical Element → …), so a reload reopens it.
