# 18.409 Algorithmic Aspects of Machine Learning

> The course organized around the algorithmic issues that arise in machine learning: modern systems are often built on algorithms without provable guarantees, so the class designs algorithms whose performance can be rigorously analyzed for fundamental machine learning problems.

**MIT OpenCourseWare** — Spring 2015, graduate (Mathematics), Prof. Ankur Moitra.
