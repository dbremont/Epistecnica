### Core Abstractions

> Here’s a table summarizing the main abstractions of Jupyter:
> 

| **Abstraction** | **Description** | **Functionality** | **Example** |
| --- | --- | --- | --- |
| **Notebook** | A document containing code, text, visualizations, and outputs, saved as a `.ipynb` file. | Combines executable code, markdown, and output. | A notebook with Python code to generate a plot and markdown explaining the results. |
| **Cell** | The building blocks of a notebook, containing either code, markdown, or raw text. | Executes code, displays markdown or raw text. | A code cell for running Python, a markdown cell for documentation. |
| **Kernel** | The computational engine that runs the code in the notebook. | Executes code interactively; can be in Python, R, Julia, etc. | IPython kernel for Python, IRkernel for R. |
| **Client** | The frontend interface where users edit and run notebooks. | Sends code to the kernel, displays outputs and allows interaction. | Jupyter Notebook app in the web browser. |
| **Widget** | Interactive UI elements within notebooks (sliders, buttons, etc.). | Allows dynamic interaction with visualizations and functions. | A slider that adjusts the parameter of a function and updates the output plot. |
| **Output** | Results of running a code cell, such as text, plots, or multimedia. | Displays results of code execution inline in the notebook. | A plot generated by `matplotlib` displayed below a code cell. |
| **Notebook Server** | The backend server managing notebook execution, file handling, and kernel communication. | Handles notebook file management and communicates between the kernel and client. | Running `jupyter notebook` launches the server and browser interface. |
| **Dashboard** | The interface for managing notebooks and files in the Jupyter environment. | Allows users to create, open, and manage notebook files. | The Jupyter dashboard lists available notebooks and allows users to open them. |
| **Extensions** | Plugins that enhance notebook functionality with additional features. | Adds capabilities such as spell check, table of contents, or code formatting. | `nbextensions` for additional notebook features like collapsible headings. |
| **Document Format** | Jupyter notebooks are saved as `.ipynb` files, which use a JSON structure to store cells, output, and metadata. | Notebooks can be shared and converted to other formats such as HTML or PDF. | Sharing `.ipynb` notebooks via GitHub or email, or converting them to HTML. |
| **Magics** | Special commands within Jupyter (prefixed with `%` or `%%`) that perform various tasks. | Extends normal syntax for actions like timing code, system commands, or running scripts in different languages. | `%time` for measuring execution time of code, `%%writefile` for writing cell content to a file. |
| **Metadata** | Information stored in notebooks that adds context, such as execution time, tags, or author. | Helps with notebook organization and management, enabling tagging or annotating cells and notebooks. | Notebook metadata could include tags for categorizing cells, or time and date of last execution. |
