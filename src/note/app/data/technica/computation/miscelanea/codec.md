# Codec


> A **codec** is a device or software that **encodes and decodes** digital data, typically for the purposes of **compression, transmission, and playback** of media such as audio or video.
> 

### 🎥 **What Does a Codec Do?**

- **Encoding**: Converts raw data (e.g., uncompressed video) into a compressed format to **reduce file size** or make it suitable for streaming.
- **Decoding**: Reverses the process to convert the compressed format back into something **viewable or audible**.
