# Plugin


> 

| Capability | Plugin | Why |
| --- | --- | --- |
| **File tree** | `nvim-tree.lua` | Navigate project structure |
| **File/text search** | `telescope.nvim` | Find files, symbols, text |
| **LSP** | `nvim-lspconfig` | Diagnostics, definitions, references, hover |
| **Completion** | `nvim-cmp` | Code completion |
| **Debugging** | `nvim-dap` | Breakpoints, stepping, variables |
| **Syntax parsing** | `nvim-treesitter` | Structural syntax highlighting/selection |
| **Git** | `gitsigns.nvim` | Git changes directly in buffers |
| **Formatting** | `conform.nvim` | Run formatters |
| **Linting** | `nvim-lint` | Run external linters |
| **Terminal** | `toggleterm.nvim` | Integrated terminal |
