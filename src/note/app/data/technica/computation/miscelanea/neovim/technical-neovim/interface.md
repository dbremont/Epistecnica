# Interface


> In this section of the notes - we will dig deeper into the idea of the Interface —  that is  how to interact with neovim,  user interface, etc.
> 

## What is the structure of Neovim’s **visual interaction** surface?

| Category | Element | Description | Interaction Characterization |
| --- | --- | --- | --- |
| **Workspace** | Tabpage | Represents a workspace containing one or more windows | Switch, create, close, reorder |
| **Workspace** | Window | Viewport onto a buffer | Focus, split, resize, move, close |
| **Content** | Buffer view | Rendered representation of the current buffer | Navigate, select, edit |
| **Content** | Cursor | Indicates the current editing position | Move, select, operate |
| **Content** | Line numbers | Displays line coordinates alongside buffer content | Read, navigate |
| **Content** | Sign column | Displays signs such as diagnostics, breakpoints, Git markers | Read, act through associated commands |
| **Content** | Fold column | Displays fold state and fold markers | Open, close, navigate folds |
| **Content** | Virtual text | Text rendered alongside or within buffer content without modifying the buffer | Read, inspect, contextual interaction |
| **Content** | Conceal | Visually replaces or hides selected buffer text | Read; underlying text remains editable |
| **Structural** | Window separator | Visual boundary between adjacent windows | Identifies spatial boundaries; resize interaction |
| **Structural** | Statusline | Displays state and metadata for the current window/buffer | Read; can contain interactive components |
| **Structural** | Tabline | Displays tabs/tabpages and their state | Select, create, close, reorder |
| **Command** | Command line | Interface for entering Ex commands, searches, and other input | Type, execute, cancel |
| **Command** | Command-line completion | Displays possible completions for command-line input | Navigate, select |
| **Feedback** | Message area | Displays informational messages, errors, command output, and feedback | Read, dismiss, respond |
| **Feedback** | Diagnostics | Visual representation of errors, warnings, hints, and information | Inspect, navigate, act |
| **Feedback** | Highlighting | Visual encoding of syntax, search matches, selections, states, etc. | Perceptual; communicates semantic state |
| **Transient UI** | Popup menu | Temporary menu displaying completion or selection candidates | Navigate, select, dismiss |
| **Transient UI** | Floating window | Temporarily overlaid window independent of normal window layout | Inspect, interact, dismiss |
| **Transient UI** | Notification | Temporary visual feedback generated by Neovim or plugins | Read, dismiss |
| **Transient UI** | Hover/documentation popup | Contextual information displayed near the cursor | Inspect, dismiss |
| **Selection** | Visual selection | Highlighted range representing the current selection | Extend, modify, operate on |
| **Search** | Search highlighting | Visual indication of search matches | Navigate matches, inspect |
| **Interaction state** | Mode indicator | Visual indication of modes such as Normal, Insert, Visual, or Command-line | Read current interaction state |
| **Interaction state** | Cursorline/cursorcolumn | Visual emphasis of the cursor's row/column | Perceptual orientation |
| **Interaction state** | Focus state | Visual indication of which window or UI element currently receives input | Determines interaction target |
| **Input** | Keymap | Maps input events to commands/actions | Trigger, invoke |
| **Input** | Mouse mapping | Maps mouse events to commands/actions | Click, drag, scroll |
| **Input** | Command-line | Textual command input mechanism | Type, execute |

## **Is there a way to see all of the key bindings?**

> `:map` — lists **key mappings** currently defined by the user or plugins.
> 

> `:help normal-index` / `:help visual-index` — lists the **built-in key commands**.
> 

```
:map          → mappings
:nmap         → Normal-mode mappings
:vmap         → Visual-mode mappings
:verbose map  → mappings + where they were defined
```

## Is there a way to list all of the command accepted?

- **Built-in Ex commands:** `:help ex-cmd-index`
- **User/plugin-defined commands:** `:command`

## Which are the interaction modes?

> Neovim has several **interaction modes**, each defining how keyboard input is interpreted:
> 

| Interaction Mode | Entered With | Primary Purpose | Input Interpretation |
| --- | --- | --- | --- |
| **Normal** | `Esc`, `Ctrl-[` | Navigation, commands, operators | Keys are interpreted as editor commands |
| **Insert** | `i`, `a`, `o`, etc. | Insert and edit text | Keys insert characters |
| **Visual** | `v`, `V`, `Ctrl-v` | Select and operate on text | Keys operate on the selection |
| **Select** | `gh`, `gH`, `g<C-H>` | Select text in a more selection-oriented way | Typed text replaces the selection |
| **Command-line** | `:`, `/`, `?` | Enter Ex commands and searches | Keys build a command-line expression |
| **Terminal** | `i` from a terminal buffer | Interact with a terminal process | Keys are sent to the terminal |
