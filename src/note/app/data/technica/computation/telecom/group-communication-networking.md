# Group Communication (Networking)


> Broadcast and Multicast Algorithm
> 

> Efficiently deliver data to multiple recipients.
> 

## Methods

- **Flooding**:
    - Sends data to all nodes in the network.
- **Spanning Tree-Based Multicast**:
    - Uses a tree structure to minimize redundant transmissions.
- **Gossip Protocols**:
    - Distributes data through randomized communication.
