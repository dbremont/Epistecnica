# Congestion Control


> Manage network traffic to prevent congestion and ensure fair resource allocation.
> 

## **Methods**

- **TCP Congestion Control**:
    - Examples: TCP Reno, TCP Cubic.
    - Uses mechanisms like slow start, congestion avoidance, and fast retransmit.
- **AQM (Active Queue Management)**:
    - Example: RED (Random Early Detection).
    - Drops packets probabilistically to signal congestion before queues overflow.
- **Rate-Based Algorithms**:
    - Example: TFRC (TCP-Friendly Rate Control).
    - Adjusts sending rates to be fair to TCP flows.
