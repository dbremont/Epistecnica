# TURN (Traversal Using Relays around NAT)

- [STUN (Session Traversal Utilities for NAT)](note.html?n=technica/computation/telecom/stun-session-traversal-utilities-for-nat.md), [Interactive Connectivity Establishment (ICE)](note.html?n=technica/computation/telecom/interactive-connectivity-establishment-ice.md)

> If STUN is unable to establish a direct connection because the router or other mechanisms block incoming traffic, TURN serves as a fallback. In this case, the client initiates the connection to the TURN server and keeps it open, creating a bidirectional communication channel.
