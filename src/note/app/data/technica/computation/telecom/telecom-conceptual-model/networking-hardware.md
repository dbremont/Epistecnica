# Networking Hardware

- [Antenna](note.html?n=technica/computation/telecom/telecom-conceptual-model/antenna.md)

> 

| **Category** | **Device** | **Function** |
| --- | --- | --- |
| **Core Networking** | Router | Connects different networks, manages traffic, assigns IPs (DHCP), and provides NAT. |
|  | Switch | Connects devices within a network, forwarding packets based on MAC addresses. |
|  | Hub | Basic multiport repeater that broadcasts data to all connected devices. |
|  | Bridge | Connects two network segments and filters traffic based on MAC addresses. |
| **Security & Control** | Firewall | Monitors and controls incoming/outgoing network traffic based on security rules. |
|  | Proxy Server | Acts as an intermediary for requests, enhancing security and caching. |
| **Wireless & Edge** | Wireless Access Point (AP) | Provides Wi-Fi connectivity, extending wired networks wirelessly. |
|  | Range Extender | Boosts Wi-Fi signal to cover larger areas. |
|  | Modem | Converts digital data into signals for transmission over telephone or cable lines. |
| **Specialized Networking** | Load Balancer | Distributes traffic across multiple servers to improve performance and reliability. |
|  | Network Interface Card (NIC) | Allows devices to connect to a network via Ethernet or Wi-Fi. |
|  | Gateway | Connects networks using different communication protocols. |
|  | VPN Concentrator | Manages multiple VPN connections for secure remote access. |
