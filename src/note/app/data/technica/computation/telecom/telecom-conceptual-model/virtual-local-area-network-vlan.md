# Virtual Local Area Network (VLAN)


> A **Virtual Local Area Network (VLAN)** is a logical subdivision of a physical network that groups together devices on separate physical **LANs** into a single broadcast domain, enabling improved network management, security, and traffic isolation while allowing devices to communicate as if they were on the same local network regardless of their physical location.
