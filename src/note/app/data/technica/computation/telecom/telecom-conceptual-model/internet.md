# Internet

- [World Wide Web (WWW)](note.html?n=technica/computation/telecom/telecom-conceptual-model/world-wide-web-www.md)

> The **Internet** is a **global network of interconnected computer networks** that communicate using standardized protocols (mainly **TCP/IP**) to exchange data and provide various services, including the World Wide Web, email, file transfer, and more. Unlike the Web, the Internet is the **infrastructure**, while the Web is a service built on top of it.
> 

## Structure

| **Category** | **Component** | **Description** |
| --- | --- | --- |
| **Core Network** | Backbone Routers & Switches | High-capacity routers and switches connecting major networks across regions. |
| **Transmission Media** | Fiber Optic Cables | High-speed physical links forming the backbone of the Internet. |
|  | Copper Cables / DSL | Traditional wired connections for local access. |
|  | Satellite Links / Wireless | Long-distance or last-mile connectivity where cables are impractical. |
| **Access Network** | ISPs (Internet Service Providers) | Companies providing end users and organizations access to the Internet. |
|  | Local Area Networks (LANs) | Networks within homes, offices, or campuses connecting devices locally. |
|  | Wi-Fi & Cellular Networks | Wireless technologies for local and mobile Internet access. |
| **Routing Infrastructure** | Border Gateway Protocol (BGP) | Protocol that routes traffic between different networks (autonomous systems). |
|  | Domain Name System (DNS) | Translates human-readable domain names into IP addresses. |
| **Data Centers & Servers** | Web Servers, Cloud Servers | Physical or virtual servers storing content, applications, and data. |
| **Security & Management** | Firewalls, Intrusion Detection | Systems ensuring secure and reliable network operation. |
|  | Network Monitoring Tools | Tools to monitor traffic, performance, and detect failures or attacks. |
