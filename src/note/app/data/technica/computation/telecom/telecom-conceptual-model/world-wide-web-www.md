# World Wide Web (WWW)

- [Internet](note.html?n=technica/computation/telecom/telecom-conceptual-model/internet.md)

> The **World Wide Web (WWW)** is a system of interlinked **hypertext documents** and resources, accessed via the **Internet** using a web browser. It allows users to **view, navigate, and interact** with information through **web pages** that can contain text, images, videos, links, and other multimedia.
> 

> The **Internet** is a **global network of interconnected computer networks** that communicate using standardized protocols (mainly **TCP/IP**) to exchange data and provide various services, including the World Wide Web, email, file transfer, and more. Unlike the Web, the Internet is the **infrastructure**, while the Web is a service built on top of it.
> 

## Structure

| **Category** | **Component** | **Description** |
| --- | --- | --- |
| **Client Side** | Web Browser | Software used to access and render web pages (e.g., Chrome, Firefox). |
| **Server Side** | Web Server | Hosts and delivers web content to clients (e.g., Apache, Nginx). |
| **Communication** | Protocols | Rules for data transfer between client and server (HTTP, HTTPS, FTP). |
| **Addressing** | URL | Uniform Resource Locator used to locate resources on the Web. |
| **Navigation** | Hypertext & Hyperlinks | Links connecting web pages, forming the “web” structure. |
| **Content** | Web Content | HTML, CSS, JavaScript, multimedia (text, images, audio, video). |
| **Back-End** | Databases | Store dynamic data and support server-side operations (MySQL, MongoDB). |
| **Discovery** | Search Engines & Indexing | Tools that crawl and index web pages to help users find content. |
