# Routing


> Determine the best path for data to travel from source to destination.
> 

## Method

- **Distance Vector Algorithms**:
    - Example: RIP (Routing Information Protocol).
    - Uses hop count as a metric.
- **Link State Algorithms**:
    - Example: OSPF (Open Shortest Path First).
    - Uses detailed topology information to compute the shortest path.
- **Path Vector Algorithms**:
    - Example: BGP (Border Gateway Protocol).
    - Used for inter-domain routing in the internet.
- **Hybrid Algorithms**:
    - Example: EIGRP (Enhanced Interior Gateway Routing Protocol).
    - Combines features of distance vector and link state algorithms.
