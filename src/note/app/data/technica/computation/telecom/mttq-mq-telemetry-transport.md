# MTTQ: MQ Telemetry Transport


> MQ Telemetry Transport (MTTQ) is a lightweight messaging protocol designed for low-bandwidth, high-latency, and unreliable networks, commonly used in IoT and M2M (machine-to-machine) communication to facilitate efficient and reliable data exchange between devices.
