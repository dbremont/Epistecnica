# Control Plane


> The control plane is responsible for managing the network infrastructure, including network devices such as routers and switches. It is responsible for routing and forwarding decisions, as well as network configuration and management.
> 

**Addressing Scheme:** > An addressing scheme is a system for assigning unique identifiers to network devices or locations, allowing data to be routed between these devices or locations.

Here are some typical **addressing schemes** used in **networking**: **IP addressing**: Internet Protocol (IP) addressing uniquely identifies devices on a network. IP addresses consist of numbers separated by dots, such as “192.168.1.1.” Two versions of IP addressing are currently in use: IPv4 and IPv6.

- **MAC address**: Media Access Control (MAC) addressing is used to identify network interface controllers (NICs) at the hardware level. MAC addresses are unique to each device and are usually assigned by the manufacturer. They consist of hexadecimal digits separated by colons or dashes, such as “00:1A:2B:3C:4D:5E”.
- **URL addressing**: Uniform Resource Locator (URL) addressing is used to identify web pages and online resources. URLs consist of a protocol prefix (such as “http://” or “https://”), a domain name (such as “google.com”), and a path to the resource (such as “/search?q=addressing+scheme”).
- **DNS addressing**: Domain Name System (DNS) addressing is used to translate human-readable domain names (such as “google.com”) into IP addresses that network devices can use. DNS servers maintain a database of domain names and their corresponding IP addresses.
- **VLAN addressing**: Virtual Local Area Network (VLAN) addresses segment a network into multiple virtual networks. VLANs are identified by a VLAN ID inserted into the Ethernet frame header. This allows multiple virtual networks to coexist on a single physical network
