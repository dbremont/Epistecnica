# Resel


> Statistical Concept.
> 

> A **resel** (short for **resolution element**) is a unit of spatial resolution used in the analysis of statistical maps over continuous spaces, particularly in the context of **random field theory** (RFT).
> 

> A **resel** is a **resolution element**, defined as the volume of the space under consideration divided by the **effective smoothing kernel volume**, typically measured in **full width at half maximum (FWHM)** units.
