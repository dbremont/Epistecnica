# d3.js


> **Data-Driven Documents (D3)** is a novel representation-transparent approach to visualization for the web.  Rather than **hide the underlying scenegraph within a toolkit-specific** abstraction, D3 enables **direct inspection and manipulation of a native representation**: the standard document object model (DOM).
> 

> D3.js is a JavaScript library for producing **dynamic**, **interactive** **data documents** in web browsers using **HTML, SVG, and CSS**.
> 

> D3.js primarily utilizes the data join, enter-update-exit pattern, and the transition model to dynamically manipulate the DOM based on data changes, enabling the creation of interactive and animated visualizations.
> 

> **Data-Driven Documents**: A "data-driven document" refers to a digital document whose content and structure are dynamically generated and modified based on underlying data.
> 

> **Declarative model**:  The D3 declarative model enables specifying the desired outcome of data visualizations rather than outlining each step to achieve it, allowing the library to handle the details of DOM manipulation and rendering.
> 

> **Interactive model**: The D3 interaction model enables dynamic and responsive visualizations by allowing user actions, such as clicks, hovers, and drags, to trigger data-driven transformations of the document's content and appearance.
> 

> **Transition model**:  A "transition model" refers to a computational framework that defines how a system evolves over time from one state to another through a series of intermediate steps or animations.
> 

## Tools

> **D3.js** offers a range of abstractions that simplify complex tasks involved in data visualization.
> 

The main abstractions include:

| **Concept** | **Description** |
| --- | --- |
| **Selections** | Abstractions are used to select and manipulate elements in the DOM. |
| **Data Binding** | Mechanisms to bind data to DOM elements, enabling data-driven transformations. |
| **Enter-Update-Exit Pattern** | A paradigm for adding, updating, and removing elements in response to data changes. |
| **Transitions** | Abstractions are used to smoothly interpolate attributes and styles of elements over time. |
| **Scales** | Functions that map data values to visual representation dimensions (like position, length, and color). |
| **Axes** | Utilities to generate axes based on scales, simplifying the addition of readable reference marks. |
| **Shapes** | High-level abstractions for generating geometric shapes, such as lines, areas, and arcs, are suitable for charts. |
| **Layouts** | Algorithms that compute positions and shapes for different visualizations (like pie charts, force-directed graphs, and treemaps). |
| **Path Generators** | Tools for constructing complex SVG paths from valid data in line and area charts. |
| **Behaviors** | Abstractions for interactive features, like drag-and-drop, zooming, and brushing. |
