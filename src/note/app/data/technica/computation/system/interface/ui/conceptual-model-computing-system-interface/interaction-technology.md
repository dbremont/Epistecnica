# Interaction Technology


> 

| **Technology** | **Description** |
| --- | --- |
| **Graphical User Interface (GUI)** | A visual interface that uses graphical elements like windows, icons, and buttons. |
| **Command-Line Interface (CLI)** | A text-based interface where users type commands to interact with the system. |
| **Touch User Interface (TUI)** | A GUI designed for touchscreens, using gestures like taps, swipes, and pinches. |
| **Voice User Interface (VUI)** | An interface that allows users to interact with a system using voice commands. |
| **Gesture-Based Interface** | An interface that uses body movements or gestures for interaction. |
| **Menu-Driven Interface** | An interface where users navigate through a series of menus and options. |
| **Form-Based Interface** | An interface where users fill out forms to input data. |
| **Natural Language Interface (NLI)** | An interface that allows users to interact using natural language. |
| **Augmented Reality (AR) Interface** | An interface that overlays digital information on the real world. |
| **Virtual Reality (VR) Interface** | An interface that immerses users in a fully virtual environment. |
| **Web-Based Interface** | An interface accessed through a web browser. |
| **Mobile Interface** | An interface designed specifically for mobile devices. |
| **Wearable Interface** | An interface designed for wearable devices like smartwatches and fitness trackers. |
| **Tangible User Interface (TUI)** | An interface that uses physical objects for interaction. |
| **Brain-Computer Interface (BCI)** | An interface that allows direct communication between the brain and a computer. |
