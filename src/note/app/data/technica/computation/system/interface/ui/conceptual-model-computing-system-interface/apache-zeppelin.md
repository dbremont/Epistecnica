# Apache Zeppelin


> **Apache Zeppelin** is a **web-based, multi-user, polyglot notebook** that enables **interactive data analytics, visualization, and collaboration** by executing code in various interpreters (e.g., Apache Spark, Flink, JDBC, Python) and supporting **real-time streaming, dynamic data exploration, and custom dashboarding** through an extensible architecture.
