# Voxel


> A **voxel** (short for *volumetric pixel*) is the smallest distinguishable **cuboidal unit** in a **discretized three-dimensional scalar or vector field**, typically represented by a **regular grid element** storing data such as intensity, density, or physical properties at a specific spatial coordinate in ℝ³, and used primarily in **3D image reconstruction**, **volume rendering**, or **computational simulations** (e.g., medical imaging, CFD, or solid modeling).
