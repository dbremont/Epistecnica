# User Persona & Journey Checklist


> 

## 🧍‍♂️ User Persona Checklist

### **Demographics & Background**

- [ ]  Age, gender, and location
- [ ]  Education level
- [ ]  Job title, industry, and seniority
- [ ]  Income range
- [ ]  Cultural context or language preferences

### **Behavioral Traits**

- [ ]  Technology proficiency
- [ ]  Digital habits (devices used, online behaviors)
- [ ]  Preferred communication channels
- [ ]  Brand loyalties (if relevant)
- [ ]  Buying or decision-making habits

### **Goals & Motivations**

- [ ]  Primary goals when interacting with your product
- [ ]  Personal or professional motivations
- [ ]  Long-term aspirations or needs

### **Pain Points & Frustrations**

- [ ]  Frustrations with current solutions
- [ ]  Problems they are trying to solve
- [ ]  Psychological or contextual barriers (e.g., lack of trust, complexity)

### **Needs & Expectations**

- [ ]  Key features or functionalities desired
- [ ]  Desired outcomes or benefits
- [ ]  Expectations regarding ease of use, speed, design, etc.

### **Quote or Summary Statement**

- [ ]  A direct quote that summarizes the user’s mindset
- [ ]  A one-sentence persona description

## 🛣️ User Journey Checklist

### **Define the Scope**

- [ ]  Define the user persona for this journey
- [ ]  Define the goal (e.g., sign up, make a purchase, get support)

### **Journey Phases**

Include these common stages (can vary based on context):

- [ ]  Awareness
- [ ]  Consideration / Evaluation
- [ ]  Conversion / Purchase
- [ ]  Onboarding / Adoption
- [ ]  Retention / Engagement
- [ ]  Advocacy / Feedback

### **Touchpoints & Channels**

- [ ]  Identify key interactions (e.g., website, app, email, support)
- [ ]  Specify the medium/channel for each interaction
- [ ]  Note where the user enters and exits

### **Actions**

- [ ]  Actions taken by the user at each stage
- [ ]  Internal processes triggered by these actions (e.g., CRM updates)

### **Thoughts & Emotions**

- [ ]  What is the user thinking at each step?
- [ ]  What emotions are they likely feeling?

### **Pain Points**

- [ ]  Identify bottlenecks, drop-off points, or friction
- [ ]  Highlight emotional or functional frustrations

### **Opportunities**

- [ ]  Improvements in UX/UI
- [ ]  Points where automation or personalization can help
- [ ]  Content or guidance needed to move forward

### **Metrics & Validation**

- [ ]  KPIs or metrics tied to each stage (e.g., conversion rate, bounce rate)
- [ ]  Qualitative feedback sources (interviews, surveys, support tickets)

## 🧩 Optional Layers for Detail

### A. **Personality Mapping (e.g., MBTI, Big Five)**

- Helps deepen understanding of user decision-making patterns

### B. **Jobs-to-be-Done Framework**

- [ ]  Job: What the user is trying to accomplish
- [ ]  Functional/emotional/social dimensions

### C. **Empathy Map**

- [ ]  What the user thinks, feels, sees, hears, says, and does

### D. **Service Blueprint Add-on**

- [ ]  Backstage processes
- [ ]  Supporting systems or teams
- [ ]  Internal pain points and opportunities
