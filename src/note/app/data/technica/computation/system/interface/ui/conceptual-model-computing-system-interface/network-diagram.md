# Network Diagram


> A **Network Diagram** is a visual representation of nodes (entities) and their connections (relationships), often used to illustrate systems, workflows, or interactions in various domains like computer networks, social networks, or project management.

## Product Space

> The **Product Space graph** is a network representation of industries or products, where nodes represent products, and edges indicate their relatedness based on shared capabilities or co-export patterns, often used to study economic development and diversification.
>
