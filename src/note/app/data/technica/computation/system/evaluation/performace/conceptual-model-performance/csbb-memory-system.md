# CSBB: Memory System


> RAM + Virtual Memory.
> 

## Memory Performance Tools

| **Tool** | **Description** | **Use Cases** |
| --- | --- | --- |
| **free** | Displays the total amount of free and used physical memory. | To monitor memory usage, including swap. |
| **vmstat** | Reports virtual memory statistics. | To report information about processes, memory, paging, block IO, traps, and CPU activity. |
| **meminfo** | Provides detailed memory information (`/proc/meminfo`). | To get a comprehensive view of system memory usage. |
