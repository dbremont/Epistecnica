# Client-Server Architecture


> Divides software into client and server components, where clients request services and servers provide them.
> 

**Characteristics:**

- Clear separation of client and server responsibilities

**Advantages:**

- Centralized control
- Easier server-side updates
- Scalability of server

**Disadvantages:**

- Network dependency
- Server can become a bottleneck
- Managing multiple clients
