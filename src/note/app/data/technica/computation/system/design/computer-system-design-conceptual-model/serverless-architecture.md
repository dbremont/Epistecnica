# Serverless Architecture


> Applications are deployed as functions managed by a cloud provider, automatically scaling with demand.
> 

**Characteristics:**

- Function as a Service (FaaS)
- Automatic scaling

**Advantages:**

- Reduced operational overhead
- Cost efficiency
- Scalability

**Disadvantages:**

- Cold start latency
- Limited execution duration and resources
- Debugging and monitoring complexity
