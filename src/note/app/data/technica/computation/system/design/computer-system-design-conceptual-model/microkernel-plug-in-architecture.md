# Microkernel (Plug-in) Architecture


> A core system with minimal functionality, extended by plug-in modules providing additional features.
> 

**Characteristics:**

- Core system with extensible plug-ins

**Advantages:**

- Flexibility
- Easy to add features
- Isolated functionality

**Disadvantages:**

- Complexity in plug-in management
- Potential performance overhead
