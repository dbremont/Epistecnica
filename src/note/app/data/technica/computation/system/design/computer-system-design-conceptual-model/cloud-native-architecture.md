# Cloud-Native Architecture


> Designed to fully exploit cloud environments, emphasizing scalability, resilience, and automation.
> 

**Characteristics:**

- Designed for cloud deployment
- Uses cloud services and infrastructure

**Advantages:**

- Scalability
- Resilience
- Cost efficiency due to pay-as-you-go models

**Disadvantages:**

- Dependency on cloud provider
- Potential vendor lock-in
- Security and compliance concerns
