# Layered (N-Tier) Architecture


> Software is divided into layers, each with a specific responsibility, typically presentation, business, and data layers.
> 

**Characteristics:**

- Separation of concerns
- Each layer interacts only with adjacent layers

**Advantages:**

- Modularity
- Easier maintenance
- Improved code organization

**Disadvantages:**

- Potential performance overhead
- Hard to manage dependencies across layers
