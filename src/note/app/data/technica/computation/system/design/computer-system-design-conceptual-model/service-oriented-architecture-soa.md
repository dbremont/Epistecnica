# Service-Oriented Architecture (SOA)


> Comprises services that communicate over a network, often using an enterprise service bus (ESB) for integration.
> 

**Characteristics:**

- Reusable services
- Common communication framework

**Advantages:**

- Integration of heterogeneous systems
- Service reusability
- Centralized governance

**Disadvantages:**

- Complexity in ESB management
- Performance bottlenecks
- High initial setup cost
