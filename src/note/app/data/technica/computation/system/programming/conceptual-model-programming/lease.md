# Lease


> In [computer science](https://en.wikipedia.org/wiki/Computer_science), a **Lease**  is a contract that gives its holder specified rights to some resource  for a limited period. Because it is time-limited, a lease is an 
alternative to a [lock](https://en.wikipedia.org/wiki/Lock_(computer_science)) for resource [serialization](https://en.wikipedia.org/wiki/Serialization).
