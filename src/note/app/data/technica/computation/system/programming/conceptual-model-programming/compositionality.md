# Compositionality


> Compositionality—the principle that the meaning (or behavior) of a system is determined by the meaning of its parts and how they are combined—is a **deep, unifying idea** in computer science.
> 

> Note: It underpins everything from programming languages to distributed systems, enabling scalability, modularity, and reasoning.
> 

> The behavior of a composite system is a function of the behavior of its components and their composition rules..
> 

## **Key Properties**

- **Modularity**: Components can be understood in isolation.
- **Hierarchy**: Systems can be built recursively (components of components).
- **Substitutability**: Swapping a component preserves composition rules.
