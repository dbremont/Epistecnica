# Cohesion


## Cohesion

> Assesses the degree to which the elements within a module or component are related and focused on a common purpose.
> 

> Cohesion: Der. del lat. cohaesus, part. pas. de cohaerēre ‘estar adherido’, ‘tener cohesión’. Acción y efecto de reunirse o adherirse las cosas entre sí o la materia de que están formadas.
>
