# Redundancy


> In [engineering](https://en.wikipedia.org/wiki/Engineering) and [systems theory](https://en.wikipedia.org/wiki/Systems_theory), **redundancy** is the intentional duplication of critical components or functions of a system with the goal of increasing reliability of the [system](https://en.wikipedia.org/wiki/System), usually in the form of a backup or [fail-safe](https://en.wikipedia.org/wiki/Fail-safe), or to improve actual system performance, such as in the case of [GNSS](https://en.wikipedia.org/wiki/GNSS) receivers, or [multi-threaded](https://en.wikipedia.org/wiki/Multi-threaded) computer processing.
