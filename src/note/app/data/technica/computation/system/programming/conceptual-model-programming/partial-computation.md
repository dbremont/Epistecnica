# Partial Computation


> **Partial commutation** refers to the situation where two or more operations or events can be executed in a different order without affecting the program's final outcome. In other words, if two events can be reordered without changing the result, they are said to partially commute.
> 

> This is an important concept in **concurrent programming** because it can affect the performance, correctness, and scalability of concurrent programs.
>
