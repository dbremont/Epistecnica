# Technique

- [Indirection](note.html?n=technica/computation/system/programming/conceptual-model-programming/indirection.md), [Circuit Breaker](note.html?n=technica/computation/system/programming/conceptual-model-programming/circuit-breaker.md)

> A **programming technique** is a method, strategy, or approach used by programmers to design, implement, or optimize code in order to solve a problem efficiently, clearly, and correctly.
> 

## Taxonomy

> Which are the fundamental categories on which every technique falls?
> 

> Note: One technique can spans across many categories.
> 

| **Category** | **Description** | **Instance(s)** |
| --- | --- | --- |
| **Design** | Techniques for structuring code and systems to improve clarity, maintainability, and reuse. | Object-oriented design (encapsulation, inheritance, polymorphism), design patterns (Observer, Factory, Singleton), modularization, model-driven engineering, test-driven development |
| **Data** | Techniques for representing, storing, transforming, and accessing data efficiently and effectively. | Data modeling (relational, graph, hierarchical, vector), normalization/denormalization, indexing strategies, caching, serialization/deserialization, ETL pipelines |
| **Algorithmic** | Strategies and methods for solving computational problems. | Divide and conquer, dynamic programming, greedy algorithms, backtracking, recursion, graph algorithms (BFS, DFS, Dijkstra), sorting/searching algorithms |
| **Control** | Techniques managing execution flow and decision-making. | Structured programming (loops, conditionals, function calls), recursion, event-driven programming (callbacks, reactive programming), exception handling, state machines |
| **Organization** | Methods for arranging components, responsibilities, and interactions in a program or system. | Layered architecture, n-tier design, package/module management, service-oriented architecture, microservices, component-based design, dependency injection, inversion of control |
| **Concurrency** | Techniques enabling multiple computations to occur simultaneously or asynchronously. | Multi-threading, multi-processing, async/await, promises, actor model, message passing, GPU / SIMD programming, locks, semaphores, monitors |
| **Performance** | Techniques focused on improving execution efficiency, reducing latency, or optimizing resource use. | Profiling, loop unrolling, lazy evaluation, memory pooling, caching, vectorization, algorithmic optimization, just-in-time (JIT) compilation |
| **Security** | Techniques ensuring correctness, confidentiality, integrity, and robustness against attacks. | Input validation, sandboxing, privilege separation, cryptography, secure coding practices, access control, code signing, SQL injection prevention |
| **Metaprogramming** | Techniques that allow programs to inspect, generate, or modify code dynamically. | Reflection, macros, code generation, templates, dynamic typing, serialization-based code manipulation, aspect-oriented programming |
