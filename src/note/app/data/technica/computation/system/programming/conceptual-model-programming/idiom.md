# Idiom


> Since large programs grow from smaller ones, it is crucial that we develop an arsenal of standard program structures of whose correctness we have become sure - we can call them idioms.
> 

> A programming principle is a fundamental guideline or concept that serves as a best practice for writing high-quality, efficient, maintainable, and scalable computer programs.
> 

> **Program Idiom**: Standard way to perform a task in a given programing language.
>
