# Computer Decision Support System


> A **decision support system** is a computerized tool or software application designed to assist individuals or organizations in making informed decisions by providing relevant information, analysis, and modeling capabilities.
> 

April 27, 2024 Refactor Computer Decision Support System

**Structure**: - `R: S -> R(S)` - Model Interpretation (Context) (E.G Meaning of A Specific State of a Table) - List of Analysis Tools - Collaboration Tools - …

Strategies:

- Data Histories / Notebooks / [Evidence](https://evidence.dev/)
- Dashboards
- **Model-Driven DSS:** This approach uses mathematical models and simulations to analyze data and support decision-making. It’s particularly useful for complex, quantitative decision problems.
- **Data-Driven DSS:** Data-driven DSS focuses on collecting, storing, and analyzing large volumes of data to generate insights for decision-makers. Techniques like data mining and machine learning are often employed.
- **Cognitive DSS:** Cognitive DSS leverage cognitive computing and natural language processing to understand and respond to user queries and provide more interactive decision support.
- **Collaborative DSS:** Collaborative DSS facilitates group decision-making by allowing multiple users to collaborate, share information, and discuss alternatives in a shared digital environment.

## Tools

**Data Visualization Systems** are software tools or platforms that allow users to create, customize, and interact with visual representations of data. These systems help in gaining insights from data and presenting it in a more understandable and meaningful way. Here is a list of some popular data visualization systems:

1. **Apache Superset**: …
2. **Metabase:** Metabase is an open-source business intelligence and data visualization tool that allows users to create interactive dashboards, run ad-hoc queries, and explore data using a user-friendly interface.
3. **Tableau:** Tableau is a widely used data visualization and business intelligence platform that offers a range of tools for creating interactive and shareable dashboards, reports, and charts.
4. **Power BI:** Microsoft Power BI is a business analytics service that provides tools for data visualization, business intelligence, and data exploration. It is commonly used for creating reports and dashboards.
5. **QlikView/Qlik Sense:** QlikView and Qlik Sense are data visualization and business intelligence platforms that offer interactive visualizations, data exploration, and dashboard creation capabilities.
6. **Looker:** Looker is a data exploration and business intelligence platform that allows users to build and share interactive reports and dashboards. It is known for its strong data modeling capabilities.
7. **Domo:** Domo is a cloud-based business intelligence and data visualization platform that enables users to create real-time dashboards and reports, as well as perform data analysis.
8. **Sisense:** Sisense is a business intelligence and analytics platform that offers data visualization, dashboard creation, and data preparation tools for organizations of all sizes.
9. **Periscope Data:** Periscope Data (now known as Sisense for Cloud Data Teams) is a data analytics and visualization platform that helps data professionals create interactive dashboards and perform SQL-based analysis.
10. **Google Data Studio:** Google Data Studio is a free data visualization tool that integrates with various Google services and allows users to create customizable reports and dashboards.
11. **Plotly:** Plotly is a Python-based data visualization library that provides interactive charts and graphs for data analysis. It is often used in conjunction with programming languages like Python and R.
12. **Grafana:** Grafana is an open-source platform for monitoring and observability that also supports data visualization and dashboard creation for various data sources.
13. **Redash:** Redash is an open-source data visualization and dashboarding tool that allows users to connect to different data sources, create queries, and build interactive dashboards.
14. **IBM Cognos Analytics:** IBM Cognos Analytics is a business intelligence and data visualization platform that offers reporting, dashboarding, and data exploration features for enterprise users.
15. **Yellowfin BI:** Yellowfin BI is a business intelligence and data analytics platform that provides tools for data visualization, reporting, and collaboration.
16. **MicroStrategy:** MicroStrategy is a business intelligence platform that includes data visualization capabilities, reporting, and analytics for enterprises.

These data visualization systems vary in terms of features, complexity, pricing, and integration capabilities, so organizations should carefully evaluate their specific needs and requirements when choosing a data visualization tool.
