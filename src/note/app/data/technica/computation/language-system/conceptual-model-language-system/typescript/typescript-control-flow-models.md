# Typescript: Control Flow Models

> **Control Flow Model** is a **representation** of the **sequence** and order in which statements or instructions are executed in a program. It describes how the program’s control flows from one statement to the next, based on conditions, loops, and other control structures.
> 

List of Models:

- **Sequential Control Flow Model**: This is the default control flow model, in which statements are executed in the order they are written in the code.
- **Conditional Control Flow Model**: Using if/else and match statements to make decisions based on certain conditions.
- **Iterative Control Flow Model**: Using loops like for and while to execute code repeatedly.
- **Switch Control Flow Model**: Using match statements to compare values against multiple patterns and execute the corresponding code.
- **Exception Handling Control Flow Model**: Using the Result and Option types to handle errors and unexpected situations.
- **Thread Control Flow Model**: Using threads to execute code concurrently and coordinate between them.
- **Coroutines Control Flow Model**: Write asynchronous code using async/await syntax to suspend and resume execution.
- **Data-Driven Control Flow Model**: Using event-driven programming and message passing to execute code in response to external events.
