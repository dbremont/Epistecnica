# Imperative Model of Computation

- [State Machine](note.html?n=technica/computation/language-system/conceptual-model-language-system/state-machine.md), [Turing Machine](note.html?n=technica/computation/language-system/conceptual-model-language-system/turing-machine.md)

> The **Imperative Model of Computation** is a programming paradigm where computations are expressed as a sequence of explicit instructions that change the state of the program’s variables and memory.
> 

## Paradigms

> **Structured Programming**: A programming paradigm that uses control structures like loops (for, while) and conditionals (if, else) to organize code into well-defined blocks or modules, promoting clear code organization and reducing complexity.
> 

> **Procedural Programming**: A programming paradigm centered around procedures or functions, which are reusable blocks of code that can be called from different parts of the program, allowing for modularity and code reusability.
> 

> **Object-Oriented Programming (OOP)**: A programming paradigm that organizes data and behavior into objects, where objects represent real-world entities and interact through methods and message passing. OOP emphasizes encapsulation, inheritance, and polymorphism.
>
