# Algebraic Effect

- [Effect System](note.html?n=technica/computation/language-system/conceptual-model-language-system/effect-system.md)

> Algebraic effects provide a way to describe and manipulate **computational effects** in a modular and compositional manner. They offer a more flexible approach compared to monads, allowing for dynamic modification of effect handling.
> 

> Algebraic effects are a structured way to represent and **handle computational effects**, such as state, exceptions, or I/O, by defining operations abstractly and providing handlers that specify their behavior.
> 

> One **abstraction** to rule them all; a generalization of many **computational effect abstractions**.
>
