# State Machine

- [Imperative Model of Computation](note.html?n=technica/computation/language-system/conceptual-model-language-system/imperative-model-of-computation.md)

> The State Machine Model of Computation is a theoretical framework where computation is represented as a series of states and transitions, with the machine moving from one state to another based on input and defined rules.
> 

**¿What computations does the model help us to encode?**

The model helps us encode computations that involve sequences of steps or actions, where the current state determines the machine's future behavior.

**¿What is the abstract machine?**

The abstract machine in the State Machine Model is a computational device that can exist in a finite set of states and transitions between states based on input and predefined rules.

**¿How to encode computations?**

Computations in the State Machine Model are encoded by specifying the set of states, the initial state, the input alphabet, the transition rules that define how the machine moves from one state to another based on input, and the final (accepting) states, which determine when the computation ends. This model is instrumental in designing systems with well-defined sequential behaviors, such as protocol specifications, language recognition, and control systems.
