# Cascading Style Sheets (CSS)


## Layout Models

Here’s a table summarizing the different CSS display models and their characteristics:

| **Display Model** | **Description** | **Examples** |
| --- | --- | --- |
| **Block** (`display: block;`) | Block-level elements start on a new line and occupy the full width. | `<div>`, `<p>`, `<h1>`, `<header>`, `<footer>`, `<nav>`, `<section>`, `<article>`, `<ul>`, `<ol>`, `<li>`, `<blockquote>`, `<form>` |
| **Inline** (`display: inline;`) | Inline elements do not start on a new line and only take up as much width as necessary. | `<span>`, `<a>`, `<strong>`, `<em>`, `<img>`, `<input>`, `<button>`, `<label>`, `<abbr>`, `<code>`, `<cite>` |
| **Inline-Block** (`display: inline-block;`) | Inline-block elements are similar to inline elements but can have padding, margins, and widths applied. They do not start on a new line. | It is helpful for elements with block-like properties that must sit next to each other. |
| **Flexbox** (`display: flex;`) | A one-dimensional layout model that aligns and distributes elements within a container along a single direction (horizontal or vertical). | Creates a flex container with flex items for powerful alignment and distribution capabilities. |
| **Grid** (`display: grid;`) | A two-dimensional layout model that aligns and distributes elements within a container in rows and columns. | Create a grid container with precise control over rows and columns for complex layouts. |
| **Table** (`display: table;`), Table Row (`display: table-row;`), Table Cell (`display: table-cell;`) | Used to create table-like layouts with elements behaving like table elements (`<table>`, `<tr>`, `<td>`). | Useful for tabular layouts mimicking table behavior. |

### Notes:

- **Block**: Typically used for creating large sections or blocks of content.
- **Inline**: Ideal for small pieces of content that flow within other elements.
- **Inline-Block**: Useful for elements that need to align next to each other but also need block-like features.
- **Flexbox**: Great for one-dimensional layouts where you need to align items in a row or column.
- **Grid**: Perfect for complex, two-dimensional layouts with rows and columns.
- **Table**: Suitable for layouts that need to mimic traditional table structures.
