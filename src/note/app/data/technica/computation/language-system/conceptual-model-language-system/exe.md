# .EXE


> For [Microsoft](https://en.wikipedia.org/wiki/Microsoft) [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [OS/2](https://en.wikipedia.org/wiki/OS/2), and [DOS](https://en.wikipedia.org/wiki/DOS), **.exe** is the [filename extension](https://en.wikipedia.org/wiki/Filename_extension) that denotes a file as being [executable](https://en.wikipedia.org/wiki/Executable) – a [computer program](https://en.wikipedia.org/wiki/Computer_program) – containing an [entry point](https://en.wikipedia.org/wiki/Entry_point).
