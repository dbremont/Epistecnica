# ASM

- [Java Bytecode](note.html?n=technica/computation/language-system/conceptual-model-language-system/java-bytecode.md)

> ASM is a low-level **Java bytecode** manipulation and **analysis framework** that provides direct, fine-grained control over **JVM**  instructions via a visitor-pattern API, enabling high-performance class  generation, transformation, and analysis at the bytecode level.
> 

> 🚨 **ASM Bytecode Compatibility** refers to the ability of a Java class or method's bytecode to be analyzed, modified, or generated by the ASM framework without breaking the expected behavior or structure, ensuring proper interaction with the Java Virtual Machine (JVM).
>
