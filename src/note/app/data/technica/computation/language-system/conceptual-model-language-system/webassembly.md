# WebAssembly


> **WebAssembly** (**Wasm**) defines a [portable](https://en.wikipedia.org/wiki/Software_portability) [binary-code](https://en.wikipedia.org/wiki/Binary_code) format and a corresponding text format for [executable programs](https://en.wikipedia.org/wiki/Executable) as well as [software](https://en.wikipedia.org/wiki/Software) interfaces for facilitating interactions between such programs and their host environment.
