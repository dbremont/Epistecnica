# C#: 🛠️ Tooling & Ecosystem

> How to produce computational systems using the C# Toolbox?
> 

- Library
- Production Technical Object:  Nuget, …

| **Technology** | **Description** | **Use Case** |
| --- | --- | --- |
| **.NET Core** | A cross-platform, open-source framework for building modern, high-performance applications. | Web, mobile, cloud, microservices, IoT, and console apps |
| **ASP.NET Core** | A web framework built on top of .NET Core for building modern web applications and APIs. | Web applications, REST APIs, microservices |
| **Entity Framework Core** | An Object-Relational Mapper (ORM) for .NET Core, used to interact with databases using object-oriented code. | Database interactions and ORM support |
| **WPF (Windows Presentation Foundation)** | A UI framework for building rich desktop applications for Windows. | Desktop applications for Windows |
| **Windows Forms** | A GUI class library for building desktop applications on Windows, offering a classic Win32 UI framework. | Legacy desktop applications |
| **Xamarin** | A cross-platform framework for building mobile applications for Android, iOS, and Windows using C#. | Mobile applications (iOS, Android, Windows) |
| **Blazor** | A web framework for building interactive web UIs using C# instead of JavaScript, running on WebAssembly. | Web applications with C# instead of JavaScript |
| **SignalR** | A library for adding real-time web functionality to apps, enabling bidirectional communication. | Real-time communication (e.g., chat apps, notifications) |
| **.NET MAUI (Multi-platform App UI)** | A cross-platform framework for building native desktop and mobile applications from a single codebase. | Cross-platform mobile and desktop applications |
| **Azure SDK** | A set of tools and libraries for integrating and managing Azure cloud services within .NET applications. | Cloud applications, managing Azure resources |
| **ML.NET** | A machine learning framework for building custom ML models with .NET. | Machine learning models and AI applications |
| **C#** | A modern object-oriented programming language used with .NET for a wide range of application types. | All-purpose programming (web, desktop, mobile, etc.) |
| **NuGet** | A package manager for .NET that enables easy distribution and management of libraries and tools. | Dependency management and package distribution |
| **ASP.NET MVC** | A web application framework that follows the Model-View-Controller pattern, used for building dynamic web apps. | Web apps with MVC architecture |
| **ASP.NET Web API** | A framework for building HTTP-based services that can be consumed by browsers, mobile apps, and other services. | RESTful APIs |
| **Roslyn** | The .NET compiler platform that provides APIs for code analysis, generation, and compilation. | Code analysis, refactoring, and custom tooling |
| **Telerik UI for Blazor** | A collection of UI components for building Blazor-based web applications. | Rich UIs for Blazor apps |
| **Power BI .NET SDK** | SDK for integrating Power BI reports and dashboards into .NET applications. | Business intelligence and analytics in .NET apps |
