## QA

### What naming conventions are typically used for classes in:  source code (.java)  and Bytecode  (.class) files)?"

- The JVM internally uses **fully qualified names** (e.g., `com/example/MyClass` in bytecode).
- The Compiler uses **fully qualified names** (e.g., `com.example.MyClass` in source code).
- JVM Execution also uses  slashes (`/`) - Used in `ClassLoader`, method signatures, etc.
