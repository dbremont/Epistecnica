# Polymorphism

- [Subtyping](note.html?n=technica/computation/language-system/conceptual-model-language-system/subtyping.md)

> **Polymorphism** is the ability to write code that works with values of multiple types, including parametric polymorphism (generics) and subtype polymorphism (inheritance).
> 

> **Monomorphic**: An expression can have only one realization.
> 

> **Polymorphic**: In expression can has multiple realizations / instantiations. E.J. (Virtual Types / Actual Types / Hooks / Puntos de Adaptación /Personalización/Cambios/Modificación/Ajuste/Ikea/Extención/Plug Mechanisms),
> 

> **Polymorphism**: The ability of a program fragment to have multiple types (opposite of monomorphism).
> 

> **Abstract type**: In programming languages, an abstract type is a type in a nominative type system that cannot be instantiated directly; a type that is not abstract – which can be instantiated – is called a concrete type. Every instance of an abstract type is an instance of some concrete subtype. Abstract types are also known as existential types.
