# Disassembler


> 

| **Disassembler** | **Description** | **Language Support** | **Features** |
| --- | --- | --- | --- |
| **Ghidra** | A powerful, open-source reverse engineering tool by NSA. | C, C++, Rust, Go, etc. | Interactive GUI, scripting, decompiler, and plugin support. |
| **Radare2** | An open-source framework for reverse engineering and analyzing binaries. | C, C++, Rust, etc. | Command-line interface, scriptable, supports many architectures, and has a visual mode. |
| **IDA Pro** | A commercial disassembler with extensive analysis features. | C, C++, Java, etc. | Interactive disassembly, decompiler, and plugin support. |
| **objdump** | A part of the GNU Binutils, useful for disassembling ELF files. | C, C++, Assembly | Command-line tool, displays assembly code, and section details. |
| **Binary Ninja** | A commercial reverse engineering platform with a user-friendly interface. | C, C++, Python, etc. | Interactive GUI, scripting capabilities, and advanced analysis. |
| **Hopper** | A commercial disassembler for macOS and Linux. | C, C++, Objective-C, etc. | GUI-based, supports decompilation and scripting. |
| **Capstone** | A lightweight multi-platform, multi-architecture disassembly framework. | C, C++, Python, etc. | API for disassembly, supports multiple architectures, and can be embedded in applications. |
| **Cutter** | A Qt and C++ GUI powered by Radare2 for easy analysis. | C, C++, Rust, etc. | User-friendly interface, debugging features, and script support. |
| **Disassemblers in Debuggers** | Debuggers like GDB (GNU Debugger) can disassemble code during debugging sessions. | C, C++, Assembly | Interactive disassembly during debugging and can inspect memory. |
