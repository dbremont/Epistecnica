# Symbolic Model of  Computation


> A class of **computational models** that focuses on **term-rewriting** rather than evaluation.
> 

**Symbolic Computation**: 

- **Translations**: Sentence $\in$ grammar $G$ $\rightarrow$  Sentence $\in$ grammar $G'$.
- **Solvers**: Find `Solutions` to Problems in Certain Formal System.
- …

## Strategies

> Here's a list of symbolic computation models commonly used in symbolic mathematics and computer algebra systems:
> 

| **Model** | **Description** |
| --- | --- |
| **Term-Rewriting Systems** | Models for transforming and simplifying expressions through systematic rules. |
| **Lambda Calculus** | A formal system for defining, applying, and abstracting functions, foundational for functional programming. |
| **Abstract Syntax Trees (ASTs)** | Tree representations of expressions' syntactic structure, where nodes are operations and leaves are operands. |
| **Algebraic Structures** | Includes groups, rings, fields, and modules used to study mathematical operations and their properties. |
| **Computational Algebraic Geometry** | Uses Gröbner bases and other tools for handling polynomial equations and algebraic varieties. |
| **Automata Theory** | Models computation with finite state machines and automata, useful for pattern recognition and formal languages. |
| **Formal Logic Systems** | Handles logical expressions and proofs, including propositional logic, predicate logic, and proof systems. |
| **Category Theory** | Framework for abstracting mathematical structures and their relationships through categories and functors. |
| **Polynomial Ring Theory** | Focuses on the manipulation of polynomials and polynomial rings, including factorization and interpolation. |
| **Higher-Order Logic** | Extends classical logic to include functions and predicates as first-class objects for theorem proving. |
