# Macro System


> In computer programming, a **macro** (short for **"macro instruction**"; **from Greek μακρο- 'long, large'**) is a rule or pattern that specifies how a certain input should be mapped to a replacement output.
> 

It means: 

1. Substitution system, 
2. Meta-Programing System (manipulating the objects that describe a computation during the computation itself), 
3. Modifying the AST at Compile Time
