# DWARF(Debugging With Arbitrary Record Formats)


> **DWARF(**Debugging With Arbitrary Record Formats**)** is a widely used standardized debugging data format that was initially developed alongside the Executable and Linkable Format (ELF), although it functions independently of object file formats.
> 

How to list the debugging symbols from a file? 

- readelf –symbols `<out>` | grep debug
- readelf –debug-dump `<out>`
