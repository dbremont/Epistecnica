# Monomorphization


> **Monomorphization** is the process of generating specialized copies of generic code for each specific type used, optimizing performance by eliminating abstraction overhead at compile time.
> 

> **Type Erasure**: Whether type information is present at runtime or if it’s erased during compilation (Common in Languages with Generics).
>
