# Annotation

- [Type System](note.html?n=technica/computation/language-system/conceptual-model-language-system/type-system.md)

> Metadata annotations in programming refer to the ability to attach additional information or attributes to various program elements, such as classes, methods, properties, or parameters. These annotations provide additional context and instructions that can be used by compilers, frameworks, or other tools at compile-time or runtime.
