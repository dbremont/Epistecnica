# Glasgow Haskell Compiler (GHC)

- [Haskell](note.html?n=technica/computation/language-system/conceptual-model-language-system/haskell.md)

> The **Glasgow Haskell Compiler (GHC)** is a state-of-the-art, optimizing, multi-phase compiler for the Haskell programming language that transforms high-level, statically-typed, lazy functional code into efficient native machine code or intermediate representations such as Core, STG, and C--, supporting a rich runtime system with garbage collection, concurrency, and foreign function interfaces.
