# S-Expression


> S-Expressions encodes computation(sentences) and data.
> 

**S-Expressions**: S-expressions (symbolic expressions) are a data structure used in Lisp and other programming languages. They are a way of representing nested lists and trees using a simple syntax that consists of parentheses and symbols.

In an **S-Expression**, the outermost pair of parentheses represents a list, with each element of the list being either another list (represented by another pair of parentheses) or an atom (represented by a symbol or a literal value). This allows complex data structures to be represented in a simple, uniform way.

**S-Expressions** are commonly used in Lisp for representing programs and data structures, and they are also used in other languages for various purposes, such as configuration files and network protocols. They are often used in situations where human-readability and ease of manipulation are more important than performance or efficiency.
