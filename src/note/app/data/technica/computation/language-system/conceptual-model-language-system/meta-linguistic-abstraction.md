## Meta-computational Technique

> **Meta-computational techniques** are often **referential by nature**, meaning they involve **self-reference** or **reflection** within a program.
> 

> **Reflection** is a key concept in meta-computational techniques where a program can inspect and modify its own structure, types, and behavior.
> 

> Many meta-computational techniques, especially in **metaprogramming**, involve manipulating or generating code that refers to or operates on itself.
> 
- Techniques for representing and manipulating the flow of control in a program include **continuations (`call/cc`), delimited continuations (`shift/reset`), exception handling (`throw/catch`), coroutines (`yield`), asynchronous programming (`async/await`), backtracking, and non-local jumps (`goto`, `setjmp/longjmp`)**, each enabling different forms of execution control and state management.
- Meta-programming:  **Metaprogramming** refers to writing programs that manipulate other programs (or themselves), often by modifying syntax, generating code, or dynamically changing execution behavior.
