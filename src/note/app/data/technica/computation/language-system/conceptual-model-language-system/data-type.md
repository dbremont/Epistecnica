# Data Type

- [Type System](note.html?n=technica/computation/language-system/conceptual-model-language-system/type-system.md)

> **Active Objects** are objects that encapsulate their own **thread of control**.
> 

> An **Entity** is a distinct, identifiable thing in a system or domain that can be referenced or manipulated.
> 

> A **Data Type** defines the set of **values** an entity can take and the **operations** that can be performed on those values.
> 

## Property

- **Memory Resource** – how and where the entity is stored in memory.
- **Hashcode** – a derived numeric property used for efficient identification or retrieval.
- **Mutability** – whether the entity’s state can be modified after creation.
- **Structured** – whether the entity is composed of other entities (e.g., arrays, objects).
- **Identity** – the unique distinguishable aspect of an entity that separates it from others.
