# Expression Notation


> 

Here’s a table summarizing different types of expression notations:

| **Notation** | **Description** | **Example** | **Common Usage** |
| --- | --- | --- | --- |
| **S-Expression** | Symbolic expressions used to represent nested list structures with a simple, parenthetical syntax. | `(+ 1 (* 2 3))` | Lisp programming language, symbolic computation |
| **M-Expression** | Macro expressions used to define and manipulate macros with a more structured syntax. | `{define x 10}` | Used in Lisp for macro definitions and expansion |
| **Infix Notation** | Operators are placed between operands, common in arithmetic expressions. | `3 + 4 * 5` | Most programming languages for arithmetic expressions |
| **Prefix Notation** | Operators are placed before their operands. | `+ 3 * 4 5` | Used in Lisp for function calls and expressions |
| **Postfix Notation** | Operators are placed after their operands. | `3 4 5 * +` | Used in stack-based calculators and some programming languages |
| **Polish Notation** | A form of prefix notation where operators precede their operands. | `+ 3 * 4 5` | Mathematical notation and some computer algorithms |
| **Reverse Polish Notation (RPN)** | A form of postfix notation where operators follow their operands. | `3 4 5 * +` | Used in calculators and some programming environments |
| **Prefix Tree (Trie)** | A tree-like data structure used for efficient retrieval of strings or prefixes. | Not applicable (tree structure) | Efficient searching, text processing |
