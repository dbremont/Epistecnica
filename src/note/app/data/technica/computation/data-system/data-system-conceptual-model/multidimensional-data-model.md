# Multidimensional Data Model


> A **Multidimensional Data Model** is a data model that organizes data into multiple dimensions (e.g., time, geography, products) and measures, enabling fast and complex queries for analytical and business intelligence purposes.
> 

## Instances

> 
- **OLAP Cube**: Organizes data into multiple dimensions and measures for fast and complex analytical queries.
- **Star Schema**: A schema design where a central fact table is linked to dimension tables, with minimal normalization.
- **Snowflake Schema**: A more normalized version of the star schema, where dimension tables are broken down into additional levels of hierarchy.
