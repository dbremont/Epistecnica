# LSM Tree

- [Data Maps (Index)](note.html?n=technica/computation/data-system/data-system-conceptual-model/data-maps-index.md)

> An **LSM tree**, or Log-Structured Merge-tree, is a data structure used in databases to optimize write performance by sequentially writing entries into a log and periodically merging them into a sorted on-disk structure.
