# Representation Problem:  Barcode Data


> **Domain:**  A barcode or bar code is a method of representing data in a visual, machine-readable form.
> 

## Representations Systems

> ¿How to Build Barcodes?
> 

Barcodes can be represented in various ways, each having its encoding method. Here are some central representations of barcodes:

1. **1D Barcodes (Linear Barcodes):** Represented by parallel lines of varying widths and spacings. For Instance, UPC, EAN, Code 39, Code 128, Codabar, and ITF-14.
2. **2D Barcodes (Matrix Barcodes) are r**epresented by patterns of squares, dots, or other shapes in a two-dimensional arrangement. For instance, use QR Code, Data Matrix, MaxiCode, and PDF417.
3. **Numeric-Only Barcodes: These are r**epresented by numeric characters. Examples include UPC, EAN, Codabar, ITF-14, and Pharmacode.
4. **Alphanumeric Barcodes: These are r**epresented by a combination of letters and numbers. Examples include Code 39, Code 128, and QR Codes.
5. **Binary Barcodes:** Encode binary data, allowing representation of various types of information. Examples include QR Code, Data Matrix, and PDF417.
6. **Stacked Barcodes** consist of multiple rows of linear barcode data stacked on each other. Examples include PDF417, Code 128 (stacked version), and GS1 DataBar Stacked.
7. **Matrix and Array-Based Barcodes:** Use a grid or matrix of cells to represent data. Examples include QR Code, Data Matrix, and MaxiCode.
8. **Variable-Length Barcodes:** Allow for encoding data with varying lengths. Examples include Code 39, Code 128, and QR Code.
9. **Compact Barcodes are d**esigned to represent a large amount of data in a compact space. Examples include the Data Matrix, PDF417, and MaxiCode.
10. **Composite Barcodes:** Combine two or more different symbologies into a single barcode. Examples include GS1 Composite and PDF417 with MicroPDF417.
11. **Datalogic/GS1-128:** Subset of Code 128 used in logistics and supply chain applications.

These are just a selection of barcode types, and many others are designed for specific purposes and industries. The choice of barcode type depends on factors such as data capacity, industry standards, and application requirements.
