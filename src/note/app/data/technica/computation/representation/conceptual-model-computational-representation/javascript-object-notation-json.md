# JavaScript Object Notation (JSON)


> JSON (JavaScript Object Notation) is a data structure used for storing and exchanging data. It is a lightweight format for representing data in a human-readable and machine-readable way. JSON consists of key-value pairs, similar to a dictionary or hash table, and can be used to represent a variety of data types, including strings, numbers, booleans, arrays, and objects. Because it is easy to read and parse, JSON is widely used for data exchange between web servers and web applications, and is also used as a data storage format in NoSQL databases.
