# Compress Universal Representation


> **Domain**:  “Compress Representations” typically refers to the process of reducing the size of data or information representations while retaining essential content and structure to save storage space and improve data transfer efficiency.
> 

## Representations Systems

> **Compression models** aim to reduce data size, often without significant loss of information. These models are used in various applications, including image and video compression, text compression, and more.
> 

Here’s a list of some well-known **compression models** and algorithms:

- **ZIP**: One of the most popular compression formats for creating archives of one or more files.
- **GZIP**: A widely used compression format typically used in Unix-based systems.
- **7z**: A high-compression format with support for strong encryption, capable of creating smaller archives than ZIP.
- **RAR** is a proprietary compression format known for its ability to split archives into multiple parts and apply recovery records.
- **TAR** is a file format that combines multiple files into a single archive. It is often used with other compression formats (e.g., TAR.GZ).
- **BZIP2**: A compression format that provides higher compression ratios than GZIP.
- **LZMA**: A compression format used in 7z files, known for its high compression ratio.
- **Z**: A simple and fast compression format typically used in Unix-based systems.
- **XZ**: A compression format based on LZMA2 with improved performance.
- **LZIP**: A lossless data compressor that uses the LZMA algorithm.
- **LZ4**: A fast compression algorithm suitable for real-time compression.
- **Zstandard (Zstd)**: A compression algorithm focusing on high compression and decompression speeds.
- **LZHAM**: A compression format with a balance between compression ratio and speed.
- **CAB**: A compression format commonly used for Microsoft Windows installation files.
- **StuffIt**: A compression format commonly used on macOS systems.
- **ARC**: An older compression format used in the early days of computing.
- **UHARC**: A high-compression format known for its impressive compression ratios.
- **ARJ**: A compression format with support for multi-volume archives.
- **LHA/LZH**: A compression format often used in older, DOS-based operating systems.
- **ZOO**: A compression format capable of handling multiple files and directories.
