# Representation Problem: Image (Data)


> **Domain**: Images and graphics are represented using various formats like JPEG, PNG, GIF, SVG, etc., which encode color and pixel information.
> 

> **Image Representation Systems** refer to the various ways in which images can be encoded, stored, and processed. These representations are crucial in computer vision, image processing, and graphics.
> 

## **Image Representation Systems**

- **Raster (Bitmap)**: Images are represented as a grid of pixels, where each pixel stores color information. Standard formats include JPEG, PNG, BMP, and TIFF.
- **Vector Graphics are** images represented as a collection of geometric shapes and paths defined by mathematical equations. Examples include formats like SVG and PDF.
- **Color Spaces**: Different color models for representing colors, including RGB (Red, Green, Blue), CMYK (Cyan, Magenta, Yellow, Key/Black), and HSL (Hue, Saturation, Lightness).
- **Grayscale**: Images represented in black and white, with shades of gray, often used for simplicity or to reduce file size.
- **Indexed Color**: Images are represented using a limited palette of colors, with each pixel referring to an index in a color lookup table (CLUT).
- **Histograms** are representations based on the distribution of pixel values in an image, often used for image enhancement and analysis.
- **Binary Images are** images represented as two-color (usually black-and-white) images, where each pixel is either on or off. They are commonly used for thresholding and segmentation.
- **Frequency Domain**: Images represented in terms of their frequency components using techniques like the Fast Fourier Transform (FFT).
- **Wavelet Transform**: A mathematical representation used for multi-resolution analysis of images, often used in image compression.
- **Pyramid Representations**: Hierarchical representations of images with multiple levels of resolution, proper for image scaling and analysis.
- **Run-length encoding (RLE)** is a simple compression technique that represents images as a series of runs of consecutive pixels with the same value.
- **DCT (Discrete Cosine Transform)** is a mathematical transformation used in JPEG compression to represent image data in the frequency domain.
- **SIFT (Scale-Invariant Feature Transform)** is a representation used in computer vision to detect and describe local features in images.
- **Bag of Visual Words**: A representation used in image classification and object recognition, treating images as collections of visual words.
- **Histogram of Oriented Gradients (HOG)**: A feature representation used in object detection and recognition based on gradient orientation.
- **Deep Learning Features**: Features extracted from deep neural networks (e.g., CNNs) trained for image analysis tasks, such as image classification and object detection.
- **PointClouds**: A representation used in 3D imaging and computer graphics, where 3D points in space represent object surfaces or scenes.
- **Polar Coordinates**: A representation that uses radial and angular coordinates instead of Cartesian coordinates, often used in image analysis.
- **Panoramic Images**: Special representations of images stitched together to create a panoramic view, commonly seen in VR and 360-degree photos.
- **HDR (High Dynamic Range)**: Images with a wide range of luminance values capture details in both shadow and highlight areas.
