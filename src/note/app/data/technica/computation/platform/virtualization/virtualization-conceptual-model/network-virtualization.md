# Network Virtualization


> A virtual network is a software-defined network that exists within a physical network infrastructure. It is created by using virtualization technologies, which allow multiple virtual networks to share the same physical network resources. Virtual networks are used to provide a range of benefits, including improved security, flexibility, and scalability.
> 

> Nodes in the overlay network can be thought of as being connected by virtual or logical links, each of which corresponds to a path, perhaps through many physical links, in the underlying network. For example, distributed systems such as peer-to-peer networks and client–server applications are overlay networks because their nodes run on top of the Internet. https://www.wikiwand.com/en/Overlay_network
> 

Here are some common types of virtual networks:

- **Virtual Local Area Networks (VLANs)**: VLANs are used to segment a physical network into multiple logical networks. This allows different groups of users to be isolated from each other and to have their own separate network settings, such as IP address ranges and security policies.
- **Virtual Private Networks (VPNs)**: VPNs are used to provide secure remote access to a private network over the public internet. They use encryption and other security technologies to protect data transmitted over the VPN connection.
- **Virtual Switching**: Virtual switching allows multiple virtual machines (VMs) to share a physical network interface card (NIC). This enables the VMs to communicate with each other and with the outside world as if they were connected to a physical switch.
- **Software-defined networking (SDN)**: SDN is a type of virtual network that uses software to control the flow of network traffic. It separates the network control plane from the data plane, allowing network administrators to manage network policies and configurations centrally.
