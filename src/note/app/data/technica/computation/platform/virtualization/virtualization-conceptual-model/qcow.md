# qcow


> QEMU [Copy On Write](https://en.wikipedia.org/wiki/Copy-on-write)
> 

> The "qcow" (QEMU Copy-On-Write) format is a disk image file format used in virtualization that employs copy-on-write mechanisms to optimize storage efficiency by only allocating space for data as it is written, while initially sharing unchanged data with a base image.
