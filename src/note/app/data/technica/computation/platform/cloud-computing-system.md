# Cloud Computing System

> In a **technical sense**, **cloud computing** is the delivery of computing resources—such as servers, storage, databases, networking, software, and analytics—over a network (typically the Internet) in a **scalable, on-demand, and abstracted manner**, allowing users to access and utilize these resources without managing the underlying physical infrastructure.

## Provider

> A Cloud Provider.
> 

| Provider | Description | Note | Type |
| --- | --- | --- | --- |
| **AWS (Amazon Web Services)** | The largest cloud provider offering a wide range of IaaS, PaaS, and SaaS services, including compute (EC2), storage (S3), databases (RDS), analytics, AI/ML, and serverless computing. | Strong global presence, mature ecosystem, broad service portfolio. | Hyperscaler |
| **Microsoft Azure** | Cloud platform providing compute, storage, networking, AI, and developer tools integrated with Microsoft enterprise software. | Strong integration with Windows Server, Active Directory, and Microsoft 365. | Hyperscaler |
| **Google Cloud Platform (GCP)** | Cloud services focused on compute, storage, big data, AI/ML, and container orchestration (Kubernetes). | Emphasis on data analytics, AI, and open-source technologies. | Hyperscaler |
| **IBM Cloud** | Enterprise-focused cloud with IaaS, PaaS, AI (Watson), and hybrid cloud solutions. | Strength in enterprise systems, mainframes, and hybrid deployments. | Enterprise Cloud |
| **Oracle Cloud** | Cloud offerings focused on databases, enterprise applications, and IaaS/PaaS services. | Optimized for Oracle workloads and enterprise applications. | Enterprise Cloud |
| **Alibaba Cloud** | Leading cloud provider in China offering compute, storage, networking, AI, and big data services. | Strong presence in Asia, growing global footprint. | Hyperscaler (Asia) |
| **DigitalOcean** | Simpler cloud platform focused on developers and SMBs, with easy-to-use VPS, managed databases, and Kubernetes services. | Developer-friendly, simpler pricing, smaller scale than hyperscalers. | Developer Cloud |
| **VMware Cloud** | Hybrid cloud solutions leveraging VMware virtualization technology, enabling on-prem workloads to move to the cloud. | Good for enterprises already using VMware infrastructure. | Hybrid Cloud |
| **Salesforce (Heroku, Mulesoft)** | Cloud-based SaaS and PaaS offerings for CRM, app development, and integration. | Focused on application development and business applications rather than raw infrastructure. | SaaS / PaaS |
| **Lambda Labs** | GPU-focused cloud offering high-performance NVIDIA GPUs for deep learning training and inference. | Simple pricing, popular among AI researchers and startups. | GPU Cloud |
| **RunPod** | On-demand GPU compute for training, inference, and custom container workloads. | Strong community usage, affordable pricing, serverless GPU options. | GPU Cloud |
| **Paperspace** | GPU VMs and notebooks oriented toward deep learning, graphics, and scientific computing. | Accessible UI, Gradient platform for ML workflows. | GPU Cloud |
| **CoreWeave** | Specialized GPU cloud optimized for large-scale AI/ML, VFX, and batch workloads. | Very high GPU availability, optimized clustering. | GPU Cloud |
| **Vast.ai** | Marketplace for renting GPUs from distributed providers. | Often cheaper; variable performance depending on provider. | GPU Marketplace |
| **NIMBIX** | HPC-focused cloud with GPU and FPGA instances for scientific computing and simulation workloads. | Strong in HPC and industrial simulation. | HPC / GPU Cloud |
| **Genesis Cloud** | Affordable GPU servers hosted in Europe for ML workloads. | Focus on predictable pricing and sustainability. | GPU Cloud |
