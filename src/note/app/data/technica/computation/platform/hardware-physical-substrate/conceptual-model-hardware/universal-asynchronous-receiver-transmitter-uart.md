# Universal Asynchronous Receiver-transmitter (UART)


> A **Universal Asynchronous Receiver-Transmitter (UART)** is a **hardware communication module** that converts parallel data into serial form and vice versa, enabling asynchronous, full-duplex data transmission between digital devices using start and stop bits without requiring a shared clock.
