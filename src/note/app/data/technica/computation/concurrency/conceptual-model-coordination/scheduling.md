# Scheduling


> 

**Static Scheduling**:

- Tasks are assigned to resources at compile time.
- Examples: Real-time systems, embedded systems.

**Dynamic Scheduling**:

- Tasks are assigned to resources at runtime.
- Examples: Operating system schedulers, load balancers.

**Distributed Scheduling**:

- Tasks are scheduled across multiple nodes.
- Examples: MapReduce, Kubernetes.
