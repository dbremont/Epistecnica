# Distributed Counter


> A **Distributed Counter** is a fault-tolerant, eventually consistent data structure implemented across multiple nodes in a distributed system, which uses conflict-free replicated data types (CRDTs) or consensus protocols to support concurrent, increment/decrement operations while ensuring convergence without coordination.
