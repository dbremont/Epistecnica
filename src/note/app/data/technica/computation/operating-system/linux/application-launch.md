# Application Launch


> An **application launcher** in Linux is a tool or utility designed to help users quickly find and start applications. It typically provides a user-friendly interface for accessing and managing applications installed on the system. Here are some common types and examples of application launchers:
> 

| **Name** | **Description** | **Type** | **Window Server** |
| --- | --- | --- | --- |
| **GNOME Activities Overview** | Provides a search interface and overview of running applications and open windows. | Graphical Application Menu | Xorg, Wayland |
| **KDE Plasma Kickoff** | A menu that provides access to applications, files, and system settings in KDE Plasma. | Graphical Application Menu | Xorg, Wayland |
| **Plank** | A lightweight dock that provides quick access to frequently used applications. | Graphical Dock | Xorg, Wayland |
| **Docky** | A customizable dock with easy access to applications and system features. | Graphical Dock | Xorg |
| **dmenu** | A dynamic menu for X that allows users to launch applications by typing. | Keyboard-Based Launcher | Xorg |
| **rofi** | A flexible launcher that can be used for applications, window switching, and file search. | Keyboard-Based Launcher | Xorg |
| **Albert** | A fast and customizable launcher with support for various plugins and extensions. | Keyboard-Based Launcher | Xorg, Wayland |
| **launch** | A simple terminal-based launcher for running commands and applications. | Terminal-Based Launcher | Xorg, Wayland |
| **synapse** | A quick application launcher with fuzzy searching capabilities for applications and files. | Terminal-Based Launcher | Xorg |
| **Custom Scripts/Shortcuts** | Custom scripts or `.desktop` files created for launching applications and executing commands. | Custom Launcher | Xorg, Wayland |
