# Hyprland

- [Linux Graphics Stack](note.html?n=technica/computation/operating-system/linux/conceptual-model-linux/linux-graphics-stack.md), [Display Manager](note.html?n=technica/computation/operating-system/linux/conceptual-model-linux/display-manager.md), [Window Manager](note.html?n=technica/computation/operating-system/linux/conceptual-model-linux/window-manager.md), [Wayland](note.html?n=technica/computation/operating-system/linux/conceptual-model-linux/wayland.md), [X Window System (X11 Version)](note.html?n=technica/computation/operating-system/linux/conceptual-model-linux/x-window-system-x11-version.md)

> **Hyprland** is a dynamic, tiling Wayland compositor that focuses on customization and modern, efficient window management.
> 

> A **Wayland compositor** is a system component that manages windows, coordinates rendering, and handles input events in a Wayland-based graphical environment.
>
