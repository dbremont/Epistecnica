# dmesg


> `dmesg` stands for **"display message"** or **"diagnostic message"**.
> 

> It is a command in Unix-like operating systems that prints the kernel ring buffer, which contains system messages related to hardware, drivers, and the kernel itself. It's commonly used for debugging and troubleshooting hardware or boot issues.
>
