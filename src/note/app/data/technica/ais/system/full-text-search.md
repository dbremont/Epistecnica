# Full-Text Search


> **Full-Text Search** is a technique that enables the retrieval of documents by scanning and indexing every word in the text, allowing for fast and accurate matches to search queries.
> 

> **Full-text search is called "full-text"** because it involves searching through the entire content of a document, including all the words, rather than just specific fields or metadata, to find matches for the search query.
>
