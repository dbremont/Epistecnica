# System Prompt

 : Language Modelling (LM) (Language%20Modelling%20(LM)%20ecd681eb6e99416a90313abf6fd23665.md)

The **system prompt** is a special instruction given to an AI model (like me) before a conversation begins. It helps define **how the AI should behave**, what it should **know about the user**, and what **style or tone** it should use.

You can think of it as the AI’s **"starting instructions"** or **context settings**.

### Example Purposes of a System Prompt:

- Telling the AI to behave like a friendly assistant or a formal expert.
- Reminding the AI of things it should know (e.g., “The user is a Linux developer”).
- Setting constraints (e.g., “Do not browse the web” or “Be concise”).
- Informing it of preferences (e.g., “User prefers technical detail”).

### In ChatGPT

In this version, I also maintain a **Model Set Context**, which is similar. It stores things I’ve learned from you in this chat over time (like your interests or goals) to keep responses more relevant.
