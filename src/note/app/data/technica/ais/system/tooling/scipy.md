# Scipy


> SciPy is a Python library that extends NumPy with advanced mathematical functions and algorithms for scientific and technical computing, including optimization, integration, interpolation, and statistical analysis.
> 

## Core Abstractions

> Here's a table summarizing the **core abstractions** in **SciPy**:
> 

| **Abstraction** | **Description** | **Example Usage** |
| --- | --- | --- |
| **`scipy.optimize`** | Provides algorithms for function optimization, root finding, and curve fitting. | `scipy.optimize.minimize`, `scipy.optimize.root` |
| **`scipy.integrate`** | Offers numerical integration and differential equation solvers. | `scipy.integrate.quad`, `scipy.integrate.odeint` |
| **`scipy.interpolate`** | Includes tools for interpolation and smoothing of data. | `scipy.interpolate.interp1d`, `scipy.interpolate.griddata` |
| **`scipy.linalg`** | Provides linear algebra operations, including matrix decompositions and eigenvalue problems. | `scipy.linalg.solve`, `scipy.linalg.eig` |
| **`scipy.fft`** | Contains functions for Fast Fourier Transform (FFT) and related operations. | `scipy.fft.fft`, `scipy.fft.ifft` |
| **`scipy.spatial`** | Includes spatial data structures and algorithms for distance computations, and nearest neighbors. | `scipy.spatial.Delaunay`, `scipy.spatial.cKDTree` |
| **`scipy.stats`** | Provides statistical functions, probability distributions, and statistical tests. | `scipy.stats.norm`, `scipy.stats.ttest_ind` |
| **`scipy.special`** | Includes special mathematical functions, such as Bessel functions and gamma functions. | `scipy.special.gamma`, `scipy.special.jn` |
| **`scipy.ndimage`** | Functions for multidimensional image processing and analysis. | `scipy.ndimage.gaussian_filter`, `scipy.ndimage.zoom` |
