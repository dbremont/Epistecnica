### What is the structure of a MLP?

> **Parameterized function class that implements layered nonlinear transformations over vector spaces.**
> 

Formally: $f(x)=W_L,\sigma(W_{L-1},\sigma(\dots\sigma(W_1 x + b_1)\dots)+b_{L-1})+b_L$

Where:

- $x$: input vector
- $(W_i, b_i)$: learned affine transformations
- $(\sigma)$: nonlinear activation
- $f(x)$: composed hierarchical mapping
