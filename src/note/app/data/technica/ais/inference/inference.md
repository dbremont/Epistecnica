# Inference

> `Technical Mechanism` — the operation of the trained system at inference time: decoding, efficiency, and capacity mechanisms applied to a fixed synthesized model.
> 

- Which inference-time mechanisms operate and optimize a trained system?
- Which efficiency and capacity trade-offs does each mechanism introduce?

## Scope

Quantization, decoding controls, test-time compute, performance, and capacity/attention efficiency mechanisms (MoE, MLA, MTP, DCA).
