# Learning Method

> `General Technique` — the model-class selection and synthesis procedures by which a learner is chosen and fitted, distinct from the architectures it implements.
> 

- Which learning methods can select and fit a model class for a given problem?
- Which assumptions (data regime, loss, structure) does each method require?

## Scope

Classical learners and estimators: classification, clustering, tree-based and ensemble methods, probabilistic and sequence models.
