# Epiphenomenon

> An **epiphenomenon** is a secondary phenomenon that **arises as a consequence of underlying causal processes but does not exert causal influence back on those processes**. Formally, it is **causally dependent but causally inert** with respect to the primary system dynamics that generate it.
