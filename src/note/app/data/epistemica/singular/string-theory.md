# String Theory


> String theory is a family of theories based on the fundamental notion of a one-dimensional extended object — the string — that tries to unify quantum mechanics and general relativity into a single consistent framework of fundamental physics.

## Theory

| **String Theory** | **Description** | **Key Features** |
| --- | --- | --- |
| **Type I** | Contains both open and closed unoriented strings; gauge group $SO(32)$; includes D-branes | 10D, unoriented strings, open + closed |
| **Type IIA** | Closed oriented superstring theory; non-chiral (left-right symmetric) | 10D, oriented, non-chiral |
| **Type IIB** | Closed oriented superstring theory; chiral (left-right asymmetric) | 10D, oriented, chiral |
| **Heterotic SO(32)** | Closed oriented strings; gauge group $SO(32)$; combines 26D bosonic string with 10D superstring | 10D, gauge symmetry $SO(32)$ |
| **Heterotic $E_8 \times E_8$** | Closed oriented strings; gauge group $E_8 \times E_8$; important for phenomenology | 10D, gauge symmetry $E_8 \times E_8$ |
| **Bosonic String Theory** | Only bosons; 26 spacetime dimensions; no fermions or supersymmetry | 26D, unstable tachyons, no supersymmetry |
| **M-Theory** | Proposed 11-dimensional theory unifying all 5 superstring theories | 11D, includes membranes (M2, M5 branes) |
