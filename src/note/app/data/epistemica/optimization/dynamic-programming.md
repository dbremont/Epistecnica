# Dynamic Programming


> Dynamic Programming is a method for solving complex problems by breaking them down into simpler subproblems, storing the results of subproblems (memoization), and using these results to build up the solution to the original problem, thereby avoiding redundant calculations.
> 

> It’s called dynamic programming because, at the time, **'programming'** was a buzzword, and using it in the name likely increased the chances of securing funding.
> 

> The term **"Dynamic Programming"** is somewhat misleading. It doesn’t actually refer to "dynamic" as in real-time or changing processes, nor does it specifically refer to **"programming"** in the sense of writing code. Instead, "dynamic" refers to solving problems that involve decisions over time or stages, and "programming" refers to the process of planning or decision-making in an optimization context.
