# One-Hot Encoding

 : Input Representation (Input%20Representation%20188c0f5171ec80f98609c2fb11567e53.md)

> A combination of one-hot encoding and hashing, used to reduce the dimensionality of categorical variables.
> 

> Machine learning, feature engineering in high-cardinality features
> 

> A sparse representation where each word is represented as a vector with a single high (1) value and the rest low (0).
> 

> "I" -> [1, 0, 0], "love" -> [0, 1, 0], "NLP" -> [0, 0, 1]
>
