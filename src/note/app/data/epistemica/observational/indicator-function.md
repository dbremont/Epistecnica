# Indicator Function


> aka.  C**haracteristic Function.**
> 

> An **indicator function** is a mathematical function that outputs $1$ if a specified condition is true and $0$ if the condition is false, often used to represent membership in a set.
> 

> An **indicator function** $\mathbf{1}_A(x)$ is a function that equals $1$ if $x \in A$ and $0$ if $x \notin A$, effectively "indicating" membership of $x$ in the set $A$.
>
