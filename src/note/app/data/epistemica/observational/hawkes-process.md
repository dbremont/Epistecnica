# Hawkes Process

 : Stochastic Process (Stochastic%20Process%200fecab268ff946668713151fbce73638.md)

> Let’s do  a deep dive into the theory and practice of ‘Hawkes Process’
> 

Guiding questions: 

- What is a **Hawkes process**?
- What kind of epistemic tool is a **Hawkes process**?
    - Extraction of dynamical affirmations — that is, characterizing the system by estimating the values of predefined dynamical properties. - so called latent structural parameters -  that generated a certain dynamical regime.
    - Simulation: ‘Sampling from Trajectory Space’, …
    - A Hawkes process is a **parametric stochastic inference model** that (1) estimates latent feedback-driven structure in event streams, (2) characterizes the resulting dynamical regime, and (3) induces a distribution over trajectories for simulation.
- How is variation—or contingency—supported by the Hawkes process?
- What is the philosophy of probability behind a **Hawkes process**?
- Which set of affirmations about realty does the  **Hawkes process** encodes?
- *What are the affirmations that can be made about a **Hawkes process**?*
- How is the Hawkes process operationalized? What are the downstream epistemic tools that build upon the Hawkes process intensity formulation?
- How can a Hawkes process be used as an intensity-based stochastic model to represent, analyze, and infer the dynamics of a task event stream generated by a variable user population interacting with a server?
