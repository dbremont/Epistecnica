# Random Object

 : Distribution (Distribution%20184c0f5171ec8043be4fd6256478fbaa.md), Random Variable (Random%20Variable%20255c0f5171ec80dc95a8d63345182df0.md), Expected Value (Expected%20Value%20a126776d511e4492b643fb5075e68ef2.md), Variance (Variance%201cfc0f5171ec80f5a7f1c535bbde6e1c.md)

> A Note that explores  a set of **random objects** like variable, vector, matrix, field, etc.
> 

> The idea of a **random object is deeply abstract**: it represents a latent or unrealized value or a stochastic system or experiment, while the probability distribution describes its possible realizations.
> 

> 📝 Terminology: In this note, we will use the unifying abstraction of a random object to refer to random {variable, vector, matrix, field,  etc}.
> 

## Randomness

> **Randomness** has the ontological status of a **non-ontic element** . It is not a constituent of reality itself, but rather a **relational property** that can be attributed either
> 
> 
> (a) to a *system* , relative to a given informational or causal resolution, or
> 
> (b) to a *model of a system* , reflecting limits in knowledge, representation, or predictive power.
> 

## Pattern

> A **pattern** has the ontological status of a **non-ontic element**. It is not an object or substance, but a **structural property** attributed to a given set of observations, data, or states under a particular descriptive or analytical framework.
> 

## Determinism

> **Determinism** has the ontological status of a **non-ontic element**. It is a **property ascribed to a system** relative to a specified state space, dynamical law, and level of description, expressing that future states are uniquely fixed by prior states under those assumptions.
> 

## Random Variable

> See [Distribution](distribution-2.md), [Random Variable](random-variable.md).
> 

> See this ([Why do we have very similar concepts such as probability distributions, laws, and random variables? What value does the idea of a random variable offers?](probability.md) ) for the comparison between a **probability distribution** and  a **random variable**.
> 

> A random variable is a measurable function from a probability space to the **real numbers**, representing a numerical outcome of a random experiment.
> 

## Random Vector

> A random vector is an ordered tuple of random variables, capturing multiple random quantities simultaneously.
> 

## Random Matrix

> A random matrix is a matrix whose entries are random variables, allowing probabilistic analysis of matrix-valued data.
> 

## Random Field

> A random field is a collection of random variables indexed by points in a multidimensional space, generalizing stochastic processes to spatial or spatiotemporal domains.
> 

## **Random Tensor**

> A random tensor is a multidimensional array whose elements are random variables, extending the concepts of random vectors and matrices to higher-order data structures.
> 

## Random Tree

> A random tree is a tree-shaped structure whose nodes and edges are generated according to a probabilistic model, often used to represent hierarchical or branching random phenomena.
> 

## Random Graph

> A random graph is a graph whose structure (nodes and edges) is determined by some random process, often defined by a probability distribution over the set of possible graphs.
> 

## Random Manifold

> A random manifold is a manifold equipped with randomness, typically modeled as a random variable taking values in a space of manifolds or by random perturbations of its geometric structure.
> 

## Random Process

> A random process (or stochastic process) is a **collection of random variables** indexed by time or another parameter, describing the evolution of a system under uncertainty.
> 

> Se more in [**Stochastic Process**](stochastic-process.md).
> 

## Random Function

> A random function = randomness over functions.
> 

## Random Operator

> What is the modelling used of this super complex concept?
> 

> A random operator is a mapping between function spaces (or vector spaces) whose action depends on randomness, often modeled as an operator-valued random element.
> 

> Random Operator: Operator → Probability.
> 

## ❓ QA

### What can we do with a ‘Random Variable,’ or with a numerical representation of a stochastic system?

| **Category** | **Mechanism  (Operation)** | **Use** |
| --- | --- | --- |
| **Transform** | Apply functions $Y = f(X)$ | Convert a random variable into another one to study derived quantities or create new representations. |
| **Summarize** | Compute expectations, moments, variance | Extract meaningful numerical summaries: mean, variance, skewness, kurtosis, etc. |
| **Predict** | Conditional expectation / probability | Estimate likely outcomes given partial information (e.g., ($E[X]$) |
| **Simulate** | Monte Carlo or random sampling | Generate synthetic samples to explore system behavior and approximate complex models. |
| **Compare** | Distribution comparison / hypothesis testing | Measure similarity or test hypotheses between random variables or datasets. |
| **Optimize (Decision)** | Expected utility or risk optimization | Use probabilistic models to make decisions under uncertainty. |
