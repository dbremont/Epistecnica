# Bag of Words (BoW)

 : Input Representation (Input%20Representation%20188c0f5171ec80f98609c2fb11567e53.md)

> A representation where text is converted into a set of words, disregarding grammar and word order but maintaining multiplicity.
> 

> "I love NLP" -> {I: 1, love: 1, NLP: 1}
>
