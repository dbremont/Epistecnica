# Mean

 : Burstiness Index (Burstiness%20Index%20337c0f5171ec807c99d3cb9a5f8fb15b.md), Tendency (Tendency%20349c0f5171ec807b8398cb0b8b0ecdd6.md)

> A mean is a measure that summarizes a set of values into a single representative number, often capturing the "central tendency." Different types of means are used depending on the context and the mathematical relationship among the data.
> 

## Type

| Mean Type | Formula (for values $(x_1, x_2, …, x_n)$) | Key Idea | Typical Use |
| --- | --- | --- | --- |
| **Arithmetic Mean** | $(\frac{x_1 + x_2 + … + x_n}{n})$ | Equal weighting of values | General average (e.g., test scores, income). |
| **Geometric Mean** | $((x_1 \cdot x_2 \cdot … \cdot x_n)^{1/n})$ | Multiplicative balance | Growth rates, ratios, normalized comparisons. |
| **Harmonic Mean** | $(\frac{n}{\frac{1}{x_1} + \frac{1}{x_2} + … + \frac{1}{x_n}})$ | Average of reciprocals | Speeds, rates, efficiency measures. |
| **Quadratic Mean (RMS)** | $(\sqrt{\frac{x_1^2 + x_2^2 + … + x_n^2}{n}})$ | Emphasizes larger values | Signal processing, physics (e.g., root-mean-square voltage). |
| **Weighted Mean** | $(\frac{w_1 x_1 + … + w_n x_n}{w_1 + … + w_n})$ | Values contribute proportionally to weights | Grading systems, statistics, economics. |
| **Generalized Mean (Power Mean)** | $(\left(\frac{1}{n}\sum x_i^p\right)^{1/p})$ | Family of means parameterized by (p) | Unifies arithmetic, geometric, harmonic, RMS. |
