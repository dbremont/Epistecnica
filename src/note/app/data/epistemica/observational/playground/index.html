Playground

live noteindex#observational

A playground pairs an epistemic element's corpus note with an interactive notebook. The note states the schema, the formulation, and the decomposition; the notebook lets the same element be moved, measured, and taken apart. The book icon opens the note; ▶ play runs the notebook.

Notebooks are live pages, not simulated tutorials: every number is computed in the browser from the state you set, and every figure follows that state.
