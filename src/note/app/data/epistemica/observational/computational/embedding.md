# Embedding


> An **Embedding Space Representation System** is a method in machine learning that maps high-dimensional data into a lower-dimensional space, preserving relevant properties and relationships.
> 

**Embedding space representation** methods in machine learning, which transform high-dimensional data into lower-dimensional, dense vectors, include techniques like:

1. **Word2Vec**: Generates word embeddings by either predicting a word from its context (CBOW) or predicting the context given a word (Skip-gram).
2. **GloVe**: Utilizes global word-word co-occurrence statistics from a corpus to produce word embeddings.
3. **t-SNE**: A nonlinear dimensionality reduction technique, ideal for visualizing high-dimensional data in a low-dimensional space (usually 2D or 3D).
4. **UMAP**: A manifold learning technique for dimension reduction, often used for visualization.
5. **Autoencoders**: Neural networks used for learning compressed representations of data, where the network aims to reproduce its input at the output layer.

**Embedding representations** in **machine learning** include:

1. **Latent Space**: A compressed representation capturing the essence of data, often used in generative models.
2. **Manifold Space**: Represents complex, high-dimensional data in a lower-dimensional space, maintaining intrinsic geometric properties.
3. **Hidden Layer Representations (in neural networks) are** features automatically learned by neural networks that are not directly observable in the input data.
4. **Feature Space**: The space of input variables or features representing data points.
5. **Embedding Space**: A space where entities (like words or items) are mapped to vectors, capturing semantic relationships.
