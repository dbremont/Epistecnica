# Ridge Function

 : Activation Function (Activation%20Function%2038378a7ebe2e4fe89bca4e08fd31fef4.md)

> A **ridge function** is a composition $f(x) = g(Wx)$: a linear map $W$ followed by an [activation](activation-function.md) $g$. It is constant along every direction the weight matrix annihilates, so its level sets are parallel hyperplanes — the shape that gives it its name, and the shape a single neuron contributes to a network.
