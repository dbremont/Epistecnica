# Singularity Theory


> 

> This concept has been applied by Sumio Watanabe in what is known as Singular Learning Theory. This theory recognizes that all deep learning models are singular, meaning that their parameter space (where weights and biases reside) has sharp cusps and twists. Furthermore, the mapping from parameter space to function space is not injective, meaning different parameter choices can yield the same function computed by a neural network.
