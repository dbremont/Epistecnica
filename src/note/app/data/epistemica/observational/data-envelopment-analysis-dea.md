# Data Envelopment Analysis (DEA)


> **Data Envelopment Analysis (DEA)** is a mathematical method used to assess the efficiency of decision-making units (DMUs), such as organizations, schools, or hospitals, by comparing their relative performance in transforming multiple inputs (resources) into multiple outputs (results) without requiring a predefined functional form. It calculates the efficiency frontier and identifies which units are operating at optimal efficiency and which are not.
