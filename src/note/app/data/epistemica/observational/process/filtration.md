# Filtration

 : State Estimation (State%20Estimation%2018ec0f5171ec80b997b6c78fc4b3be89.md), Stochastic Process (Stochastic%20Process%200fecab268ff946668713151fbce73638.md)

> **Formal Definition**: A filtration is an increasing sequence of σ-algebras $\{ \mathcal{F}_t, t \in T \}$, where each $\mathcal{F}_t$ represents the information available up to time $t$.
> 

> Purpose: Describes how the information available about the process evolves over time.
>
