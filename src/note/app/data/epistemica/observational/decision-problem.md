# Decision Problem


> A **decision** is a choice that is made between two or more alternatives after considering different factors, options, and information. It involves the selection of one course of action from multiple available options.
> 

> Not necessarily related to a **'decision problem'** in computer science.
> 

## Formalization

A decision problem can be seen as: $P=(S,E)$

where:

- **Solution Space**: $S$ is the set of possible **solutions (choices)**
- **Evaluation Model**: $E$ is the **evaluation model**, which can be:
    - A **binary classifier** (Yes/No decision) → e.g., "Is there a solution that satisfies a constraint?"
    - An **optimization function** → e.g., "Which choice maximizes a given metric?

## Evaluation Model

> An **evaluation model** consists of a set of criteria and a structured process for applying them to assess, rank, or choose a solution, often balancing **trade-offs** between **competing factors**.
> 

> Choosing a **good** evaluation model is an art; and requires a deep understanding of the problem; and the solution.
>
