# Markov Blanket


> Markov Blanket is a property  $\mathrm{MB}(v) \subseteq V \setminus {v}$ of a set of variables that renders a random variable $v$ **conditionally independent of all remaining variables in the system**, such that, once $\mathrm{MB}(v)$ is known, no additional information about $v$ can be obtained from any other variable in $V$.
> 

Guiding Questions:

- What is the used of the idea?  The concept of a Markov blanket is important because it allows us to simplify complex models by focusing only on the relevant variables for a particular prediction task. It is also used in machine learning for feature selection and in probabilistic inference to efficiently compute posterior distributions.
