# Coding

 : Information (Information%2017ac0f5171ec813d813ff6055c98fe7d.md), Huffman Coding (Huffman%20Coding%20198c0f5171ec807cabf9e059541c655f.md)

> **Coding:** Is a data representation scheme using codes or symbols in a way that optimizes storage or transmission efficiency.
> 

## **Coding Methods**

| **Coding Method** | **Description** |
| --- | --- |
| **Huffman Coding** | A variable-length prefix coding technique that assigns shorter codes to more frequent symbols, reducing the average length of the encoded message. |
| **Arithmetic Coding** | Encodes sequences of symbols as fractional numbers in a specific range, enabling efficient compression. |
| **Run-Length Encoding** | A simple method that represents repeated sequences of the same symbol by a single code followed by a count. |
| **Shannon-Fano Coding** | A variable-length coding method that divides symbols into subsets based on their probabilities, assigning codes accordingly. |
| **Lempel-Ziv Compression (LZ77 and LZ78)** | Dictionary-based algorithms that replace repeated patterns in the data with references to previously encoded data. |
| **Burrows-Wheeler Transform (BWT)** | A reversible permutation of characters in a string, often used as a preprocessing step for compression algorithms. |
| **Entropy Coding** | Coding based on entropy, where symbols with higher probabilities are assigned shorter codes, minimizing the average code length. |
| **Turbo Codes and LDPC Codes** | Advanced error-correcting codes that efficiently detect and correct errors in data transmission. |
| **Reed-Solomon Codes** | Error-correcting codes used in applications like data storage and communication systems to detect and correct errors. |
| **Cryptographic Codes** | Codes used in cryptography to transform plaintext into ciphertext for secure communication. |

## **Error Correction Code**

> **Error Correction Code (ECC)** is a method used in digital communications and data storage to detect and correct errors in data transmission or storage by adding redundancy to the original data, ensuring the integrity and accuracy of the information.
>
