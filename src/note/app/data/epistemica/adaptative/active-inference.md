# Active Inference


> **Active Inference** is a theoretical framework that models perception, action, and learning as a process of **minimizing prediction error** by updating internal models based on sensory inputs and prior beliefs.
> 

> Active Inference is a first principle account of how autonomous agents operate in dynamic, non-stationary environments.
> 

> Active Inference provides a framework (derived from first principles) for solving and understanding the behavior of autonomous agents in situations requiring decision-making under uncertainty [Friston et al., 2017a,b].
>

Active Inference

**Active inference** is a theoretical framework in neuroscience and machine learning that aims to explain how agents can perceive and act on their environment to achieve their goals. It proposes that agents are constantly trying to minimize the difference between their sensory predictions and actual sensory inputs while also taking actions to influence the sensory inputs they receive.

The **active inference** framework is based on the **free energy principle**, which measures how well an agent’s internal world model matches the sensory data it receives. In active inference, agents try to minimize free energy by adjusting their beliefs about the world and by taking actions that influence the sensory inputs they receive.

**Active inference** has been applied to various tasks, from perception and decision-making to motor control and learning. One key advantage of the active inference framework is its ability to handle uncertainty and ambiguity in the environment, as agents can use their internal models to make probabilistic predictions about future sensory inputs.

The **active inference** framework has also been used to develop machine learning algorithms, such as active inference networks, a deep neural network that can perform active inference tasks. These algorithms have shown promise in robotics and autonomous systems, where agents must perceive and act in complex and dynamic environments.

## Practice

**Active inference** is a computational framework for understanding perception and action as inference processes. Unlike traditional machine learning, active inference does not require a large dataset for training. Instead, it relies on a generative model of the environment and a belief update mechanism to make predictions and decisions in real-time.

However, using simple datasets to illustrate the concepts of active inference and test implementations can be helpful. Here are a few examples of datasets that can be utilized for active inference:

- **Sinusoidal signal**: A simple dataset can be created by generating a sinusoidal signal with some noise. This can be used to test the ability of the active inference model to learn and predict a periodic signal.
- **Linear system**: Another simple dataset can be created by defining a linear system, such as a mass-spring-damper system, and generating noisy observations. This can be used to test the ability of the active inference model to learn and predict the dynamics of a physical system.
- **Image classification**: Although active inference is not typically used for image classification, it can be helpful to test implementations on a well-known dataset such as MNIST or CIFAR-10. This can be done using a pre-trained neural network to generate predictions and the active inference model to select the following image to classify.
- **Robot navigation**: Simulating a robot navigating an environment with obstacles can create a more complex dataset. This can be used to test the active inference model's ability to plan and execute actions based on sensory input.

## Alternatives

1. **Predictive Processing**: A cognitive framework that emphasizes the brain's role in generating predictions about the environment and updating them based on sensory input.
2. **Bayesian Brain Hypothesis**: A theory proposing that the brain operates as a Bayesian inference machine, continuously updating beliefs based on incoming sensory data.
3. **Cybernetics**: An interdisciplinary approach studying systems, feedback, and control mechanisms in various fields, including biology, psychology, and engineering.
4. **Embodied Cognition**: Emphasizes the role of the body and its interactions with the environment in shaping cognition and perception.
