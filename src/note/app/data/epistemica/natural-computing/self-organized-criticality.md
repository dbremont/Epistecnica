# Self-Organized Criticality


> **Self-organized criticality** (**SOC**) is a property of [dynamical systems](https://en.wikipedia.org/wiki/Dynamical_system) that have a [critical point](https://en.wikipedia.org/wiki/Critical_phenomena) as an [attractor](https://en.wikipedia.org/wiki/Attractor).
