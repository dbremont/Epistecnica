# Abstract Reference System


> A **structured set of symbolic** or conceptual entities designed to **refer to** or **represent** properties or relations of objects, without necessarily depending on the objects' concrete nature.
> 

**In very technical terms**, you could break it down further:

- **System**: there is a set of entities (numbers) and operations (addition, multiplication, etc.) with structured rules (axioms).
- **Reference**: numbers refer to cardinalities, orders, measures, etc.
- **Abstract**: numbers and operations exist as formal concepts, independent of physical instantiation.
