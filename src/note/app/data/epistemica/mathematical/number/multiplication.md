## Formulation

Multiplication is a **mathematical binary operation** that combines two quantities (factors) to produce a third quantity (their product), according to specified mathematical rules.

For natural numbers, multiplication can be introduced as repeated addition. More generally, multiplication is defined according to the algebraic structure in which it operates and need not be reducible to repeated addition.

## Interpretation Set

| Interpretation | Description | Case |
| --- | --- | --- |
| Repeated addition | Multiplication represents adding the same quantity a specified number of times. | $3 \times 4 = 4+4+4=12$ |
| Equal groups | Multiplication determines the total quantity obtained from a specified number of groups containing an equal number of elements. | 3 boxes containing 4 apples each: $3\times4=12$ apples. |
| Rectangular array | Multiplication determines the total number of elements arranged in rows and columns. | 3 rows of 4 objects: $3\times4=12$ objects. |
| Scaling | Multiplication transforms a quantity by a specified factor. | Doubling 4 gives $2\times4=8$. |
| Cartesian product | Multiplication determines the number of ordered pairs obtainable from two finite sets. | A set of 3 shirts and a set of 4 trousers produce $3\times4=12$possible combinations. |
| Area calculation | Multiplication determines the area of a rectangle from its length and width. | A rectangle measuring 3 m by 4 m has an area of $3\times4=12\text{ m}^2$. |
| Proportionality | Multiplication determines a quantity proportional to another quantity by a constant factor. | At $4 per item, 3 items cost $3\times4=\$12$. |
| Algebraic operation | Multiplication combines elements of an algebraic structure according to its multiplication operation and associated properties. | For real numbers, $3\times4=12$. For matrices, multiplication follows different rules. |
| Combinatorial counting | Multiplication counts the total number of outcomes when a sequence of independent choices has a specified number of possibilities at each stage. | 3 choices of shirt and 4 choices of trousers yield $3\times4=12$ outfits. |
| Computational procedure | Multiplication is an algorithmic procedure for determining the product of two operands. | Applying the standard multiplication algorithm to $23\times14$ yields $322$. |
| Division (reciprocal scaling) | Multiplication by the reciprocal of a nonzero number is equivalent to division by that number. | Multiplying 12 by 0.5 is equivalent to dividing 12 by 2: $12\times0.5=12\div2=6$. |
