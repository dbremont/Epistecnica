# Roman Numeric System

 : Numeric System (Numeric%20System%201d6c0f5171ec80899160d6587a6a9e3e.md)

> The **Roman numeric system** (or **Roman numeral system**) is a **non-positional**, **additive-subtractive numeral system** used in ancient Rome and throughout the Roman Empire.
> 

## 🔢 **Core Symbols**

> The system uses **seven letters** from the Latin alphabet as symbols for numbers:
> 

| Symbol | Value |
| --- | --- |
| I | 1 |
| V | 5 |
| X | 10 |
| L | 50 |
| C | 100 |
| D | 500 |
| M | 1000 |

## 🧮 **Rules of Composition**

1. **Additive Principle**:
    - Symbols placed **from left to right** are **added** if they are in **descending or equal order**.
    - Example: `VI = 5 + 1 = 6`, `XX = 10 + 10 = 20`.
2. **Subtractive Principle**:
    - A smaller numeral placed **before** a larger numeral **subtracts** from it.
    - This is used to **avoid four repetitions** of the same numeral.
    - Example: `IV = 5 - 1 = 4`, `IX = 10 - 1 = 9`.
3. **Repetition Limits**:
    - A numeral can typically be repeated **at most three times** in succession.
    - Example: `III = 3`, but `IIII` is avoided in favor of `IV`.
4. **Non-Positional**: The value of a symbol **does not depend on its position** in the number but on these additive and subtractive rules.

## ⚙️ **Limitations**

- **No concept of zero**.
- Difficult to represent very large numbers.
- Cumbersome for arithmetic operations (e.g., addition, multiplication).
- Rarely used in scientific or mathematical contexts.

## 🧠 **Modern Use**

> Today, Roman numerals are mostly used for:
> 
- Clocks (e.g., `XII` for 12),
- Chapter numbers, monarchs (e.g., Elizabeth II),
- Events (e.g., **Olympics**, **Super Bowl**),
- Legal and formal numbering.
