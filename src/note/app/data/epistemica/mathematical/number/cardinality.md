# Cardinality


> In this note, we will explore a fundamental **property in mathematics** related to sets: **cardinality**.
> 

> **Note:** Cardinality is not itself a specific property-instance, but rather a **property type** (or abstract property schema). A particular value—such as *5*, *10*, or *ℵ₀*—is the **value** that instantiates this property type for a given set.
