# Hypergraph

 : Graph (Graph%20176c0f5171ec80f6b099dc37efe8511e.md)

> A **hypergraph** is a generalization of a graph where an edge, called a **hyperedge**, can connect any number of vertices, allowing for more complex relationships beyond pairwise connections.
