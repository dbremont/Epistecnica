# Coordinate System

 : Euclidean  Geometry (Euclidean%20Geometry%20858b34433a204b55bb716919101bdcc6.md), Projective Geometry (Projective%20Geometry%20206c0f5171ec8016b1e0d9772b9e9a07.md), Space (Space%2019fc0f5171ec80a88882f0b8b4d96331.md)

> A **coordinate system** is a framework used to uniquely identify the position of **points or objects** in a **space** by using one or more numbers, known as coordinates.
> 

> La palabra "coordenada" está formada con raíces latinas y significa **"línea, eje o plano, que sirve para determinar la posición de un punto"**.
Sus componentes léxicos son: ordin (orden), más el sufijo -ado (que ha  recibido la acción). Ver: sufijos, otras raíces latinas, coordinar, 
orden y también participio.
> 

## Formulation

> What is a coordinate system?  A Coordinate System is a technical mechanism that encodes the position  of  each elements of the space, enabling computation.
> 

> Does the relation between the elements imposed a constraint on the type of coordinate system that can be used? A coordinate system is admissible **only if it is compatible with the structure (relations) of the space**, meaning that coordinate transformations must **preserve that structure**.
> 

> A **coordinate system** is a **representation** (or “view”) of a space, obtained by mapping its elements to tuples of numbers. This mapping must preserve the semantics induced by the relations defined on the space.
> 

> Can we use many different coordinate systems in the same space? Yes.
> 

## System Space

| Coordinate System | Description | Typical Applications |
| --- | --- | --- |
| Unit Coordinate System | A unit coordinate system is a coordinate system where the basis vectors have a magnitude of one, providing a standardized framework for measuring and representing positions in space. |  |
| Cartesian Coordinate System | Defines points in a space using perpendicular axes (x, y, z). | Engineering, computer graphics, physics |
| Polar Coordinate System | Defines points in a plane using a radius and angle from a reference direction. | Electromagnetics, navigation, circular motion |
| Cylindrical Coordinate System | Extends polar coordinates with an additional height (z) component for three-dimensional space. | Fluid dynamics, electromagnetics, mechanical engineering |
| Spherical Coordinate System | Defines points in three-dimensional space using a radius, polar angle, and azimuthal angle. | Astronomy, physics, geophysics |
| Geographic Coordinate System | Uses latitude, longitude, and sometimes elevation to define locations on the Earth's surface. | Cartography, navigation, geography |
| Homogeneous Coordinate System | Extends Cartesian coordinates by adding an extra dimension to facilitate projective geometry. | Computer graphics, projective geometry |
| Barycentric Coordinate System | Defines points within a triangle or tetrahedron using the vertices and proportional distances. | Computer graphics, finite element analysis, geometric modeling |
| Curvilinear Coordinate System | Uses curvilinear lines instead of straight lines to define coordinates. | Fluid dynamics, general relativity, theoretical physics |
| Elliptic Coordinate System | Uses ellipses and hyperbolas to define coordinates in a plane. | Electromagnetic field analysis, classical mechanics |
| Log-Polar Coordinate System | Transforms Cartesian coordinates with logarithmic scaling of the radius and linear scaling of the angle. | Image processing, computer vision |
