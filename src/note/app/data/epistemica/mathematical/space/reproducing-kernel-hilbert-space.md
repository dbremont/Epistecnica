# Reproducing Kernel Hilbert Space

 : Positive-definite Kernel (Positive-definite%20Kernel%2018ec0f5171ec807a9014c83ecdf07ad9.md)

> A **Reproducing Kernel Hilbert Space (RKHS)** is a Hilbert space of functions in which evaluation at each point is a continuous linear functional, and it is associated with a positive definite kernel function that reproduces the inner product in that space.
