## Table of Discrete Structures

| **Structure** | **Definition** | **Key Properties** | **Applications** |
| --- | --- | --- | --- |
| **Set** | A collection of distinct elements. | Unordered, no duplicates. | Foundation of all discrete math; databases, logic. |
| **Multiset** | A set allowing duplicate elements. | Elements have multiplicities. | Counting problems, statistics. |
| **Graph** | A pair $G = (V, E)$, where  $V$ is a set of vertices and   $E$ edges. | Directed/undirected, weighted/unweighted. | Networks, algorithms, social graphs. |
| **Tree** | A connected acyclic graph. | $n$ vertices, $n-1$ edges; hierarchical. | Data structures (BSTs), taxonomy. |
| **Poset** | A partially ordered set (reflexive, antisymmetric, transitive). | Chains, lattices, Hasse diagrams. | Scheduling, logic, domain theory. |
| **Lattice** | A poset where every pair has a LUB (join) and GLB (meet). | Distributive, modular, Boolean variants. | Cryptography, formal concept analysis. |
| **Boolean Algebra** | A lattice with complementation, $\land$,$\lor$, $\neg$. | De Morgan’s laws, duality. | Circuit design, logic programming. |
| **Group** | A set with an associative binary operation, identity, and inverses. | Subgroups, homomorphisms, cosets. | Symmetry (e.g., Rubik’s Cube), cryptography. |
| **Finite Field** | A field with a finite number of elements (e.g., $\mathbb{F}_p$ ). | Arithmetic modulo  $p$; used in polynomials. | Error-correcting codes, cryptography (AES). |
| **Matroid** | A pair $(E, \mathcal{I})$, where $\mathcal{I}$ is a family of independent sets. | Exchange property, rank function. | Greedy algorithms, combinatorial optimization. |
| **Hypergraph** | A generalization of a graph where edges can connect any number of vertices. | Incidence matrix, coloring. | Machine learning (clustering), database relations. |
| **Combinatorial Design** | A family of subsets (blocks) of a finite set with intersection properties. | Balanced incomplete block designs (BIBDs). | Experimental design, tournament scheduling. |
| **Finite Automaton** | A tuple $(Q, \Sigma, \delta, q_0, F)$ for state transitions. | Deterministic/non-deterministic, regular languages. | Compiler design, text parsing. |
| **Permutation** | A bijection from a set to itself. | Symmetric group $S_n$, cycles. | Cryptography (DES), puzzles. |
| **Partition** | A division of a set into non-overlapping subsets. | Equivalence relations, Bell numbers. | Clustering, number theory. |
| **Binary Relation** | A subset of $A \times B$. | Reflexivity, symmetry, transitivity (e.g., equivalence relations). | Databases, formal languages. |
| **String** | A finite sequence of symbols from an alphabet. | Concatenation, substrings, languages. | Bioinformatics, coding theory. |
| **Trie** | A tree-like data structure for storing strings. | Prefix-based retrieval. | Autocomplete, IP routing. |
