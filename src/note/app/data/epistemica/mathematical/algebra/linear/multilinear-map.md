# Multilinear Map

 : Tensor (Tensor%2000b35866438f431f90e06cc223bd8eb5.md), Linear Space (Linear%20Space%20b935942a1a064729b3f2be42d174923a.md)

> A **bilinear map** is a function that takes two arguments from two vector spaces and maps them to a third vector space, such that the function is linear in each argument when the other is held fixed.
