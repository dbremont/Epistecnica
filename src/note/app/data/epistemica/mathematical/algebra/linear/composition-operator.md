# Composition Operator

 : Non-linear Operator (Non-linear%20Operator%20207c0f5171ec80d5aa4cd8031f8dc25d.md)

> aka. **Koopman Operator.**
> 

> The **composition operator** is an operator that maps a function $f$ to the composition $f \circ \phi$, where $\phi$ is a fixed function, i.e., $C_\phi(f) = f \circ \phi$.
>
