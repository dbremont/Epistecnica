# Stirling Number


> aka. Stirling Two Dimensional Sequences.
> 

> Stirling numbers are two-parameter combinatorial arrays (not simple sequences), counting structural configurations of permutations (first kind) and set partitions (second kind), generalizing the concept of combinatorial enumeration beyond linear sequences like Catalan numbers.
