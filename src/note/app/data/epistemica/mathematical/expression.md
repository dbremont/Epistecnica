# Expression

 : Mathematical Object (Mathematical%20Object%201d1c0f5171ec80fdb785c5eb4df98fdb.md), Function (Function%20049537a4fd564eaaac4bae443839b0c0.md)

> **Mathematical Expression:**  An **expression**  is a combination of numbers, variables, and mathematical operators  (such as addition, subtraction, multiplication, and division) that  represents a value or a quantity without an equality sign.
> 

> In mathematics, **non-algebraic functions** (also called **transcendental functions**) are functions that **cannot**  be expressed as finite combinations of **algebraic operations** (addition,  subtraction, multiplication, division, roots) on variables.
> 

> [**Algebraic Operation**] The term **"algebraic"** refers to operations and  constructions that can be built from a core set of fundamental  mathematical actions, all of which arise naturally in the study of **polynomial equations** and **elementary algebra**.
