# Classical Algebra

 : Algebra (Algebra%2018fde09aee854bbdaf5008362315f85a.md), Arithmetic (Arithmetic%201d6c0f5171ec80038b81f09601bcd9df.md)

> **In this note**, we explore the problem-solving framework of **Elementary Algebra, or should we say** Reduction by Completion and Balance 😊.
> 

> **Algebraic Model**  is a representation of  a  problem/system/phenomena using  set of equations; it helps to infer unknown data from known data; respecting the equations.
> 

> **Classical algebra (**Problem Set, Object, Operations, Techniques → Results.**)** is the art of analyzing equivalent structures, where only partial information about their components is known, and the goal is to uncover the missing information to fully describe each component on both sides.

## Expression

> An **algebraic expression** is a combination of **numbers, variables, and operations** (such as addition, subtraction, multiplication, division, and exponentiation) that represents a value.
> 

> See more in [Expression](expression.md), [Number](number.md).
> 

| Category | Expression | Description |
| --- | --- | --- |
| Constant | $7,\ -3,\ 0.5,\ 0.57$ | A fixed numerical value with no variables. |
| Variable | $x,\ y,\ a$ | A symbol representing an unknown or changeable quantity. |
| Monomial | $3x,\ -5a^2,\ 7y^3$ | A single term composed of a constant coefficient multiplied by variables raised to non-negative integer powers. |
| Binomial | $x+5,\ 3a^2-2a$ | An expression consisting of **two terms** joined by addition or subtraction. |
| Polynomial | $2x^2+3x-7,\ a^3-4a+1$ | A sum of one or more monomials. Variables have non-negative integer exponents. |
| Rational Expression | $\dfrac{x+1}{x-2},\ \dfrac{3a^2-1}{a+5}$ | A quotient of two polynomials. The denominator cannot be zero. |
| Radical Expression | $\sqrt{x+3},\ \sqrt[3]{2a^2-1}$ | An expression containing a root (square root, cube root, etc.) of a variable or polynomial. |
| Exponential Expression | $2^x,\ e^{3a}$ | A variable appears in the exponent. |
| Logarithmic Expression | $\log(x),\ \ln(a^2+1)$ | The logarithm of a variable or expression, the inverse operation of exponentiation. |
| Trigonometric Expression | $\sin(x),\ \cos(2\theta)$ | Expressions using trigonometric functions of variables. |

## Technique

> A **technique** is a **systematic method or procedure used to manipulate, transform, or solve algebraic expressions and equations** according to established rules.
> 

> **Note:** The terminology of these categories is not strict—factorization, for example, is a type of transformation, and in fact, almost everything listed here can be seen as a form of transformation.
> 

| Category | Technique | Description | Target |
| --- | --- | --- | --- |
| **Solution** | Substitution | Replace variables with equivalent expressions to simplify equations. | Systems of equations, multi-variable expressions. |
|  | Elimination | Add/subtract equations to cancel variables, reducing complexity. | Linear systems, simultaneous equations. |
|  | Quadratic Formula | Solve quadratic equations using $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$. | Quadratic equations (\(ax^2 + bx + c = 0\)). |
| **Factorization** | GCF Factoring | Extract the greatest common factor from all terms in an expression. | Polynomials, rational expressions. |
|  | Difference of Squares | Factor $a^2 - b^2$ into $(a - b)(a + b)$. | Binomials, quadratic expressions. |
|  | Trinomial Factoring | Decompose $ax^2 + bx + c$ into $(px + q)(rx + s)$. | Quadratic trinomials. |
| **Simplification** | Combining Like Terms | Sum/dissimilar terms with identical variable parts. | Polynomials, algebraic expressions. |
|  | Fraction Reduction | Divide numerator/denominator by their GCF to simplify rational expressions. | Fractions, rational equations. |
|  | Expanding Products | Apply distributive property (e.g., $(a+b)(c+d) = ac + ad + bc + bd$). | Factored expressions, parentheses. |
| **Transformation** | Completing the Square | Rewrite $ax^2 + bx + c$ as $a(x-h)^2 + k$ for vertex form. | Quadratic equations, parabola analysis. |
|  | Logarithmic Conversion | Transform exponential equations (e.g., $a^x = b$) into logarithmic form. | Exponential growth/decay, solving for exponents. |
|  | Trigonometric Identities | Replace expressions using identities (e.g., $\sin^2\theta + \cos^2\theta = 1$). | Trigonometric equations, simplification. |
| **Representation** | Slope-Intercept Form | Express linear equations as $y = mx + b$ (slope $m$, y-intercept $b$). | Linear equations, graphing. |
|  | Matrix Notation | Represent systems as $AX = B$, where $A$ is a coefficient matrix. | Linear systems, vector spaces. |
|  | Function Notation | Define relationships as $f(x) = \text{expression}$ for clarity. | Functions, mappings, calculus. |
| **Visualization** | Coordinate Graphing | Plot equations on the Cartesian plane to show solutions. | Equations, inequalities, functions. |
|  | Table of Values | Generate input-output pairs to illustrate relationships. | Functions, sequences, patterns. |
|  | Number Line | Display solutions to inequalities or intervals on a line. | Inequalities, absolute values, real numbers. |

## ❓ QA

- Under what conditions does an algebraic manipulation (e.g., multiplying both sides by a variable expression, squaring both sides) **preserve equivalence** of an equation?
- Why are certain operations in algebra reversible while others are not? How does this impact the solution process?
- In solving a system of equations, how can we formally define the conditions under which the system is **consistent, inconsistent, or indeterminate**?
- How does the abstraction of a variable as a “placeholder for an unknown” enable the generalization of arithmetic rules to algebra? Are there limitations to this abstraction?
- What is the conceptual difference between **an expression** and **an equation**, and why does this distinction matter for problem solving?
- How does the principle of equivalence of equations justify the operations we perform on both sides?
- How do the properties of real numbers (commutativity, associativity, identity, inverses) underpin all algebraic manipulations?
- Can you explain why solving for an unknown is equivalent to finding the intersection of two functions?
- How does factorization reveal the underlying structure of a polynomial?
- Why is the concept of a “root” of a polynomial central to both elementary and advanced algebra?
- How does elementary algebra encode arithmetic operations in symbolic form?
- How does understanding patterns in algebraic manipulations contribute to mathematical intuition?
- How are algebraic identities used to generalize problem-solving methods?
- Why are substitution and elimination valid strategies for solving systems of equations?
