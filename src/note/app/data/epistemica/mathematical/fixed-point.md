# Fixed Point

 : Convergent (Convergent%20178c0f5171ec80279a2fc495bfb78817.md), Invariant (Invariant%20178c0f5171ec80b2820ed652743f65a8.md)

> A **fixed point** is an element $x$ in the domain of a function or mapping $f$ such that  $f(x) = x$, meaning it remains unchanged under the application of $f$.
> 

| **Context** | **Type of Fixed Point** | **Description** | **Example** |
| --- | --- | --- | --- |
| **Functions and Mappings** | Fixed Point of a Function | A point  $x$ such that $f(x) = x$. | For $f(x) = x^2$, the fixed points are $x = 0$ and  $x = 1$. |
|  | Attracting Fixed Point | A fixed point where nearby points are drawn toward it under iteration. | For $f(x) = \frac{x}{2}$,  $x = 0$  is an attracting fixed point. |
|  | Repelling Fixed Point | A fixed point where nearby points move away from it under iteration. | For  $f(x) = 2x$,  $x = 0$ is a repelling fixed point. |
| **Dynamical Systems** | Equilibrium Point | A state where the system does not change over time. | In $\dot{x} = 0$), any constant $x$ is an equilibrium point. |
|  | Stable Fixed Point | A fixed point where small perturbations decay over time. | In  $\dot{x} = -x$,  $x = 0$ is a stable fixed point. |
|  | Unstable Fixed Point | A fixed point where small perturbations grow over time. | In   $\dot{x} = x$,  $x = 0$ is an unstable fixed point. |
|  | Saddle Point | A fixed point that is stable in some directions and unstable in others. | In  $\dot{x} = -x$,  $\dot{y} = y$,  $(0, 0)$ is a saddle point. |
| **Iterative Processes** | Fixed Point of an Iterative Algorithm | A point $x$ such that  $x = f(x)$ under repeated application of $f$. | In gradient descent, the fixed point is the optimal solution. |
|  | Limit of a Convergent Sequence | A point  $x$ where a sequence  $x_n$ converges to  $x$. | In the theorem you provided, $v_n$ converges to a fixed point $v$. |
| **Topology** | Brouwer Fixed Point | A fixed point guaranteed by the Brouwer Fixed-Point Theorem for continuous maps. | Any continuous map on a convex compact set in $\mathbb{R}^n$ has one. |
|  | Lefschetz Fixed Point | A fixed point studied in algebraic topology, related to homology. | Used in the study of manifolds and mappings. |
| **Functional Analysis** | Fixed Point of an Operator | A point $x$ in a function space such that $T(x) = x$ for an operator $T$. | In $T(f) = f$,  $f$ is a fixed point. |
|  | Banach Fixed Point (Contraction Mapping) | A unique fixed point guaranteed for contraction mappings in complete metric spaces. | Used in solving differential equations and optimization. |
| **Economics and Game Theory** | Nash Equilibrium | A fixed point in game theory where no player can benefit by changing strategy. | In the Prisoner's Dilemma, the Nash equilibrium is a fixed point. |
| **Physics** | Equilibrium State | A state where forces or potentials are balanced, and the system is at rest. | In a pendulum, the bottom position is a stable equilibrium (fixed point). |
|  | Critical Point in Phase Transitions | A fixed point in the renormalization group analysis of phase transitions. | Used in statistical mechanics to study critical phenomena. |
| **Computer Science** | Fixed Point in Recursion | A value that satisfies a recursive equation. | In $x = f(x)$, $x$ is a fixed point of the recursive function $f$. |
|  | Fixed Point in Fixed-Point Arithmetic | A representation of numbers where the decimal point is fixed. | Used in digital signal processing and low-level programming. |
