Atlas of Dynamical Representational Systems

live note catalog #dynamical-systems #representation

A catalog of the representational systems — systems of signs, symbols, structures, and rules — through which dynamical behavior is written down and studied. Each entry is a Representational System; where a corpus note exists, the card opens it for exploration.

A representational system is an epistemic element constituted by a set of representational elements and rules of organization and interpretation, which enables the representation of aspects of reality* — including its entities, properties, relationships, states, or dynamics. Cases include the Hindu–Arabic numeral system, the arithmetic system (based on Hindu–Arabic numerals), and the classical algebraic representation system.
