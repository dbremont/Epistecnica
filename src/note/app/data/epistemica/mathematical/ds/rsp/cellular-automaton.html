Cellular Automaton Representational System

live noteinteractive#cellular-automata#representation

A Cellular Automaton (CA) representational system writes change as a local rule on a discrete lattice: every cell holds a state, and at each tick it updates from its own state and its neighbours. . It is the canonical way discrete, parallel computation is stated, and the spacetime diagram is the way it is read.

Below, this one representation is instantiated in five domains. Pick an instance to load it; its rule and description appear above the lab. Then play — step generation by generation, draw cells with the pointer, and watch the population graph.
