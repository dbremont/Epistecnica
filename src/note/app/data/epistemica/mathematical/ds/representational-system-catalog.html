Representational System Catalog

live note catalog #dynamical-systems #representation

A dynamical system is never studied through the thing itself but through the sign-system in which it is written — equations, maps, symbol sequences, sections, graphs. This catalog gathers the representational systems of the dynamical-systems scope: each is a system of signs, symbols, structures, and rules in which a dynamics can be formed and interpreted, and each reads as an Epistemic Representation → Representational System.

Formulation

What epistemic element type does this instance belong to?

Epistemic Representation → Representational System — an index of systems of signs, symbols, structures, and rules within which representations of a dynamical system can be formed and interpreted; each system comprises Representation Elements (combinable constituents) resting on a Constitutive Substrate (its rules and structures). Schema: Philosophia Artium Epistemicarum et Operis.

What is this epistemic instance?

A catalog of the representational systems by which dynamics are encoded and studied in this scope: differential equations and flows (continuous time), iterated maps (discrete time), symbolic dynamics and cellular automata (symbolic), attractors, fixed points, sections, and bifurcation diagrams (qualitative / topological), graph dynamical systems (relational), and time-delay embeddings (data-driven). Each row is a distinct notation in which the same dynamical object can be stated, preserved, or lost.

What grounds this reading?

It resolves the epistemic gap of representing temporal evolution — turning a process that cannot be held in hand into a stable, inspectable, manipulable sign-system. It preserves the structure the notation is built to carry (a flow's orbit structure, a map's recurrence, a sequence's admissible patterns) and destroys what the notation cannot hold — which is why no single system below is the dynamics itself, only a reading of it.

The representation systems

Each system states the dynamics in its own signs. The elements combine into representations; the substrate is the rule-structure that gives those elements meaning. Select a system to open its note.

Diagnostic questions

What does one representation make visible that another hides?

A phase portrait shows the shape of a flow but not its exact orbits; a symbol sequence exposes forbidden patterns but hides geometry; a bifurcation diagram shows parameter dependence but collapses each orbit to a point. Reading a dynamics means choosing which structure to make legible — and which to leave out.

Can two different representational systems represent the same dynamics indistinguishably?

Yes. A flow and its Poincaré return map carry the same orbit structure under sampling, and an SFT and its adjacency matrix are two encodings of one symbolic system. Conjugacy is exactly this: distinct sign-systems that agree on the dynamics they represent, so the representation certifies the dynamics but not the notation that produced it.

What does each representation destroy?

Poincaré sampling discards inter-section timing; symbolization discards metric detail, keeping only admissible patterns; a scalar embedding discards the original coordinates, keeping a reconstructed attractor up to diffeomorphism. Every system below is lossy by construction — the loss is what makes it usable.

How does the substrate constrain what can be stated?

A differentiable substrate can state rates but not jumps; a symbolic substrate can state local rules but not smoothness; a graph substrate can state coupling topology but not position. The constitutive substrate of a representational system fixes the boundary of what its representations can express.
