# Dynamical System

> A **`dynamical systems`**  is a field in mathematics that develop tools to study **`dynamical systems`**  is a mathematical model that describes th**e evolution** of a set of variables **over time**, where the **future state** depends on the **current state** and is **governed by a set of equations or rules**.
>

## Formulation

> Note: Basic Definition for a Continuous System.
> 

A **dynamical system** is often defined by a set of **differential equations**, such as: $\frac{dx}{dt} = f(x, t)$

Where $x(t)$ is the state of the system at the time $t$.

- The **initial condition** (e.g.,  $x(0) = x_0$) specifies where in the state space the system starts.
- The solution $x(t)$ tells us **how the system evolves** from that initial state.
