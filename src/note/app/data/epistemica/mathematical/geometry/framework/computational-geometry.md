# Computational Geometry


> Problems related to the study of geometric objects and their properties, such as finding the intersection of two lines or computing the convex hull of a set of points.
> 
- **Convex hull**: An algorithm that computes the smallest convex polygon that encloses a set of points in the plane.
- **Voronoi diagram**: An algorithm that partitions a plane into regions based on the distance to a set of points in the plane.
- **Delaunay triangulation**: An algorithm that constructs a triangulation of a set of points in the plane such that no point is inside the circumcircle of any triangle.
- **Line intersection**: An algorithm that computes the intersection point of two lines in the plane.
- **Point location**: An algorithm that determines which region of a planar subdivision a query point lies in.
- **Closest pair of points**: An algorithm that finds the two closest points in a set of points in the plane.
- **Polygon triangulation**: An algorithm that partitions a polygon into triangles.
- **Convex partitioning**: An algorithm that partitions a simple polygon into convex polygons.
- **Visibility graph**: An algorithm that computes the graph of all possible line-of-sight connections between a set of points in the plane.
- **Motion planning**: Algorithms that compute collision-free paths for moving objects in the plane.
