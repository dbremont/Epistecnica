# Mathematical Structure


> **Mathematical Structure**: In mathematics, a structure is a set endowed with some additional features on the set (e.g. an operation, relation, metric, or topology). Often, the additional features are attached or related to the set, so as to provide it with some additional meaning or significance. A partial list of possible structures are measures, algebraic structures (groups, fields, etc.), topologies, metric structures (geometries), orders, events, equivalence relations, differential structures, and categories.
> 

> A **mathematical structure** is a set (or multiple sets) equipped with a collection of operations, relations, and axioms that define the properties and interactions of its elements.
> 

> An **algebraic structure** is a set equipped with one or more operations (e.g., addition, multiplication) that satisfy specific axioms, such as associativity, commutativity, or the existence of identity and inverse elements.
> 

| **Type of Algebraic Structure** | **Defining Properties** | **Examples** |
| --- | --- | --- |
| **Group** | A set with a single binary operation (⋅) that is associative, has an identity element, and every element has an inverse. | - (ℤ, +) (integers under addition) <br> - Symmetric groups (permutations) |
| **Abelian Group** | A group where the operation is commutative (a ⋅ b = b ⋅ a). | - (ℤ, +) <br> - (ℝ, +) (real numbers under addition) |
| **Ring** | A set with two operations (+, ⋅) where (R, +) is an abelian group, and (R, ⋅) is associative and distributive over +. | - (ℤ, +, ⋅) (integers under addition and multiplication) <br> - Matrices over a field |
| **Commutative Ring** | A ring where the multiplication operation (⋅) is commutative. | - (ℤ, +, ⋅) <br> - Polynomial rings (e.g., ℝ[x]) |
| **Field** | A commutative ring where every non-zero element has a multiplicative inverse. | - (ℚ, +, ⋅) (rational numbers) <br> - (ℝ, +, ⋅) (real numbers) |
| **Integral Domain** | A commutative ring with no zero divisors (if a ⋅ b = 0, then a = 0 or b = 0). | - (ℤ, +, ⋅) <br> - Polynomial rings over a field |
| **Division Ring** | A ring where every non-zero element has a multiplicative inverse (not necessarily commutative). | - Quaternions (ℍ) |
| **Vector Space** | A set of vectors with addition and scalar multiplication over a field, satisfying vector space axioms. | - ℝⁿ (n-dimensional real space) <br> - Function spaces |
| **Algebra over a Field** | A vector space equipped with a bilinear product (e.g., multiplication). | - Matrix algebras <br> - Polynomial algebras |
| **Module** | A generalization of a vector space where scalars come from a ring instead of a field. | - ℤ-modules (abelian groups) <br> - Modules over polynomial rings |
| **Lie Algebra** | A vector space with a bilinear operation (Lie bracket) satisfying antisymmetry and the Jacobi identity. | - Skew-symmetric matrices <br> - Tangent spaces in differential geometry |
| **Lattice** | A partially ordered set where every pair of elements has a unique supremum and infimum. | - Power set of a set with union and intersection <br> - Divisibility lattice |
| **Boolean Algebra** | A lattice with distributive and complement properties, modeling logical operations. | - Power set of a set <br> - Logical propositions |
| **Monoid** | A set with a single associative operation and an identity element (no inverses required). | - (ℕ, +) (natural numbers under addition) <br> - Strings with concatenation |
| **Semigroup** | A set with a single associative operation (no identity or inverses required). | - (ℕ, +) <br> - Transformation semigroups |
| **Quasigroup** | A set with a binary operation where division is always possible (left and right). | - Latin squares |
| **Loop** | A quasigroup with an identity element. | - Moufang loops <br> - Octonions |
| **Magma** | A set with a single binary operation (no additional properties required). | - Free magmas <br> - Non-associative structures |
