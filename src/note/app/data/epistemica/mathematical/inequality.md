# Inequality


> **Inequalities** serve as essential mathematical constructs that express the relative magnitudes of values or expressions, enabling the formulation of constraints and relationships across various disciplines, from basic arithmetic to advanced analysis, thus underpinning much of mathematical reasoning and optimization.
> 

> **Boundary value**: is the number separating the value that makes the inequality true.
> 

| **Inequality** | **Formula** | **Description** |
| --- | --- | --- |
| **Cauchy-Schwarz Inequality** | $( \sum_{i=1}^{n} a_i b_i )^2 \leq ( \sum_{i=1}^{n} a_i^2 )( \sum_{i=1}^{n} b_i^2 )$ | Fundamental inequality in linear algebra and analysis, relating dot products. |
| **Triangle Inequality** |  |  |
| **AM-GM Inequality** | $\frac{a_1 + a_2 + \dots + a_n}{n} \geq \sqrt[n]{a_1 a_2 \dots a_n}$ | The arithmetic mean is always greater than or equal to the geometric mean. |
| **Jensen's Inequality** | $f \left( \frac{x_1 + \dots + x_n}{n} \right) \leq \frac{f(x_1) + \dots + f(x_n)}{n}$ | For convex functions, the function's value at the mean is less than or equal to the mean of the function's values. |
| **Holder's Inequality** |  |  |
| **Minkowski Inequality** |  |  |
| **Young's Inequality** | $ab \leq \frac{a^p}{p} + \frac{b^q}{q}$ where $\frac{1}{p} + \frac{1}{q} = 1$ | Relates the product of two numbers to their powers and exponents. |
| **Bernoulli's Inequality** | $(1 + x)^n \geq 1 + nx$ for $x \geq -1$ and $n \geq 0$ | A simple but important inequality in calculus and analysis. |
| **Markov's Inequality** | $P(X \geq a) \leq \frac{E[X]}{a}$ | Used in probability theory to bound the probability that a non-negative random variable exceeds a certain value. |
| **Chebyshev's Inequality** |  |  |
| **Sobolev Inequality** | $| u |{L^q} \leq C | \nabla u |{L^p}$  | Relates norms of functions in Sobolev spaces, important in partial differential equations. |
| **Logarithmic Inequality** | $\log(1+x) \leq x$ for $x > -1$ and $x \neq 0$ | Provides a bound on the natural logarithm function. |
| **Bessel's Inequality** |  |  |
| **Chernoff Inequality** | $P(X \geq a) \leq e^{-\lambda a} E[e^{\lambda X}]$ | Provides exponential bounds on tail probabilities, used in probability theory. |
| **Cantelli's Inequality** | $P(X - E[X] \geq \lambda) \leq \frac{\sigma^2}{\sigma^2 + \lambda^2}$ | A one-sided version of Chebyshev's inequality in probability theory. |
