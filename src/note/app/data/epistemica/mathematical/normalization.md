# Normalization

> **Normalization** or **normalisation** refers to a process that makes something more normal or regular.

> Transforming values or representations into a normalized form according to specified rules or conventions.

## Which Concepts Are are Entails with the Term Normalization?

 Concept | Description |
|---|---|
| **Statistical Normalization** | Transforming data or statistical variables to facilitate comparison, analysis, or interpretation. |
| **Data Normalization** | Organizing data to reduce redundancy and improve consistency, particularly in database structures. |
| **Database Normalization** | Structuring relational databases to minimize redundancy and prevent undesirable dependencies. |
| **Vector Normalization** | Transforming a vector to have a specified magnitude, commonly unit length. |
| **Feature Scaling** | Transforming numerical features to a common or specified scale. |
| **Min–Max Normalization** | Rescaling values to a specified interval, commonly [0, 1]. |
| **Z-Score Standardization** | Transforming values to have a mean of zero and a standard deviation of one. |
| **Probability Normalization** | Ensuring that probabilities in a distribution sum to one. |
| **Ratio Normalization** | Expressing a ratio relative to a specified reference value, often by setting one term to unity. |
| **Matrix Normalization** | Transforming matrix values according to a specified norm or other normalization criterion. |
| **Text Normalization** | Transforming textual representations into a consistent format. |
| **Image Normalization** | Adjusting image intensity values to a specified range or distribution. |
| **Signal Normalization** | Rescaling signal values according to a reference magnitude or statistical property. |
| **Canonical Normalization** | Transforming different representations into a common canonical form. |
| **Unicode Normalization** | Transforming text into standardized Unicode representations. |
| **Normalization in Physics** | Adjusting mathematical representations, such as wave functions, to satisfy specified normalization conditions. |
| **Ratio Reduction** | Expressing a ratio using smaller, equivalent numerical values, typically by dividing both terms by their greatest common divisor. |
| **Unitization** | Expressing a quantity relative to a unit or reference quantity. |
