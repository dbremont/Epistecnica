# Positive-definite Kernel

 : Reproducing Kernel Hilbert Space (Reproducing%20Kernel%20Hilbert%20Space%20464b47a44ed04b8eb1ea93386888e40b.md), Metric Space (Metric%20Space%20a96a5c7274d445188d654c88e86e43a0.md)

> A **positive-definite kernel** is a **bivariate function**: $k : X \times X \to \mathbb{R} \text{ (or } \mathbb{C})$ It defines a generalized inner product between inputs in some (possibly infinite-dimensional) feature space, but it is not itself an operator.
> 

> Note:  The word kernel have many meanings in linear algebra, operator theory, …
