## Encodings Mechanism

> How do we build number systems?
> 

> **Sign-Value Notation (Non-Positional Encoding):**  Uses distinct symbols for specific values; the total value is the sum of these symbols.
> 

> **Positional Notation:** A numeral system in which the value of each digit is determined by its position, where each position corresponds to a power of the base; the overall value is obtained by multiplying each digit by the base raised to its positional power and summing the results.
> 

## Numeric System

> A **numeral system** is a writing system for expressing numbers using digits or symbols in a consistent and standardized manner.
> 

| Numeric System | Descriptions | Characterization |
| --- | --- | --- |
| **Indo-Arabic Numerals** | The most widely used numeral system in the world today consists of ten digits from 0 to 9. | The positional decimal system, base-10, includes zero |
| **Roman Numerals** | The numeral system originated in ancient Rome and used combinations of letters from the Latin alphabet. | Non-positional, additive, and subtractive principles |
| **Chinese Numerals** | A traditional numbering system is used in China, and it includes complex and simple forms. | Non-positional, various forms for different contexts |
| **Mayan Numerals** | The Maya civilization used a vigesimal (base-20) system. | Positional includes zero, uses dots and bars |
| **Babylonian Numerals** | The ancient Babylonians used a base-60 (sexagesimal) numeral system. | Positional, base-60, uses wedge-shaped cuneiform symbols |
| **Greek Numerals** | A numeral system using the Greek alphabet where each letter has a numeric value. | Non-positional, alphabetic |
| **Hebrew Numerals** | A system using the Hebrew alphabet for numbers. | Non-positional, alphabetic |
| **Egyptian Numerals** | A non-positional system using hieroglyphs to represent numbers. | Non-positional, hieroglyphic |
| **Binary Numerals** | A base-2 numeral system used in digital electronics and computer science. | Positional, base-2 |
| **Octal Numerals** | A base-8 numeral system is often used in computing. | Positional, base-8 |
| **Hexadecimal Numerals** | A base-16 numeral system used in computing and digital electronics. | Positional, base-16 |
| **Quinary Numerals** | A base-5 numeral system used in various ancient cultures. | Positional, base-5 |
| **Duodecimal Numerals** | A base-12 numeral system used in multiple ancient cultures. | Positional, base-12 |
