# Decomposition

 : Representation (Representation%20262c0f5171ec8021a535fc9111fd1ed5.md)

> In mathematics, **decomposition** is the process of expressing a mathematical object as a combination of simpler, more fundamental components, usually in such a way that the original object can be reconstructed from those components.
> 

> In mathematics, to decompose is to rewrite a complicated object as a sum, product, or collection of simpler, more structured objects — usually orthogonal, independent, or canonical — so that the original object becomes easier to analyze, manipulate, and understand.
> 

> Decomposition is one of the key techniques in mathematics - [Core Technique](https://app.notion.com/p/Core-Technique-26ec0f5171ec8042b22ad701a67e136e?pvs=21).
> 

### **Object Being Decomposed**

> Which mathematical objects are subject to decomposition?
> 

| **Mathematical Object** | **Case** |
| --- | --- |
| **Number** | Prime factorization |
| **Function** | Fourier series, Taylor expansion |
| **Vector** | Sum of basis vectors |
| **Matrix / Linear Operator** | LU decomposition, SVD, Spectral theorem |
| **Topological Space** | Decomposition into connected components, simplicial complexes |
| **Probability Distribution** | Mixture models, independent components |

## Technique Space

| **Technique** | **Description** |
| --- | --- |
| **Basic Decomposition** | Writing an object as a sum, product, or union of simpler objects. |
| **Orthogonality** | Components have zero inner product; fundamental in linear algebra and Hilbert spaces. |
| **Perpendicularity** | Special case of orthogonality in Euclidean geometry. |
| **Independence** | Linear independence; no component is a linear combination of the others. |
| **Factorization** | Expressing an object as a product of simpler factors (numbers, polynomials, matrices, operators). |
| **Projection** | Decomposing a vector into components along chosen subspaces. |
| **Basis Expansion** | Representing vectors/functions as linear combinations of basis elements. |
| **Spectral Decomposition** | Expressing a matrix/operator in terms of its eigenvalues and eigenvectors. |
| **LU / QR / Cholesky Decomposition** | Breaking matrices into products of triangular or orthogonal factors. |
| **Jordan Decomposition** | Representing a linear operator in its Jordan canonical form. |
| **Singular Value Decomposition (SVD)** | Expressing a matrix as orthogonal–diagonal–orthogonal factors. |
| **Tensor Decomposition** | Generalizing factorization to multidimensional arrays (CP, Tucker decompositions). |
| **Fourier / Wavelet Decomposition** | Representing functions as sums of orthogonal basis functions. |
| **Series Decomposition** | Expressing functions as power series, Laurent series, etc. |
| **Partial Fraction Decomposition** | Breaking rational functions into simpler fractions. |
| **Direct Sum Decomposition** | Representing a vector space as a direct sum of subspaces. |
| **Primary Decomposition** | Decomposing ideals into intersections of primary ideals (algebraic geometry). |
| **Manifold Decomposition** | Breaking a manifold into charts or simpler topological pieces. |
| **Spectral Theorem Applications** | Decomposing self-adjoint or normal operators into integrals over spectra. |

## Use

| **Mathematical Area** | Case |
| --- | --- |
| **Algebra** | Factorization of numbers, polynomials, modules, ideals |
| **Linear Algebra** | Basis expansion, direct sum decomposition, diagonalization, spectral decomposition |
| **Analysis** | Fourier series, orthogonal expansions, measure decomposition |
| **Topology & Geometry** | Manifold charts, cell decomposition, homology built from simplices |
| **Probability & Statistics** | Independence decomposition, mixture models, variance decomposition |
| **Category Theory** | Products, coproducts, limits, colimits — ways to break and reassemble structures |
