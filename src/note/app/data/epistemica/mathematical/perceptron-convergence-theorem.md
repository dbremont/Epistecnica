# Perceptron Convergence Theorem


> The **Perceptron** Convergence Theorem states that if a dataset is linearly separable with margin $\delta > 0$ and input vectors bounded by norm $R$, the **perceptron** algorithm will correctly classify all points after at most $\frac{R^2}{\delta^2}$ updates.
