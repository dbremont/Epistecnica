# Green's Function

 : Integral Operator (Integral%20Operator%20100c0f5171ec804e8f36d1066c3679d2.md)

> A **Green's function** (or **Green function**) is the [impulse response](https://en.wikipedia.org/wiki/Impulse_response) of an [inhomogeneous](https://en.wikipedia.org/wiki/Inhomogeneous_ordinary_differential_equation) linear [differential operator](https://en.wikipedia.org/wiki/Differential_operator) defined on a domain with specified initial conditions or boundary conditions.
