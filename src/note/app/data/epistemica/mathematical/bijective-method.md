# Bijective Method

 : Enumeration (Counting) (Enumeration%20(Counting)%20256c0f5171ec80ec80dfdcb8bc82d1e6.md), Function (Function%20049537a4fd564eaaac4bae443839b0c0.md)

> The **Bijective Method** is a **problem-solving technique in combinatorics** where one solves a counting problem (or proves an identity) by establishing a **bijection**—a one-to-one correspondence—between two sets.
> 

> If two finite sets $A$ and $B$ can be placed in a bijection (i.e. a one-to-one and onto mapping $f\colon A\to B$), then $\lvert A\rvert=\lvert B\rvert$. Note: That in practice we have to build the set B; which is an encoding of set A,  but easier to count.
> 

> Note: This is an instance of  larger problem-solving - structural technique - transformation.
> 

## Case Study

### Walks
