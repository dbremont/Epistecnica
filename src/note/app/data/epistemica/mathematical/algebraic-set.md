# Algebraic Set


> An **algebraic set** is the set of common solutions in affine space (e.g., $\mathbb{A}^n$) to a collection of polynomial equations with coefficients in a field $k$; it is the geometric realization of an ideal in a polynomial ring $k[x_1, \dots, x_n]$.
