# Control Theory


> **Control theory** is a branch of **engineering** and **mathematics** that deals with the behavior of dynamical systems and how to manipulate their outputs to achieve desired outcomes.
> 

> A control system manages, commands, directs, or regulates the behavior of a system.
> 

| **Algorithm** | **Type** | **Description** | **Common Applications** |
| --- | --- | --- | --- |
| **Proportional (P)** | Linear | Adjusts control output based on the present error. | Simple temperature or speed control. |
| **Proportional-Integral (PI)** | Linear | Adds integral action to eliminate steady-state error. | Motor speed control, HVAC systems. |
| **Proportional-Derivative (PD)** | Linear | Adds derivative action to improve response time. | Robotics, drones, stabilizers. |
| **Proportional-Integral-Derivative (PID)** | Linear | Combines P, I, and D for optimal control. | Industrial automation, process control. |
| **Bang-Bang (On-Off)** | Nonlinear | Switches between two states (on/off) based on threshold. | Thermostats, refrigerators, simple switches. |
| **Model Predictive Control (MPC)** | Advanced | Uses a dynamic model to predict future system behavior. | Chemical plants, autonomous vehicles. |
| **Adaptive Control** | Adaptive | Adjusts control parameters in real-time. | Aerospace, machining, complex automation. |
| **Fuzzy Logic Control** | Intelligent | Uses rule-based logic instead of precise equations. | Consumer electronics, automotive systems. |
| **Neural Network Control** | AI-Based | Uses machine learning to adaptively control systems. | Robotics, smart automation, finance. |
| **Sliding Mode Control (SMC)** | Nonlinear | Maintains control despite disturbances using discontinuous control laws. | Aerospace, robotic arms, power electronics. |
| **Optimal Control (LQR, LQG)** | Optimization-Based | Minimizes a cost function to achieve the best performance. | Spacecraft control, economic modeling. |
