# Descartes’s Method

Related: [Epistemology](note.html?n=epistemica/theory/practice/general/epistemology.md), [Philosophical System](note.html?n=epistemica/theory/practice/method/philosophical-system.md)

> **Rationalism**
> 

> An Epistemological Framework.
> 

> Doubt → Certainty (Cogito) → Trust in reason (with God’s assurance) → Knowledge of world.
> 

| Step | Principle | Description |
| --- | --- | --- |
| 1 | **Doubt Everything** | Accept nothing as true unless it is clearly known to be so; avoid assumptions. |
| 2 | **Divide Problems** | Break every problem into as many parts as possible to better solve it. |
| 3 | **Order Thoughts** | Start with the simplest, easiest things to know, and gradually move to more complex ones. |
| 4 | **Review Thoroughly** | Make comprehensive reviews to ensure nothing is omitted or overlooked. |

| Concept | Description |
| --- | --- |
| **Methodic Doubt** | Start by doubting everything that can possibly be doubted, to find what is absolutely certain. |
| **Cogito, ergo sum** | "I think, therefore I am." The first indubitable truth: even if everything else is false, the fact that one is thinking proves existence. |
| **Clear and Distinct Perceptions** | Descartes believes that whatever is perceived very clearly and distinctly must be true. This becomes a basic rule for true knowledge. |
| **Innate Ideas** | Some ideas (like the idea of God, or basic mathematical truths) are inborn, not learned from experience. |
| **God as Guarantor of Truth** | A perfect, non-deceiving God ensures that clear and distinct perceptions are trustworthy. Without God, there would be no guarantee that our reason isn’t defective. |
| **Mind-Body Dualism** | Knowledge of the self (mind) is certain and different from knowledge of the body (material things), which is less immediately certain. |
