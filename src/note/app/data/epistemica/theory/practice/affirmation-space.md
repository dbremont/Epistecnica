# Affirmation Space

Related: [Modelling](note.html?n=epistemica/theory/practice/modelling.md)

> An **Affirmation Space** is a powerful idea that attempts to capture the full set of possible affirmations that can be made about something.
> 

> It represents the most **fundamental questions** one can ask about a subject.
