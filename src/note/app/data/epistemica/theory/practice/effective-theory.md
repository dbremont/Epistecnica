# Effective Theory

> An **effective theory** is a simplified scientific model that accurately describes phenomena within a specific range of conditions or scales, without claiming to capture the underlying fundamental laws.
> 

## Case

| Discipline | Effective Theory | Phenomena Modeled | Level of Abstraction |
| --- | --- | --- | --- |
| Physics | Newtonian Mechanics | Motion of objects at everyday speeds | Ignores relativistic and quantum effects |
|  | Thermodynamics | Heat, work, energy transfer | Ignores individual particle dynamics |
|  | Fluid Dynamics (Navier–Stokes) | Fluid flow | Ignores molecular interactions |
|  | Hooke’s Law | Elastic deformation | Ignores atomic lattice details and plasticity |
|  | Effective Field Theory (e.g., Chiral Perturbation) | Low-energy particle interactions | Ignores high-energy fundamental dynamics |
| Economics | Keynesian Economics | Short-run macroeconomic behavior | Ignores full micro-level agent interactions |
|  | IS-LM Model | Interest rates and output | Ignores some market frictions and expectations |
|  | Supply & Demand Curves | Price-quantity relationships | Ignores individual agent heterogeneity |
|  | Solow Growth Model | Long-term economic growth | Ignores microfoundations of innovation and behavior |
|  | Behavioral Economics Heuristics | Simplified decision-making | Ignores full cognitive and neural processes |
| Behavioral Sciences | Prospect Theory | Decision-making under risk | Ignores neural implementation |
|  | Reinforcement Learning Models (Psychology) | Behavior shaped by rewards/punishments | Ignores detailed neurobiology |
|  | Theory of Planned Behavior | Intentions and actions | Ignores complex social network effects |
|  | Cognitive Load Theory | Learning performance | Ignores neural and detailed cognitive mechanisms |
|  | Classical Conditioning | Stimulus-response learning | Ignores brain-level mechanisms |
