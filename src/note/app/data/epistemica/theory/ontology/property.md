# Property

Related: [Ontology](note.html?n=epistemica/theory/practice/general/ontology.md), [Principle](note.html?n=epistemica/theory/ontology/principle.md)

> In this note we will explore the abstract concept - of a property - that describes a characteristic, attribute, or quality that an object, entity, or system can have. It is a **meta-level descriptor** rather than a concrete object itself.
> 

> **`Property`** is a meta-concept, arising from reflection on the set of all properties—such as redness, evenness, oddness, and so on. Each individual property is itself a concept, and we do not need to explicitly recognize them as properties; this understanding is part of the human cognitive apparatus.
> 

> A **`property`** is a concept through which we ascribe an abstract attribute, characteristic, or predicate to an object.
> 

> **Note:** In computer science, the concept of a property is different; there, it refers to a **piece of state of an object or data structure, a part → value.**
> 

> Note: That every statement about the reality - can be frame as a **property**.
>

## Formulation

> Properties are *expressed*, as meanings, by *predicates*.
> 

> A **property** is an abstract concept that can be formalized as a **predicate** over a domain of objects. Formally, let $\mathcal{D}$ be a set of objects.
> 

> A property $P$ is a function: $P: \mathcal{D} \to \{ \text{True}, \text{False} \}$ such that for each object $x \in \mathcal{D}$, $P(x) = \text{True}$ if and only if $x$ possesses the property $P$.
> 

> Equivalently, a property can also be represented as the **subset of objects** in $\mathcal{D}$ that satisfy it: $\llbracket P \rrbracket = \{ x \in \mathcal{D} \mid P(x) = \text{True} \}$.
>

## Theory

> What are the theories or varieties of conceptualization of property?
> 

| **Theory (Variety)** | **Note** |
| --- | --- |
| **Aristotelian Essential/Accidental** | Properties are predicates of substances; essential properties define the substance, accidental ones do not. |
| **Lockean Ownership / Legal** | Property refers to rights or ownership over objects; introduces social and legal dimensions. |
| **Descartes Primary/Secondary** | Distinguishes between intrinsic (primary) properties like extension, and perception-dependent (secondary) properties like color. |
| **Humean Bundle Theory** | Properties are bundles of sensory impressions; objects are collections of these properties. |
| **Kantian Phenomenal/Noumenal** | Properties are structured by human cognition; we perceive attributes (phenomena), not things-in-themselves. |
| **Analytic / Logical (Russell, Moore)** | Properties formalized as **universals or predicates**, foundational for logic and mathematics. |
| **Metaphysical Realism (Armstrong)** | Properties are **real universals** that exist independently of observers. |
| **Nominalism (Quine)** | Properties are **conceptual constructs** or names; only particulars exist. |

> Is color a property, or the color red is the property?
> 

> We enter deep philosophical waters with this question. One might say that **color** is a category or abstract property, and that the specific property is the value (e.g., red, blue, green).
