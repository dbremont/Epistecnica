Epistecnica

Epistecnica is a unified framework for the two fundamental dimensions of human agency: knowing (Epistemica) and acting (Tecnica).

Epistemica describes how an agent knows; Tecnica describes how an agent acts. Epistecnica brings both under a common index, deployment, and set of conventions, without collapsing their conceptual distinction or their independence as subprojects.

Entry Guidance

I want to see how things connect
Epistemica graph or Tecnica graph — read-only viewers with filters, search, minimap.
I want to author or edit
Epistemica editor or Tecnica editor — AI-assisted authoring; saves through the sync server.
I want to see the notes
the notes catalog — search and read the markdown notes and live notebooks behind both ontologies.
I want to take a course
the courses catalog — one directory per course: an entry plus a set of lectures.
I want to read a paper
the documents catalog — papers, articles, and books as markdown entries with references.
I want a typed note
the personas catalog — a new type of note, each entry carrying a type.
I want to look up a term
the glossarium — the lexical corpus behind both ontologies; select any word on the note pages for its definition.
