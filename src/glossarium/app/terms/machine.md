# Machine

> **Machine** is a drive, motion or power package that actuates a tool or equipment.

A canonical `Production Support` kind, distinct from the tool it drives and from the producer it serves: the tool bears on the workpiece, the machine supplies the motion. The machine-tool is the historical union of both.

The machine marks the point at which technical labor is transferred from the human body to an external power source — the beginning of the technical system proper.


## Technical reading

Read as a **technical machine**, the term names a drive, motion or power package that actuates a tool or equipment — the element that supplies energy and motion rather than contact or measurement. The distinction from a tool is functional: a machine without a tool does no work on the material, and a tool without a machine does only what human power supplies.
