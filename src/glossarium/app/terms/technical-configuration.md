# Technical Configuration

> A **Technical Configuration** is a particular arrangement of technical components and their relations — at a moment, or as a design.

> Configuration is the *arrangement*, not the parts: two assemblies with the same components differ technically by configuration alone, which is why a diff is a technical statement.

The term sits between [structure](/glossarium/?t=structure) and [state](/glossarium/?t=technical-state). Structure is the organization that stays the same across arrangements; a configuration is one such arrangement; a state is the configuration together with the values of its parameters at a time. A change of configuration that leaves the structure intact is a modification; one that alters the structure is a transformation.
