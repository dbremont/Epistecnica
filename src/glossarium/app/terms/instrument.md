# Instrument

> **Instrument** is an implement that measures, indicates, regulates or monitors a production variable.

Canonically the `Production Instrument`, a `Production Support` kind: it does not transform the good, it makes a variable observable or controllable. The instrument is what allows a process to be evaluated and a specification to be verified.

Instruments extend the senses as tools extend the hands; together they are the material basis of technical evaluation.


## Technical reading

Read as a **technical instrument**, the term names an implement that measures, indicates, regulates or monitors a variable — the element whose function is information rather than transformation. Instruments are what make a process observable and therefore controllable, and their own accuracy is a technical property of the measurement, not of the process.
