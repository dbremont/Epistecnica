# Characterization Element

Related Glossarium: Characterization System, Dimension, Property

> A **characterization element** is the atomic unit of a profile: one **dimension**, one assigned **category**, and the **mapping rule** applied to one case — e.g. {dimension: governance arrangement, value: board-governed, rule: a governing board appoints the chief executive}.

A characterization system with D dimensions yields D characterization elements per instance. Comparison proceeds element by element: same dimension, different values, across cases.

## What it is not

- **Not a property**: a [Property](index.html?t=property) is a trait a thing exemplifies; an element is that trait *as assigned by a system* — dimension plus value plus rule. The same property can appear in different elements of different systems.
- **Not a characteristic**: a [Characteristic](index.html?t=characteristic) distinguishes a thing from others; an element need not distinguish — two instances may share every element and still differ off-system.
- **Not system-free**: an element is always relative to a system version. Change the dimensions, categories, or rules and the elements change with them (see [Characterization System](index.html?t=characterization-system)).
