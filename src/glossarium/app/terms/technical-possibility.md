# Technical Possibility

> **Technical Possibility** is a conceivable technical configuration or transformation that could be realized under specified conditions.

> Possibility is bounded by knowledge, materials, techniques and components — not by imagination alone. What is possible at one moment is a fact about the state of the technical element space, not about the boldness of the designer.

The concept is the modal counterpart of the [technical element space](/glossarium/?t=technical-element-space): the space is what exists, and possibility is what the existing set makes reachable. A possibility can be conceivable and unrealizable (the material does not exist), realizable and unaffordable, or affordable and unwanted — and each failure occurs at a different point in the [realization chain](/glossarium/?t=technical-element-realization-chain).

Keeping possibility separate from [potential](/glossarium/?t=technical-potential) prevents a common confusion: possibility is about a configuration, potential is about the capacity of the existing stock to enable configurations.
