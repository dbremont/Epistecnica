# Technical Research Problem

> A **Technical Research Problem** is a specific unresolved problem concerning the constitution, behaviour, performance or transformation of a technical element.

> It is a [technical problem](/glossarium/?t=technical-problem) that has been narrowed to the point where an investigation can address it: a gap in knowledge, not merely a gap in performance.

The distinction between a technical problem and a technical *research* problem is the difference between *this fails* and *we do not know why this fails, or whether it can be made not to*. The first calls for a fix; the second calls for inquiry, and it is only well posed when the unknown is named — the mechanism, the limit, the condition, the possibility.
