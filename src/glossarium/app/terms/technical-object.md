# Technical Object

> **Technical Object** is a structural artifact that embodies operational techniques into a stable, reproducible system with defined interfaces and invariants.

The canon distinguishes the `Production Technical Object` — the object produced within a production system and intended to enable action or further production, physical or virtual — from the `Constitutive Technical Object`, the component or sub-assembly that constitutes a larger object or system.

A technical object is not the same as the technique it embodies: the technique is the procedure, the object is the stabilized arrangement that carries it.
