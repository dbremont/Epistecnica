# Technical Control

> **Technical Control** is the regulation of a technical process or system to maintain or achieve a specified state or behaviour.

> Control requires a reference — the state or behaviour that is wanted — and a means of acting on the process when it deviates. Without the reference there is only influence, not control.

Control is the practical form of the state vocabulary: a [state](/glossarium/?t=technical-state) is identified, a reference state is specified, a deviation is measured, and an action is taken. The classical distinction is between open-loop control (the action is fixed in advance and does not use the result) and closed-loop control (the action is corrected by [feedback](/glossarium/?t=technical-feedback)).

Control is also where the technical and the institutional meet: a process can be technically controllable and institutionally uncontrolled, and the second failure is not repaired by better instrumentation.
