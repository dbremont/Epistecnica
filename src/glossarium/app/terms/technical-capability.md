# Technical Capability

> **Technical Capability** is a value-producing possibility enabled by a technical function.

A canonical Kind of `Technical Element` (Classification; Capability). Function is what the element does; capability is the possibility that function enables. Idle, the capability is latent; running, the function is exercised.

Capability is not to be confused with property, quality or performance: the property is attributable, the quality is the degree to which desirable properties are possessed, and performance is the realized quantitative behaviour under specified conditions.
