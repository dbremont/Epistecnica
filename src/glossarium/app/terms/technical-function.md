# Technical Function

> A **Technical Function** is a transformation, service or effect that a technical element is designed or capable of producing.

> Function is ascribed, not observed: nothing in the artifact's physics says *this is for cutting*; the ascription is made by a practice, and it is what makes the artifact an element of that practice rather than an object.

The function/mechanism/process triad answers three different questions about the same element: *what is it for* (function), *how is it organized to do that* (mechanism), and *how does it run* (process). Capability is the value the function enables; performance is how well it is done.

The corpus long had capability and mechanism without function, and the gap showed: a capability without a function is a value with no bearer, and a mechanism without a function is an arrangement with no purpose. The three terms are now defined together.
