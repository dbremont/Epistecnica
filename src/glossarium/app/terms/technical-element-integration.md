# Technical Element Integration

> **Technical Element Integration** is the incorporation of a technical element into an existing architecture or operational environment.

> Integration is where an element meets the interfaces it did not design: the standard, the legacy system, the workflow, the maintenance regime.

Integration is the technical content of adoption. An element that works in isolation can fail on contact with an architecture — because its interfaces do not match, its performance envelope is narrower than the incumbent flow requires, or its failure modes are not contained by the surrounding system. The engineering of integration is largely the engineering of these mismatches.

See [Technical Architecture](/glossarium/?t=technical-architecture) and [Technical Interface](/glossarium/?t=technical-interface).
