# Technical Code

> **Technical Code** is the technical realization of a social interest or ideology: the design decisions through which an artifact embodies, and thereby enforces, a particular distribution of power, access or obligation.

A technical code is not a conspiracy added to a neutral object; it is the ordinary result of designing under assumptions about who the user is, what counts as efficient, and whose convenience is served. The code is legible in the artifact's requirements — the step height that excludes, the default that presumes, the interface that decides who may act.

The concept is the critical-theory counterpart of the empirical symmetry principle: where the social-construction reading shows that interests shape the artifact, the technical code names the form that shaping takes once the artifact is in use.
