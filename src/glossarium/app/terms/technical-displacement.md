# Technical Displacement

> **Technical Displacement** is the replacement or supersession of an existing technical element by another in the role the first occupied.

> Displacement is a relation between elements, not a property of either: the displaced element need not be worse, and the displacing one need not be new — it need only take over the role.

Displacement is the mechanism by which a technical element space changes shape: the variety does not simply grow, it is reoccupied. Its common pattern is not the superior artifact defeating the inferior one but the new element occupying a niche the incumbent could not serve — cheaper, smaller, more maintainable — and then expanding from that niche into the incumbent's role.

See [Technical Obsolescence](/glossarium/?t=technical-obsolescence) for the state of the displaced element, and [Lock-in](/glossarium/?t=lock-in) for the case in which displacement fails despite a better alternative.
