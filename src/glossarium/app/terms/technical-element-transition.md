# Technical Element Transition

> A **Technical Element Transition** is the passage of an element from one technical state to another — by adjustment, modification or replacement.

> Not to be confused with a [technological transition](/glossarium/?t=technological-transition), which is a shift between sociotechnical regimes. The element transition is about one element's state; the regime transition is about a field's rule-set.

The distinction is the difference between a biography and a history. An element transition is observable in the element: the pump that was rebuilt, the protocol that gained a field, the material that was substituted. A regime transition is observable in the field: which designs are considered legitimate, which firms and institutions carry them, and which selection environment applies.

Both use the word *transition*, and keeping them apart is what prevents a single case from being asked to prove two different claims.
