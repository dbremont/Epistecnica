# Technical Agent

> **Technical Agent** is an entity capable of executing techniques using tools, resources and knowledge.

A canonical Kind of `Technical Element` (Classification; Agency). The agent is the bearer of technical labor and technical competence: the person, team or organization that performs the act.

Agency is not the same as competence: an agent may act without yet being competent, and a competence may exist in an institution rather than in a single person.
