# Technique

> In [Ancient Greek philosophy](https://en.wikipedia.org/wiki/Ancient_Greek_philosophy), **techne** ([Greek](https://en.wikipedia.org/wiki/Greek_language): [τέχνη](https://en.wiktionary.org/wiki/%CF%84%CE%AD%CF%87%CE%BD%CE%B7#English), [romanized](https://en.wikipedia.org/wiki/Romanization_of_Greek): *tékhnē*, [lit.](https://en.wikipedia.org/wiki/Literal_translation) 'art, skill, craft'; [Ancient Greek](https://en.wikipedia.org/wiki/Ancient_Greek_language): [[tékʰnɛː]](https://en.wikipedia.org/wiki/Help:IPA/Greek), [Modern Greek](https://en.wikipedia.org/wiki/Modern_Greek): [[ˈtexni]](https://en.wikipedia.org/wiki/Help:IPA/Greek)) is a philosophical concept that refers to making or doing.
> 

In the technica corpus, **technique** has a more specific sense: a procedure for performing a class of technical operations, held in the chain `Technical Practice → Technical Task → General Technique → Operative Technique → Constitutive Technique → Technical Act`.

> The **general technique** is the generalized method for a class of operations; the **operative technique** is its situated application by an agent to a particular situation; the **constitutive technique** is the technique embodied in a technical element, establishing the internal dynamic logic through which that element operates.

A technique is not a practice — the practice is the recurring whole that organizes tasks, techniques, principles, standards and tools — and it is not an act, which is the primitive doing. The technique is the procedure itself.


## Technical reading

Read as a **technical technique**, the term names the reproducible way of performing a technical operation or achieving a transformation — the pattern an operation follows, as distinct from the [technical method](/glossarium/?t=method) that organizes several techniques toward an inquiry, and from the [technical operation](/glossarium/?t=technical-operation) that is the single act. In the technica decomposition a technique is an element type with its own subtree (practice → task → general technique → operative technique → constitutive technique → technical act); read as a technical term, it is the repeatable competence-bearing pattern itself.
