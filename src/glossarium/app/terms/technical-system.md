# Technical System

> **Technical System** is an organized set of technical objects whose interaction realizes a technical capability.

The canon names the composite precisely: a `Production Technical System` is a set of production technical objects, and it may contain further systems and whole `Technical Element Set`s — practices, tooling sets — besides its objects.

The system is not a bigger object: the objects are its members, the capability is its result, and the interaction is what the system adds to the set.
