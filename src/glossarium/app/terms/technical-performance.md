# Technical Performance

> **Technical Performance** is the observable result a technical element produces under specified conditions.

> Performance is measured, not asserted: it is always relative to a condition and a measure, and a performance claim without either is a claim about nothing in particular.

Performance is the input to the evaluation vocabulary: [efficiency](/glossarium/?t=technical-efficiency) relates it to resources consumed, [effectiveness](/glossarium/?t=technical-effectiveness) relates it to intended objectives, [reliability](/glossarium/?t=technical-reliability) relates it to time and conditions, and [quality](/glossarium/?t=technical-quality) relates it to requirements. A single number is rarely enough, because the four relations can move in opposite directions.

See [Technical Evaluation](/glossarium/?t=technical-evaluation).
