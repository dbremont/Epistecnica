# Technical Dependency

> A **Technical Dependency** is a relation in which one technical element requires another to operate or to exist.

> Dependency is directional and typed: to require a power supply is not the same as to require a standard, a supplier or a skill, and each fails differently.

Dependencies are what turn a set of elements into a structure, and what makes change propagate: a modification to a depended-on element is a change to every element that depends on it. The practical vocabulary distinguishes **functional** dependency (needs its output), **technical** dependency (needs its interface or standard), **supply** dependency (needs its producer) and **competence** dependency (needs someone who can work with it).
