# Technical Combination

> **Technical Combination** is the formation of a new technical configuration by combining existing elements.

> Combination is the main engine of technical variety: most new elements are not invented from nothing but assembled from elements that already exist, in an arrangement that did not.

The concept explains why a technical element space is path-dependent in a way that a list of inventions is not: what can be combined depends on what is present, on whether the interfaces are compatible, and on whether the combiners know both domains. Combination is also the mechanism behind the recombination of existing techniques into a new practice — the case where nothing is invented and everything changes.

See [Technical Configuration](/glossarium/?t=technical-configuration) for the result and [Technical Element Space Evolution](/glossarium/?t=technical-element-space-evolution) for the population effect.
