# Technical State

> A **Technical State** is the identifiable configuration of a technical element at a particular point in time — its arrangement plus the values of its parameters.

> The state is the snapshot reading of an element. It is what a measurement, a log or a drawing records, and what a change is defined against.

The concept is what makes [technical change](/glossarium/?t=technical-change) statable: change is a difference between two states, and without a way to identify a state the claim that something changed has no content. A state is always identified relative to a purpose — the parameters that matter for control are not the ones that matter for maintenance — so two state descriptions of the same element can both be correct and not comparable.

See also [Technical Evolution](/glossarium/?t=technical-evolution), which is the sequence of states read historically.
