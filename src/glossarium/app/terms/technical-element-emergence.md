# Technical Element Emergence

> **Technical Element Emergence** is the initial appearance of a technical element — a new configuration recognized as a distinct possibility.

> Emergence is not yet invention and not yet existence: it is the moment at which a configuration becomes conceivable as a separate element rather than a variation of an existing one.

The state is relational: whether an arrangement counts as an emergent element or as a modification of an incumbent depends on the identity judgement applied to it. That judgement is often retrospective — a variant is recognized as a new element only after it has been separated by use, standardisation or a distinct community of practice.
