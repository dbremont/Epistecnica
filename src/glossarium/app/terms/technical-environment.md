# Technical Environment

> A **Technical Environment** is the set of conditions and surrounding elements within which technical objects and practices operate.

> Environment is whatever the element does not control but must accommodate: climate, supply, regulation, competing systems, the skills available around it.

The term is relational — an environment is always an environment *for* an element, and changes when the element's boundary changes. Its analytical use is to separate what the element must survive from what it may presume: a design is adequate relative to an environment, and most field failures are environments that were not in the specification.

See [Technical Constraint](/glossarium/?t=technical-constraint) and [Technical Adaptation](/glossarium/?t=adaptation).
