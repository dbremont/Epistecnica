# Technical Element Trajectory

> A **Technical Element Trajectory** is the historically extended sequence of changes through which a technical element develops.

> Not to be confused with a [technological trajectory](/glossarium/?t=technological-trajectory), which is the direction a field follows under a shared paradigm. The element trajectory traces one element; the field trajectory traces the problem-space a community walks.

The element trajectory is cumulative in the narrow sense: each state is reached from the previous one, and the path constrains the next move. It is not, however, a single line — an element can branch into variants, be recombined, or be re-derived from a different principle entirely, in which case the trajectory is discontinuous and the element is arguably replaced.

Reading a trajectory requires deciding which changes count as the same element continuing and which count as a new one. That decision is not given by the artifact; it is a judgement about identity, and it should be stated.
