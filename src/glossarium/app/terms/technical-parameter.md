# Technical Parameter

> **Technical Parameter** is a variable whose value characterizes or controls a technical object or process.

A canonical Kind of `Technical Element` (Classification; Requirements). The parameter is the handle through which a design is tuned and a process is controlled: temperature, pressure, tolerance, throughput, gain.

Parameters are what a pilot plant measures and a specification fixes; without them a requirement remains a wish rather than an operational target.
