# Technical Value Chain

> A **Technical Value Chain** is the connected set of activities through which technical elements acquire additional capability, functionality or economic value, from conception through production and deployment.

> It is not the [realization chain](/glossarium/?t=technical-element-realization-chain): the realization chain is the sequence one element passes through, the value chain is the set of activities across which capability and value are added — often across several elements, firms and sites.

The concept joins the technical and the economic readings of the same sequence of activities. Each link adds something the next link needs — a design, a component, a process, an assembly, a service — and the chain's shape determines where capability accumulates and where it is captured.

The value-chain reading is what makes questions of upgrading askable: a firm or a country can occupy a link with high technical content and low value capture, or the reverse, and the difference is not visible from the element's technical description alone.
