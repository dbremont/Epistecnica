# Technical Representation

> A **Technical Representation** is a representation of the structure, properties, behaviour or operation of a technical element — a drawing, a schema, a set of equations, a data structure, a simulation.

> Representation is not a copy: it selects the aspects that matter for a purpose and drops the rest. Two representations of the same element can both be correct and not interchangeable, because they answer different questions.

The concept is the genus of [technical model](/glossarium/?t=technical-model), [blueprint](/glossarium/?t=technical-blueprint) and [specification](/glossarium/?t=technical-specification), and the condition of possibility of technical work at a distance: an element can be designed, reviewed, built, operated and maintained by people who never see it, because a representation stands in for it.

Representations carry their own failure modes — the drawing that omits a tolerance, the schema that hides a dependency, the model that is precise about the wrong variable — and those failures are technical failures of the representation, not of the element it represents.
