# Technical Blueprint

> **Technical Blueprint** is a generative description prescribing how to create, assemble or configure an artifact.

A canonical Kind of `Technical Element` (Classification; Structure). The blueprint is generative: it is written so that an agent who follows it can produce the object, not merely recognize it.

It is the characteristic output of technical research — the form in which a technique becomes reproducible and transferable — and it is what a reverse-engineering analysis reconstructs.
