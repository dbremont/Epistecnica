# Technical Element Discontinuation

> **Technical Element Discontinuation** is the termination of a technical element's production, operation or institutional support.

> Discontinuation is a normal terminal state, not a verdict: an element can be discontinued because it is obsolete, because it is unsafe, because its supply has ended, or because the practice that needed it has changed.

The state is reached by different routes and they are not equivalent. **Withdrawal** removes support while the element is still in use; **phase-out** ends production while operation continues for a stated period; **retirement** ends operation; **decommissioning** dismantles the physical installation. Keeping the routes apart matters because each leaves a different residual — a stock of users, a maintenance burden, a waste problem, or a capability that no longer exists anywhere.

See [Technical Obsolescence](/glossarium/?t=technical-obsolescence) and [Technical Element Replacement](/glossarium/?t=technical-element-replacement).
