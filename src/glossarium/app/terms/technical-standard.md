# Technical Standard

> **Technical Standard** is a normative specification governing form, function, safety, interoperability or performance.

A canonical Kind of `Technical Element` (Classification; Requirements). A standard constrains a class of elements rather than a single artifact, and it is what allows independently produced objects to compose.

Standards sit beside requirements, specifications and parameters in the guide's requirement family: the standard is the shared norm, the specification the particular statement, the parameter the variable the statement fixes.
