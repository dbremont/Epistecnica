# Technical Process

> A **Technical Process** is an ordered sequence of operations through which a technical transformation occurs.

> Process is the temporal organization of operations: what happens, in what order, with what inputs and outputs, and under which conditions.

Process is not activity. An activity is what agents do; a process is what the transformation does, and it can be specified without naming the agent who performs it — which is what makes automation, standardisation and transfer possible. The same process can be carried by a craft workshop, a production line or a program.

See [Technical Operation](/glossarium/?t=technical-operation) for the unit and [Technical Transformation](/glossarium/?t=technical-transformation) for the result.
