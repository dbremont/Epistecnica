# Technical Element Deployment

> **Technical Element Deployment** is the introduction of a technical element into an operational environment.

> Deployment is the crossing from the controlled conditions of development into the conditions of use — the point at which the element's environment stops being chosen by its makers.

Deployment is a state, not a phase: an element is deployed when it is in service, whether or not it was designed for that environment. Its characteristic risks are integration and support — the interfaces it meets, the maintenance it needs, the skills that must exist on the other side — and these are the risks that pilots and staged rollouts are meant to expose.

See [Technical Element Integration](/glossarium/?t=technical-element-integration) and [Technical Element Persistence](/glossarium/?t=technical-element-persistence).
