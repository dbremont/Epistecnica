# Kernel

> The term kernel names different concepts and objects across multiple disciplines.

## Usage

| **Domain** | **Meaning** | **Description** |
|---|---|---|
| **Mathematics** | Kernel of a function | The set of elements that a function maps to zero; in linear algebra, the null space of a linear transformation. |
| **Mathematics** | Integral kernel | A function appearing inside an integral operator, defining how input values contribute to output values. |
| **Mathematics** | Kernel of a relation | A relation or equivalence structure associated with identifying elements that produce the same result under a mapping. |
| **Mathematics** | Kernel of a homomorphism | The set of elements mapped to the identity element of another algebraic structure. |
| **Mathematics** | Markov transition kernel | A function specifying transition probabilities from one state to another, potentially over continuous state spaces. |
| **Mathematics** | Positive-definite kernel | A symmetric function satisfying positive-semidefiniteness conditions, used in functional analysis and machine learning. |
| **Machine Learning** | Kernel function | A function computing inner products in an implicit feature space, such as the RBF kernel in Support Vector Machines. |
| **Statistics** | Kernel density estimation | A smoothing function used to estimate a probability density from observed samples. |
| **Statistics** | Kernel regression | A non-parametric regression method that estimates relationships using locally weighted observations. |
| **Statistics** | Kernel smoothing | A technique for estimating smooth functions from noisy or discrete observations. |
| **Computer Science** | Operating system kernel | The central component of an operating system responsible for resource management, hardware interaction, memory management, and system calls. |
| **Computer Science** | Database kernel | The core database engine responsible for operations such as query execution, transaction management, and storage management. |
| **Computer Science** | Language kernel | The minimal computational or syntactic core of a programming language. |
| **Computer Science** | Kernel method | An algorithmic approach that uses kernel functions to perform computations in implicit feature spaces. |
| **Signal Processing** | Convolution kernel | A function or discrete matrix applied to a signal or image through convolution. |
| **Image Processing** | Filtering kernel | A matrix of coefficients used to perform operations such as sharpening, blurring, and edge detection. |
| **Physics** | Interaction kernel | A mathematical function describing the strength or structure of interactions between physical entities. |
| **Physics** | Scattering kernel | A function describing the probability or distribution of particles scattering between specified states or directions. |
| **Physics** | Collision kernel | A function describing collision rates between particles of different properties, particularly in kinetic theory. |
| **Physics** | Nuclear kernel | The central nucleus of an atom, although *nucleus* is the more standard scientific term. |
| **Quantum Mechanics** | Propagator kernel | A mathematical function describing the amplitude for a quantum system to transition between two states or spacetime points. |
| **Quantum Mechanics** | Density matrix kernel | The position-space representation of a density operator, describing quantum statistical states. |
| **Numerical Analysis** | Smoothing kernel | A weighting function used to smooth numerical data or approximate continuous quantities. |
| **Numerical Analysis** | Reproducing kernel | A function that allows elements of a reproducing kernel Hilbert space to be evaluated through inner products. |
| **Graph Theory** | Kernel of a directed graph | An independent set of vertices such that every vertex outside the set has an outgoing edge into the set. |
| **Graph Theory** | Graph kernelization | A preprocessing technique that reduces a problem instance while preserving its essential computational properties. |
| **Linguistics** | Kernel sentence | A basic sentence structure from which more complex constructions can be derived in certain linguistic theories. |
| **Logic** | Kernel of a proof system | A minimal or fundamental component of a formal proof system or inference mechanism. |
| **Philosophy** | Kernel of an idea | The essential content or central proposition of an idea or argument. |
| **Food Science** | Grain kernel | The edible seed or fruit of cereal crops, such as wheat, maize, and rice. |
| **Botany** | Seed kernel | The internal portion of a seed, often containing the embryo and nutrient reserves. |
| **Geology** | Kernel of a mineral grain | The central portion of a grain or crystal, sometimes distinguished from its outer growth zones. |
| **Economics** | Kernel of a game | A solution concept in cooperative game theory describing stable coalitions and their payoff allocations. |
| **Economics** | Markov kernel | A conditional probability distribution used in stochastic economic models and dynamic decision processes. |
| **Operations Research** | Kernel of an optimization problem | A reduced or essential representation of a problem, particularly in kernelization and mathematical programming contexts. |
| **Networking** | Kernel networking stack | The operating-system subsystem implementing network protocols and managing packet transmission and reception. |
| **Parallel Computing** | Computational kernel | A fundamental computational routine or unit of work, often executed repeatedly or in parallel on a GPU. |
| **GPU Computing** | GPU kernel | A function executed on a GPU, typically across many parallel threads. |
| **Cryptography** | Kernel of a cryptographic function | The set of inputs mapped to a designated identity or output under a mathematical transformation; relevant particularly to algebraic constructions. |
| **Biology** | Kernel of a biological structure | The central or essential portion of a biological structure; usage varies by subfield. |
| **Agriculture** | Kernel development | The formation and maturation of cereal grains, particularly in maize and wheat. |

## General Thread of Meaning

| Conceptual Usage | What the kernel represents | Example |
|---|---|---|
| **Null set / preimage** | Elements mapped to a designated identity or zero | Kernel of a linear transformation |
| **Function** | A function defining relationships, weights, or interactions | RBF kernel |
| **Operator component** | A function defining an integral or transformation operation | Integral kernel |
| **Probability distribution** | A conditional probability distribution | Markov transition kernel |
| **Computational component** | A fundamental executable unit | GPU kernel |
| **System component** | The central subsystem of a larger system | Operating system kernel |
| **Structural core** | The essential or central part of an object | Grain kernel |
| **Reduced representation** | A smaller equivalent problem representation | Kernelization in parameterized complexity |
