# Technical Problem

> **Technical Problem** is a discrepancy between a current or projected state and a desired technical state that calls for intervention.

A canonical Kind of `Technical Element` (Classification; Context). The problem is not the absence of a solution but the stated gap that makes a solution necessary: it fixes what would count as solved.

Technical research begins by turning a situation into a problem of this form; a problem that cannot be stated as a discrepancy cannot be decomposed, funded or evaluated.
