# Technical Interface

> **Technical Interface** is a defined boundary through which technical elements exchange matter, energy, information or control.

A canonical Kind of `Technical Element` (Classification; Structure). The interface is what makes composition possible: it fixes what may pass, in which form, and under which conditions, and it is the place where a system's parts are joined without being merged.

Interface and actuation are also the point at which an agent's intent enters a technical object — the boundary is acted upon, not merely crossed.
