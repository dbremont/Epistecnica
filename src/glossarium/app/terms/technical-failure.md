# Technical Failure

> **Technical Failure** is the inability of an element to perform an intended function or to satisfy a requirement.

> Failure is defined against a function and a requirement, so it is never a bare event: the same fracture is a failure in one role and a designed outcome in another.

Failure is the most informative event in technical knowledge, because it exposes the assumptions a design was living on. The useful distinctions are **failure mode** (how it fails), **failure mechanism** (the process that produces the mode), and **failure cause** (the condition that triggered it) — and the discipline of analysis is to keep the three apart.
