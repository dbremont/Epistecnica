# Technical Requirement

> **Technical Requirement** is a formalized desired state, need or performance objective a solution must satisfy.

A canonical Kind of `Technical Element` (Classification; Requirements). The requirement states what must be true of the solution; the specification states it precisely enough to verify; the parameter is the variable through which it is measured.

Requirements are the bridge between a technical problem and a technical evaluation: they are what a solution is tested against.
