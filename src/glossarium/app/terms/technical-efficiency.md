# Technical Efficiency

> **Technical Efficiency** is the relation between the resources consumed and the results produced by a technical element.

> Efficiency is a ratio, and a ratio is only as meaningful as the terms it relates: which input, which output, over which period, under which conditions.

Efficiency is not effectiveness. An element can be highly efficient at producing something nobody wanted, and effective at an objective while consuming far more than it needed to. The two are complementary criteria, and a design that optimises one at the expense of the other has traded a technical value for another — not resolved it.

See [Technical Effectiveness](/glossarium/?t=technical-effectiveness) and [Technical Performance](/glossarium/?t=technical-performance).
