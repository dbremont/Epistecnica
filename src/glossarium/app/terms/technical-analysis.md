# Technical Analysis

> **Technical Analysis** is the examination of the structure, properties, behaviour or performance of a technical element, undertaken to explain or predict it.

> Analysis decomposes a whole into what explains its behaviour. It is not testing — testing compares an element to a requirement — and it is not investigation, which opens a question rather than answering one about a known object.

Analysis is the routine that turns an element into a set of statements a designer can act on: which parameters govern which behaviour, which component carries which load, which mechanism produces which effect. Its characteristic failure is the analysis that is precise about the wrong decomposition — a model that answers a question nobody asked.

See [Technical Evaluation](/glossarium/?t=technical-evaluation) for the judgement that follows, and [Technical Testing](/glossarium/?t=technical-testing) for the empirical comparison against requirements.
