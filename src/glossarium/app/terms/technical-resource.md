# Technical Resource

> A **Technical Resource** is an input required for technical activity — material, energy, information, labour, capital or time.

> A resource is a role, not a substance: the same water is a resource for a process, a hazard for a site, and a good for a customer.

Resources are what the technical element consumes rather than what it is. The distinction matters for decomposition: a material that becomes part of the product is a constituent; a material that is consumed in making it is a resource. The same item can be both across two decompositions, which is why the role must be named rather than assumed.
