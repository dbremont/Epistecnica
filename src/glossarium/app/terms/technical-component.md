# Technical Component

> A **Technical Component** is a constituent part of a technical object or system, identified by the role it plays in the whole.

> Componenthood is relational: the same piece of metal is a component in one assembly and scrap outside it. What makes it a component is that a whole assigns it a role, an interface and a consequence of failure.

Decomposition into components is a decision about boundaries: where the interface is drawn, which part is treated as replaceable, and what is allowed to fail independently. That is why the same object has several valid component trees — a mechanical one by load path, an electrical one by circuit, a maintenance one by replaceable unit.

See [Technical Structure](/glossarium/?t=structure) for the invariant organization the components realize, and [Technical Configuration](/glossarium/?t=technical-configuration) for a particular arrangement of them.
