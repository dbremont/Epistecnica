# Path Dependence

> **Path Dependence** is the dependence of present technical possibilities on the sequence of past choices: early decisions, once embedded in infrastructure, skills and standards, constrain what can be done next.

Path dependence is not mere persistence: it is the claim that the order of events matters, so that a different sequence would have produced a different outcome even from the same starting point. Increasing returns — learning, coordination, network effects, expectations — are the usual mechanism that locks a path in.

The concept is a corrective to both determinism and pure optimization: the path is contingent in its origin and constraining in its continuation.
