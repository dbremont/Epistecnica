# Technical Element Space

> **Technical Element Space** is the landscape of technical elements available within a domain: the practices, techniques, objects, systems, knowledge, relations and context from which a technical practice selects what it works with, and against which it measures what it lacks.

It is a working term, not a type in the canonical guide. It generalizes the narrower *technique space* — the set of techniques available in a domain — to every kind of technical element.

The corpus also uses *technical space* for the technique-level reading, where the unit that changes is the technique used in the production chain rather than the capital good that embeds it. Technical element space is the wider landscape; technique space is its technique layer.
