# Technical Element Replacement

> **Technical Element Replacement** is the substitution of one technical element by another in the role the first occupied.

> Replacement is defined by role, not by similarity: the replacing element need not be a better version of the same thing, and often is not.

The state marks the end of one element's occupancy of a role and the beginning of another's. It is distinct from [displacement](/glossarium/?t=technical-displacement), which is the relation between the two elements, and from discontinuation, which is the old element's terminal state: an element can be replaced in one role and persist in another, which is why replacement is rarely total.

See [Technical Displacement](/glossarium/?t=technical-displacement) and [Technical Element Discontinuation](/glossarium/?t=technical-element-discontinuation).
