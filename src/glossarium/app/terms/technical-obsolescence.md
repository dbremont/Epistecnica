# Technical Obsolescence

> **Technical Obsolescence** is the loss of technical relevance or adequacy of an element under changing conditions.

> Obsolescence is relational and gradual: an element becomes obsolete relative to a task, a standard or a support environment, not in itself. It can be perfectly functional and still obsolete.

Four sources are usually distinguished, and they have different remedies: **functional** obsolescence (the element no longer does what is needed), **technical** obsolescence (a better element exists), **regulatory** obsolescence (the element no longer conforms), and **support** obsolescence (parts, skills or infrastructure are no longer available). The last is the one that strands otherwise working systems, and the one that maintenance and documentation are meant to defer.
