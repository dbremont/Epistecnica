# Boundary Object

> **Boundary Object** is an object — a document, a model, a standard, a prototype — that coordinates across communities of practice without requiring them to reach consensus: it is plastic enough to be used differently, and stable enough to be recognized as the same thing.

Boundary objects explain how heterogeneous work gets done without a shared worldview: the engineer, the regulator and the user can each use the same specification, form or model for their own purposes, and the object holds the coordination in place.

The concept is a complement to actor-network: where translation describes how interests are aligned, boundary objects describe the durable artifacts through which alignment is sustained.
