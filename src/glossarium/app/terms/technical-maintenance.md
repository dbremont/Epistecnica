# Technical Maintenance

> **Technical Maintenance** is the set of activities intended to preserve or restore the operational condition of a technical element.

> Maintenance is the work that keeps an element in the life cycle after deployment — and the work that is invisible when it succeeds.

The classical division is **corrective** (after failure), **preventive** (on a schedule or condition), and **predictive** (on an inferred remaining life); a fourth, **evolutionary**, covers the changes that keep an element adequate as requirements move. Maintenance is also where the cost of a design is paid: maintainability is a design property, and an element that is cheap to build and expensive to keep is a design decision, not an accident.

See [Invisible Work](/glossarium/?t=invisible-work) for the labour side and [Technical Obsolescence](/glossarium/?t=technical-obsolescence) for the end state.
