# 15.773 Hands-On Deep Learning

> A fast-paced, hands-on introduction to deep learning with the emphasis on building models that solve complex problems involving unstructured data: deep neural networks and how to set up and train them, convolutional networks for images and video, transformers for natural language processing, generative large language models, and text-to-image models.

**MIT OpenCourseWare** — Spring 2024, graduate (Sloan School of Management), Prof. Rama Ramakrishnan. Prior familiarity with Python and fundamental machine learning concepts (training/validation/testing, overfitting, regularization) is required.
