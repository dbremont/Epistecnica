# 6.867 Machine Learning

> The graduate introduction to machine learning: an overview of the concepts, techniques, and algorithms of the field, from classification and linear regression through boosting, support vector machines, hidden Markov models, and Bayesian networks — with the basic ideas and intuition behind modern methods, a formal account of how, why, and when they work, and statistical inference as the underlying theme.

**MIT OpenCourseWare** — Fall 2006, graduate (Electrical Engineering and Computer Science), Rohit Singh, Prof. Tommi Jaakkola, Ali Mohammad.
