# 18.657 Mathematics of Machine Learning

> A mathematically rigorous introduction to the statistical and algorithmic developments behind machine learning — the automated identification of patterns in data — with emphasis on the methods themselves and their analysis rather than on implementations.

**MIT OpenCourseWare** — Fall 2015, graduate (Mathematics), Prof. Philippe Rigollet.
