# 18.S096 Matrix Calculus for Machine Learning and Beyond

> The step past 18.01 univariate and 18.02 vector calculus: a coherent approach to matrix calculus for modern applications such as machine learning and large-scale optimization — thinking of a matrix holistically rather than as an array of scalars, generalizing and computing derivatives of matrix factorizations and other complicated-looking operations, and understanding how differentiation formulas must be reimagined in large-scale computing. A derivative is re-emphasized as what it really is: a linearization, with differential calculus refocused on the linear algebra at its heart.

**MIT OpenCourseWare** — January IAP 2023, undergraduate (Mathematics), Prof. Alan Edelman and Prof. Steven G. Johnson.
