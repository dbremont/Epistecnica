## Which are the properties of any **mathematical system**?

> Here’s a structured **table of metaproperties** that can be used to analyze any mathematical system (e.g., arithmetic, set theory, logic). These properties describe the system’s behavior, limitations, and relationships to other systems:
> 

| **Property** | **Definition** | **Examples** |
| --- | --- | --- |
| **Consistency** | The system cannot derive both a statement and its negation. | Peano Arithmetic (PA) is consistent if it doesn’t prove $1 = 0$. |
| **Completeness** | Every true statement in the system is provable. | Presburger arithmetic (additive arithmetic) is complete. |
| **Soundness** | Only true statements are provable. | First-order logic is sound: if $\vdash \phi$, then $\models \phi$. |
| **Decidability** | An algorithm exists to determine if any statement is provable. | Euclidean geometry is decidable (Tarski, 1951). |
| **Categoricity** | All models of the system are isomorphic (structurally identical). | Second-order Peano axioms are categorical (unique model: $\mathbb{N}$. |
| **Expressiveness** | The system can formalize certain classes of statements. | ZFC set theory can express almost all modern mathematics. |
| **Independence** | A statement is independent if it can’t be proved or disproved in the system. | Continuum Hypothesis (CH) is independent of ZFC. |
| **Finite Axiomatizability** | The system can be defined with finitely many axioms. | Robinson Arithmetic (Q) is finitely axiomatizable; ZFC is not. |
| **Non-contradiction** | The system obeys the law of non-contradiction $\neg (P \land \neg P)$. | Classical logic satisfies this; paraconsistent logics do not. |
| **Computational Power** | The system’s ability to encode computation (e.g., Turing-complete). | Lambda calculus, PA, and ZFC are Turing-complete. |

**Examples Across Systems**

| **System** | **Consistent?** | **Complete?** | **Decidable?** | **Categorical?** |
| --- | --- | --- | --- | --- |
| **Propositional Logic** | Yes | Yes | Yes | No (multiple models) |
| **Presburger Arithmetic** | Yes | Yes | Yes | No (non-standard models) |
| **Peano Arithmetic (PA)** | Presumed | No (Gödel) | No | No |
| **ZFC Set Theory** | Presumed | No | No | No |
| **Euclidean Geometry** | Yes | Yes | Yes | Yes (second-order) |
