## Notes

---

> The paper you're referring to is **"The Use of Multiple Measurements in Taxonomic Problems"** by Ronald A. Fisher, published in 1936. This is a seminal work in statistics and pattern recognition, where Fisher introduced what is now known as **Fisher's Linear Discriminant Analysis (LDA)**.
> 

> In this paper, Fisher proposed a method to distinguish between different classes of data by finding a linear combination of features that best separates them. This concept laid the foundation for many pattern recognition techniques used in statistical classification and machine learning today.
> 

Fundamental Idea:

- Take a a data set  X;  use a function to map that dataset to a number line;   make sure that the function is able to characterize the  the sub-classes in x;  In the new dataset; reduce withing class-variance; and increase without class variance (we everything is taken into account to compute the variance).
- How to systematically **build such functions**?
